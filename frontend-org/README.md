# 🎭 마음무대 (MindStage) — Next.js 프로토타입

기획서 `타로드라마_마음무대_기획서.md` 기준 구현. 웹이지만 **모바일 앱 화면**으로 고정된 셸(최대 430px, 데스크톱에서는 폰 프레임)로 동작합니다.

## 실행

```bash
npm install && npm run dev
```

`http://localhost:3000` — 브라우저를 모바일 크기로 줄이거나 기기에서 열면 전체 화면 앱처럼 보입니다.

## AI 디렉터

`ANTHROPIC_API_KEY`가 있으면 Claude Opus 5가 디렉터를 맡고, 없으면 **내장 규칙 기반 디렉터(오프라인 모드)** 로 20턴이 끝까지 돌아갑니다. API 호출이 실패해도 항상 오프라인으로 폴백합니다.

```bash
cp .env.example .env.local   # ANTHROPIC_API_KEY=sk-ant-...
```

## 삽화

3회 고정 삽입이 아니라, **매 턴 상태가 바뀌는 하나의 무대**입니다. `SceneState`가 배경(커튼/교실/방/분할/복도/거울/무대/하늘), 조명 세기(0~4), 표정, 가면 정도(1 → 0.5 → 0), 속박 소품, 상대 등장, 카드 상태(뒷면/앞면/뒤집힘)를 함께 바꿔 이야기 진행이 그림으로 보입니다.

## 힌트와 감정

힌트는 **예시 답안이 아니라 열린 질문**이다. 답을 대신 써주면 유저는 그 틀 안에서만 말하게 된다.
대신 몸의 감각("그때 목이 막혔어, 가슴이 눌렸어?"), 목소리의 출처("그 말이 누구 목소리로 들려?"),
처음의 시점("언제부터 그랬을까?")을 묻는다. 사이코드라마에서 감정에 닿는 통로가 대개 이쪽이다.

입력창의 💗 **감정 팔레트**는 이야기를 고르는 객관식이 아니라, 이미 느끼고 있는 것에 붙일 이름을
빌려주는 칸이다. 고른 감정은 말풍선에 붙고, 감정 흐름에 쌓이고, 디렉터가 **그 단어 그대로** 받아쓴다.

## 트라우마를 다룰 때

이 서비스는 청소년이 트라우마에 *가까이* 가도록 설계돼 있다. 그래서 내려올 계단을 같이 넣었다.

- 🫧 **잠깐 멈출래** — 무대 어느 턴에서든 누를 수 있다. 5-4-3-2-1 그라운딩 → 「무대로 돌아갈게」 또는 「오늘은 여기까지 할래」
- 위기·학대 키워드는 AI보다 앞단에서 걸러지고, 전송 자체가 막히며 상담 연결이 뜬다 (해제 불가)
- 디렉터는 단정하지 않고 항상 "혹시 이런 느낌?"으로 제안하며, 유저가 「아닌데」 하면 즉시 되돌아간다
- 25분 알림, 하루 3회 제한 — 한 번에 다 꺼내지 않는 게 더 안전하다

## 데이터

세션·이야기·카드 컬렉션은 모두 브라우저 `localStorage`에만 저장됩니다. 서버로 전송되는 것은 AI 디렉터 호출 시의 세션 맥락뿐입니다.
