# 🎬 마음씬 (MindScene) — Next.js 프로토타입

> 「씬 하나씩 모아서, 내 안의 무대를 짓는다.」
> 기준 문서: [`docs/마음무대_씬무대_유저시나리오_ver2.md`](../docs/마음무대_씬무대_유저시나리오_ver2.md)

`frontend/`(마음무대)와 같은 모바일 셸 · 같은 스택(Next 15 · React 19 · Tailwind 4)이고, 별도 폴더 · 별도 포트(3001)로 돈다.

## 실행

```bash
cd frontend-mind && pnpm install && pnpm dev   # http://localhost:3001
```

`ANTHROPIC_API_KEY`가 있으면 상대 인물 · 진행자 · 거울 되읽기를 Claude가 맡고, 없거나 실패하면 **내장 엔진으로 끝까지** 돈다.

```bash
cp .env.example .env.local   # ANTHROPIC_API_KEY=sk-ant-...
```

## 화면 — 탭은 셋

| 탭 | 무엇 | 경로 |
| --- | --- | --- |
| 🏠 **홈** | 씬을 만드는 입구 — 🎞 오늘의 상황극 · 장르 · 🪞 내 무대 시작 | `/` |
| 🎬 **내 씬** | 씬이 다 모이는 한 곳. 🔗 이어 붙이기 · 🔍 보이는 것 · 💾 내 기록도 여기 안에 | `/scenes` |
| ✨ **소개** | 마음씬이 뭔지 · 두 무대 · 약속 | `/about` |

> 기획서의 「씬 서랍 · 조립대 · 나 노트」는 **「내 씬」 하나**로 합쳤다. 다 같은 씬이기 때문이다.
> - 씬 서랍 → 내 씬 목록 (🎞 · 🪞 · 🔗 필터)
> - 조립대 → 목록에서 「🔗 이어 붙이기」로 씬을 차례로 고르면 끝. 이은 씬도 같은 목록에 뜬다
> - 나 노트 → 「🔍 네 씬에서 보이는 것」이 목록 맨 위에, 그리고 그 줄의 근거가 된 씬 안에

| 흐름 | 경로 | 시나리오 문서 |
| --- | --- | --- |
| 🎞 상황극 고르기 | `/situation?genre=` | §5 |
| 🎞 한 판 — 상황 카드 → 액션 ⇄ PD → 🌟 나였다면? → 마지막 컷 → 원작 공개 → 작가실 | `/situation/[id]` | §4 · §6 · §21 |
| 🪞 내 무대 — 입장 → 카드 → 장면 세우기 → 무대(안쪽 · 마주치기 · 거울 · 다시 해 보기) → 커튼콜 → 다리 | `/inner` | §7~§10 · §11 |
| 씬 하나 — 테이크 · 나란히 · 고친 기록 · 이 씬에서 보이는 것 | `/scenes/[id]` | §15 · §16 |
| 🔗 이어 붙인 씬 — 잇기 · ▶ 이어서 보기 · ✏️ 고친 기록 | `/scenes/join/[id]` | §13 · §14 |
| 🛟 안전 시트 (어디서든) | `components/SafetySheet.tsx` | §20 #13 |

옛 경로(`/drawer` · `/workbench` · `/note`)는 `next.config.ts`에서 `/scenes`로 넘긴다.

## 데이터 — 콘텐츠는 JSON, 기록은 localStorage

**콘텐츠 (`data/*.json`)** — 문구 · 상황극을 바꿀 땐 JSON만 고치면 된다.

| 파일 | 내용 |
| --- | --- |
| `data/archetypes.json` | 🎞 상황극 원형 17개 (장르 6 × 순한 번안 2 + 아래 칸 5) — 장면 · 과제 카드 · 애드립 재료 · 🟡 새 사실 · ⚡ 돌발 · 🌟 결정적 자리 · 원작 공개 |
| `data/inner.json` | 🪞 오늘의 카드 · 막 8개 · 기법 사전 10개 · 진행자 대사 · 다리 문구 · 닮은 고전 키워드 |
| `data/meta.json` | 장르 · 과제 유형 · 맛 · 반 · 다이얼 · 틀 · 「왜 고쳤어?」 칩 · 보이는 것 금지어 |
| `data/safety.json` | 위기 키워드 · 안내 문구 · 상담 번호 |
| `data/about.json` | ✨ 소개 화면 |
| `data/scenes.json` | 🎬 내 씬 문구 — 👣 여섯 걸음 안내 · 🧩 씬 카드 다섯 칸 · 🔗 틀 고르기 (걸음 이름 · 칸 이름은 about.json에서) |
| `data/scenario.json` | 🧪 동작 시나리오 「하은이의 2주」 — 씬 6 · 이은 씬 1 · 고친 기록 · 단계별 확인할 것 |

**기록 (`localStorage`, `lib/store.ts`)** — 이 기기에만. 서버로 안 보낸다. 실명 저장 없음.

| 키 | 내용 |
| --- | --- |
| `mindscene.v1.pieces` | 🧩 씬 (테이크는 지우지 않음) |
| `mindscene.v1.works` | 🔗 이어 붙인 씬 |
| `mindscene.v1.revisions` | ✏️ 고친 기록 — 덮어쓰지 않고 전/후 · 이유를 남김 |
| `mindscene.v1.marks` | 🔍 보이는 것 표시 (맞아 · 아닌데 · 잘 모르겠어 + 덧붙임) |
| `mindscene.v1.custom` | 🪞→🎞 내 장면에서 만든 상황극 카드 |
| `mindscene.v1.profile` | 시기 · 반 · 다 보기 |

내 씬 맨 아래 **💾 내 기록**에서 위 키들을 **JSON 파일 하나로 내보내기 / 가져오기**(지금 기록은 안 지우고 합침) · 모두 지우기.

## 🧪 동작 시나리오로 UI 테스트

✨ 소개의 「예시 — 하은이의 2주」를 내 씬에 단계별로 채워서 화면을 따라가며 확인한다.

| 단계 | 채워지는 것 | 바로 가기 |
| --- | --- | --- |
| Day 0 빈 무대 | 아무것도 없음 | `/scenes?scenario=d0` |
| Day 1–3 가볍게 놀기 | 🎞 씬 2 | `/scenes?scenario=d1` |
| Day 4–6 다리 건너기 | + 🪞 씬 3 · 고친 기록 1 → 🔍 보이는 것 생김 | `/scenes?scenario=d2` |
| Day 7–12 잇고 고치기 | + 테이크 2 · 🪞 씬 1 · 📖 이은 씬 · 고친 기록 | `/scenes?scenario=d3` |
| Day 14 돌아보기 | + 「맞아」 표시 · 내 말 한 줄 | `/scenes?scenario=d4` |

- 내 씬 맨 아래 「🧪 동작 시나리오로 따라가 보기」 또는 소개 「예시」의 버튼으로도 들어간다.
- 들어갈 때 지금 기록을 `mindscene.demo.real`에 챙기고, **「시나리오 끝내기」**를 누르면 그대로 되돌린다.
- 단계마다 「확인할 것」 체크리스트(체크 상태는 `mindscene.demo.state`) · 「⬇ 이 단계 JSON」(💾 가져오기와 같은 모양).
- 날짜는 `"-13d 16:20"` 꼴(오늘에서 며칠 전)로 적어 두고, 불러올 때 진짜 날짜로 바꾼다.

## 코드

| 경로 | 역할 |
| --- | --- |
| `lib/types.ts` | `ScenePiece` · `Take` · `Work` · `Revision` · `Insight` — 문서 부록 B-1 |
| `lib/data.ts` · `lib/meta.ts` | JSON에 타입을 입혀 내보냄 |
| `lib/improv.ts` | 🎞 상대 인물 오프라인 엔진 — 내 말의 한 단어를 받아 반응 · 다이얼 · 귓속말 · 🟡 새 사실 |
| `lib/inner.ts` | 🪞 진행자 오프라인 엔진 — 막 진행 · 기법 · 속말 제안 · 3인칭 거울 · 닮은 고전 · 상황극으로 옮기기 |
| `lib/insight.ts` | 🔍 보이는 것 — 근거(내 말 · 고친 자리) 없는 줄과 진단 말은 버림 |
| `lib/text.ts` | 받침에 맞는 조사 · 받아칠 단어 고르기 |
| `lib/diff.ts` | ✏️ 바뀐 것만 — 낱말 단위 형광펜 |
| `lib/store.ts` · `lib/pieces.ts` | localStorage 읽기/쓰기 · 고친 기록 · 백업 · 씬 끝나면 자동 저장 |
| `app/api/scene/route.ts` | AI 라우트 — 안전 필터가 AI보다 앞. 실패하면 `{ offline: true }` |

## 원칙 (문서 §21 그대로)

한 화면 한 동작(액션의 주인공은 ✋ 컷) · 두 무대는 색으로 구분(🎞 밝은 무대 조명 / 🪞 낮은 객석 조명) · 모든 입력에 🎙 · 30초 비면 `패스` `지문만` `컷` · 나가는 문(✋ 컷 / ✋ 여기까지)이 늘 보임 · 다리는 칩, 강요 없음 · 저장 버튼 없음 · 고친 자리는 노란 형광펜 · 숫자 없는 화면.
