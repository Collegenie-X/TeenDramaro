# 마음무대 — 대화를 만들어 가는 방식 (장면 설계)

> [디렉터 개입패턴](../마음무대_디렉터_개입패턴.md)이 **비트 하나**(지시 → 관찰 → 질문)를,
> [열린무대 흐름표](마음무대_열린무대_흐름표.md)가 **세션 전체**(막 8개)를 다룬다면,
> 이 문서는 그 사이 — **장면 하나가 어떻게 흘러가고, 장면끼리 어떻게 이어지는지**를 다룬다.
>
> 구현: `frontend/data/patterns.json` (새 패턴 12개) · `frontend/lib/patterns.ts` (`after` 조건) ·
> `frontend/lib/prompts.ts` (DIRECTOR_SYSTEM의 [장면 하나의 흐름] [장면 사슬] [현실에 없던 장면])

표기: `{A}` 아바타 · `{B}` 상대 · **D** 디렉터 · **U** 유저 · `*…*` 보조자아 지문

---

## 0. 왜 필요한가 — 빠져 있던 가운데 층

```
  세션  ── 막(Movement) 8개 ── 캐스팅 → 카드 → 펼치기 → 안쪽 → 마주침 → 거울 → 다시 → 커튼콜
   │
  장면  ── ??? ─────────────── ← 여기가 비어 있었다
   │
  비트  ── 지시 → 관찰 → 질문 (+ 단계도 L1~L7, 개입 패턴 39개)
```

비트와 막만 있으면 디렉터는 매 비트를 따로따로 잘 만들지만, 대화 전체는
**"장면 세우기 → 다른 장면 세우기 → 또 다른 장면"** 처럼 사건을 나열하게 된다.
실제 사이코드라마 디렉터는 한 장면을 **작은 이야기 한 편**처럼 끌고 가고,
장면과 장면을 **나선형으로** 잇는다. 이 문서는 그 두 가지를 정한다.

## 1. 장면 아크 — 장면 하나의 다섯 박자

```
  ① 세우기 ──→ ② 들어가기 ──→ ③ 멈추기 ──→ ④ 한 수 ──→ ⑤ 객석으로
  어디·언제·누구   움직이고 보기    "잠깐."        기법 하나      "컷. 객석으로 와."
  L1~L2           L2~L3          L3            L3~L5         (거리 벌리기)
  open.enter      open.place     deep.freeze   deep.double   arc.wrap ★새
  open.oneScene   open.sense     deep.body     meet.reverse  mirror.audience
                  open.object                  surplus.* ★새
```

| 박자 | 하는 일 | 디렉터 말 예 | 실패 모양 |
|---|---|---|---|
| ① 세우기 | 장소·시간·사람을 현재형으로 깐다 | "자, 급식실이야. 점심시간. 소라 식판 들고 서." | 요약을 요약으로 받는다 |
| ② 들어가기 | 아바타가 그 안에서 움직이게 하고, 보이는 걸 짚는다 | "소라 어디로 걸어가? … 발이 좀 느려졌네." | 설명만 듣고 장면 안에 안 들어간다 |
| ③ 멈추기 | 제일 선명한 순간을 잡아 정지 | "잠깐. 거기서 멈춰." | 멈출 자리를 지나쳐 다음 사건으로 간다 |
| ④ 한 수 | 그 순간에 맞는 기법 **하나** | "소라 뒤에 '속의 소라' 하나 세울게. 걔는 뭐래?" | 기법 없이 "어땠어?"만 반복 |
| ⑤ 객석으로 | 장면을 닫고 밖에서 보게 한다 | "컷. 객석으로 와. 저기 소라, 처음이랑 뭐가 달라 보여?" | 장면을 안 닫고 다음 장면으로 넘어간다 |

**규칙**
- 다섯 박을 다 돌 필요는 없다. 하지만 **①만 반복**하거나 **④ 없이 장면을 바꾸면** 잔잔바리가 된다.
- 한 박자 = 한두 비트. 장면 하나는 대략 **4~8비트**.
- ⑤는 장면의 끝맺음이자 다음 장면으로 가는 문이다. 객석에서 "다른 장면도 올려볼래?" 혹은 "같은 장면 다시 해볼래?"로 이어진다.
- 유저가 닫는 신호를 보내면 박자와 상관없이 ①로 돌아간다 (`back.up`).

### 실전 — 한 장면 (펼치기 → 안쪽, 6비트)

```
U  요즘 단톡방에서 나만 대답 안 해주는 느낌이야

D  ① 단톡방. 하루 중에 딱 한 순간만 무대에 올리자. 언제야?
U  밤에 침대에서. 내가 쓴 말 밑에 아무도 답이 없을 때

D  ② 불 꺼진 방. 침대. 소라 폰 들고 누워 있어. 화면 불빛만.
   소라 손가락이 지금 뭐 하고 있어?
U  올렸다 내렸다. 계속 새로고침

D  ③ 잠깐. 거기서 멈춰. 손가락 화면 위에 둔 채로.
   소라 몸은 어디가 먼저 반응해?
U  목이 좀 막히는 거 같아

D  ④ 소라 뒤에 '속의 소라' 하나 세울게. 겉의 소라는 폰만 보고 있어.
   속의 소라는 지금 뭐라고 해? 크게 말해봐.
U  "역시 나는 없어도 되는 애구나"

D  ⑤ 컷. 객석으로 와. 조명 그대로.
   저기 누워 있는 소라, 처음에 폰 들었을 때랑 지금이랑 뭐가 달라 보여?
U  처음엔 그냥 확인하는 거였는데 지금은 혼자 판결 내리고 있어
```

## 2. 장면 사슬 — 지금 → 옛날 → 다시 지금

사이코드라마의 고전적인 나선 구조. 지금 아픈 장면에서 출발해, 같은 느낌이 처음 났던
옛 장면에 잠깐 다녀오고, **반드시 지금으로 돌아와서** 다르게 해본다.

```
         ┌─────────── 2. 옛 장면 (chain.back) ───────────┐
         │   조명이 바뀌고 {A}가 어려진다                   │
         │   "그때 {A} 몇 살이고, 거기 어디야?"             │
         │        └ 그때 필요했던 사람 (surplus.goodOther) │
         ▼                                               │
  1. 지금 장면 ─────────────────────────────────────────→ 3. 다시 지금 (chain.return)
  "단톡방, 밤, 침대"                                      "어린 {A}를 보고 오니까
                                                          지금 {A}가 왜 저렇게 서 있는지 보여?"
                                                                  │
                                                                  ▼
                                                          4. 다시 해보기 (replay.*)
```

| 단계 | 패턴 | 조건 |
|---|---|---|
| 지금 → 옛날 | `chain.back` ★ | **유저가 먼저** "처음엔", "초등학교 때", "전에도"를 꺼냈을 때만. 가도 괜찮은지 묻는다. L5~L6 |
| 옛 장면 안에서 | `surplus.goodOther` ★ | "그때 옆에 누가 한 명 있었다면?" — 대사는 유저가 쓴다 |
| 옛날 → 지금 | `chain.return` ★ | `chain.back`을 쓴 뒤에만 후보가 된다 (`after` 조건). 옛 장면에 두고 끝내지 않는다 |
| 지금에서 다시 | `replay.take` → `replay.exits` | 옛 장면에서 본 걸 연료로 같은 장면을 다르게 |

**금기**
- 디렉터가 과거를 캐내지 않는다. "어렸을 때 무슨 일 있었어?" ✗
- 옛 장면에서 원인을 확정하지 않는다. "그래서 지금 이러는 거네" ✗
- 한 세션에 한 번. 매번 뿌리로 가면 무대가 상담실이 된다.

### 실전 — 사슬 (1장 이어서)

```
U  사실 초등학교 때도 이랬어. 반 애들이 생일파티 나만 안 불렀어

D  [chain.back] 조명 바꿀게. 무대가 조금 어려진다 — 가도 괜찮으면.
   그때 소라 몇 살이고, 거기 어디야?
U  4학년. 교실. 애들이 초대장 나눠주는데 나만 없었어

D  교실. 초대장이 책상 위로 하나씩 놓여. 소라 책상만 비어 있어.
   [surplus.goodOther] 그 교실에 의자 하나 더 놓을게. 소라 옆에.
   그때 거기 누가 한 명 있었다면, 어떤 사람이었으면 좋겠어? 그 사람이 소라한테 뭐라고 해?
U  그냥 옆에 앉아서 "나도 안 받았어. 우리 둘이 놀자" 해주는 애

D  [chain.return] 다시 지금. 밤, 침대, 폰 불빛으로 돌아와.
   4학년 소라를 보고 와서 보니까, 지금 소라가 왜 저렇게 새로고침하고 있는지 좀 보여?
U  …또 초대장 기다리는 거네

D  [replay.take] 테이크 2. 같은 밤이야. 이번엔 소라가 폰 들고 다른 걸 해봐.
```

## 3. 현실에 없던 장면 — 무대에서만 되는 것 (잉여현실)

실제로 일어나지 않은 장면도 무대엔 세울 수 있다. 말로는 안 잡히던 게 모양을 가지면 다룰 수 있게 된다.
**모양·대사·답은 언제나 유저가 정한다.** 디렉터는 무대만 깐다.

| 패턴 | 언제 | 디렉터 말 | 막 · 깊이 |
|---|---|---|---|
| `surplus.concretize` 마음을 무대에 세우기 | "불안해", "부담돼", "답답해"처럼 형체 없는 말 | "그 부담, 무대에 하나 세워볼게. 사람이나 물건이라면 뭐야? 소라한테서 얼마나 떨어져 서 있어?" | 펼치기·안쪽·마주침 · L3~4 |
| `surplus.sculpt` 사람 지도 | "반 애들", "단톡방", "가족"처럼 여러 사람 | "소라 가운데 세우고 주변에 사람들 하나씩. 누가 제일 가깝고 누가 등 돌리고 있어?" | 마주침 · L2~3 |
| `surplus.council` 속마음 회의 | "하고 싶은데 싫어", "반반이야" | "소라 속에 목소리가 하나가 아닌 것 같아. 몇 명이야? 제일 목소리 큰 애는 뭐래?" | 안쪽 · L4~5 |
| `surplus.goodOther` 그때 필요했던 사람 | "아무도 몰라줬어", "혼자였어" | "그 장면에 의자 하나 더. 누가 있었으면 좋겠어? 그 사람이 뭐라고 해?" | 안쪽·다시 · L6~7 |
| `surplus.futureSelf` 미래의 아바타 | 리플레이 뒤 / 커튼콜 앞 | "무대 끝에 몇 년 뒤의 소라가 서 있어. 지금 소라한테 한마디 한다면?" | 다시·커튼콜 · L4~5 |
| `surplus.magicShop` 마음 가게 | 욕구(L7)가 나온 뒤, 가볍게 | "무대 한쪽에 마음만 파는 가게. 소라는 뭘 사고 싶어? 값으로 하나는 두고 가야 해." | 다시·커튼콜 · L5~7 |

### 실전 — 마음을 무대에 세우기

```
U  시험 생각하면 그냥 답답해. 뭔지 모르겠어

D  그 답답한 거, 무대에 하나 세워볼게.
   그게 사람이나 물건이라면 뭐야? 소라한테서 얼마나 떨어져 서 있어?
U  큰 냉장고? 바로 등 뒤에 붙어 있어. 문이 열려서 찬바람 나와

D  등 뒤에 냉장고. 문 열린 채로. 소라 어깨가 좀 움츠러들었네.
   소라가 그 냉장고한테 한마디 한다면?
```

> 유저가 고른 "냉장고"는 이후에도 그대로 "냉장고"라고 부른다. "시험 압박"으로 바꿔 부르지 않는다.

## 4. 대화가 막히는 다섯 가지 모양 — 갈래별 길

같은 디렉터라도 유저마다 길이 달라야 한다. 유저의 말 모양을 보고 고른다.

| 유저 모양 | 신호 | 길 | 패턴 |
|---|---|---|---|
| **한 단어형** | "몰라", "그냥", 5자 이하 | 캐묻지 말고 장면 한 줄로 디딤돌 → 두 번 이어지면 카드 | `back.up` → `back.card` |
| **쏟아내기형** | 긴 문단, 여러 사건 | 디렉터는 더 짧게. 그중 한 장면만 고르게 | `open.oneScene` |
| **농담형** | "ㅋㅋ", "장난이고" | 지적하지 말고 같이 웃은 다음, 웃는 얼굴 뒤를 한 겹만 | `turn.joke` ★ |
| **상대 얘기형** | "걔가…", "엄마가…" 가 계속 | 상대 얘기를 막지 말고 카메라만 아바타에게 돌린다 | `turn.camera` ★ |
| **해결 요청형** | "어떻게 해야 돼?", "뭐라고 해?" | 조언하지 않는다. 질문 자체를 리플레이 재료로 | `turn.howTo` ★ → `replay.exits` |

### 실전 — 해결 요청형

```
U  그래서 걔한테 뭐라고 해야 돼? 알려줘

D  정답은 나도 몰라. 대신 무대에선 해볼 수 있어.
   소라를 그 복도에 다시 세우고, 몇 가지 버전으로 가볼까?
   ┌ 말로 받아치기 ┐ ┌ 자리 뜨기 ┐ ┌ 농담으로 비틀기 ┐ ┌ 아무것도 안 하고 버티기 ┐
```

## 5. 대화의 리듬 — 조였다 풀었다

```
  깊이
  L6 ┤                    ●
  L5 ┤                 ●     ●
  L4 ┤          ●   ●           ○ ← 숨구멍
  L3 ┤       ●     ○                 ●
  L2 ┤  ● ●                             ● ●  ← 장면 닫고 객석
  L1 ┤●
     └──────────────────────────────────────── 비트
       세우기   한 수  객석  사슬   돌아옴  다시 해보기
```

- **내려갈 땐 한 칸씩, 올라올 땐 한 번에.** (단계도 규칙 그대로)
- **무거운 비트 세 개 뒤엔 숨구멍 하나.** 질문 없이 끝나는 비트(★)나 디렉터의 가벼운 한마디 (`back.breath`).
- **장면을 닫을 땐 객석을 거친다.** 몰입(장면 안) ↔ 거리(객석)를 번갈아야 지치지 않는다.
- **L6~L7은 세션에 한두 번.** 깊은 곳은 잠깐 다녀오는 곳이지 머무는 곳이 아니다.

## 6. 한 세션을 장면으로 보면

```
 캐스팅 ─ 카드 ─┬─ 장면 A (지금) ─────────── 1장 아크 ①~⑤
                │     └ 사슬: 장면 A' (옛날) ─ 2장  (유저가 먼저 꺼냈을 때만)
                │     └ 돌아옴: 장면 A
                ├─ 장면 B (마주침, 보조자아) ─ 사람 지도 / 역할 바꾸기
                ├─ 거울 (객석에서 A·B 되읽기)
                ├─ 다시: 장면 A 테이크 2, 3 ─ 출구 여러 개
                └─ 커튼콜 ─ 미래의 아바타 / 마음 가게 (선택)
```

장면은 **2~3개면 충분하다.** 장면 수보다 한 장면에서 ④(한 수)와 ⑤(객석)를 제대로 도는 게 중요하다.

## 7. 새로 들어간 패턴 (patterns.json)

| id | 이름 | 기법 | 막 | 깊이 | 비고 |
|---|---|---|---|---|---|
| `arc.wrap` | 장면 닫고 객석으로 | mirror | open·deepen·meet | 3~5 | 장면 아크 ⑤ |
| `chain.back` | 옛 장면으로 건너가기 | set | deepen | 5~6 | 유저가 옛날을 먼저 꺼냈을 때 |
| `chain.return` | 지금으로 돌아오기 | set | deepen·meet·replay | 5~7 | `after: ["chain.back"]` |
