## 0. 한 줄

**「무대는 세워 놨어. 대사는 없어. 네가 주인공으로 들어가고, 판이 마음에 안 들면 컷 외쳐.」**

| 핵심 | 내용 |
| --- | --- |
| 🎬 방 = 씬 | 방 하나는 S# 한 줄짜리 씬 하나. 어디, 언제, 누가, 방금 무슨 일 |
| 📄 상황만 | 작가는 상황 카드만 쓴다. 대사 0줄. 고정 사실 3개 안팎 + 「열려 있는 것」 |
| 🎞 장르 먼저 | 장르는 분위기가 아니라 **그 장르가 돌아가는 규칙** |
| 🎭 나는 주연 | 주인공 한 명은 내가 연기한다. 다른 인물들이 **나한테 반응**한다 |
| 🎛 나는 PD | 「컷」 하면 씬이 멈추고 콘솔이 열린다. 다이얼·귓속말·돌발·다시 찍기 |
| 🟡 애드립 | 인물은 상황만 지키면 뭐든 한다. 새로 생긴 사실이 쌓이고, 그게 결과물 |
| 🧩 내 작품 조립 | 장르 × 갈등 20 × 각도 × 인트로 × 본론 × 결론 → 중학생 처지의 상황 카드 |
| 🏛 세 층 원천 | 뼈대는 고전, 공기는 최신 작품(종류만), 세부는 다시 고전 |
| 🌟 명대사 | 고전 각색 대본에서 제일 유명한 한 줄은 **안 보여주고** 「나였다면?」 |
| 🛡 안전장치 | 뼈대 방화벽 · 원본 복원 · 저작권 · 수위 · `checkSafety` |

```
씬 방 1개            = 방탈출 한 판 (10분)
씬 방 7개 이어 붙임   = 단막극 한 편 (40분)
단막극 여러 편        = 연속극
기억으로 만든 씬      = 기억 씬 연습 (10분)
```

깊은 무대는 **내 이야기**를 디렉터와 들여다보고, 씬 무대는 **내가 세운 판에서 논다.** 놀다가 「이거 내 얘기랑 닿는데」 싶으면 깊은 무대로 가는 문은 늘 열려 있다.

# 1부 — 씬 무대: 놀이의 뼈대

## 1. 장르 — 그 장르가 돌아가는 규칙

| 장르 | 꼭 있어야 하는 것 | 씬 예 |
| --- | --- | --- |
| 🔍 추리 | 🗝 진실 카드 1장 · 단서 2~3개 · 숨기는 인물 1명 이상 | 방과 후 교실, 학급비 봉투가 사라졌다 |
| 💘 로맨스 | 아직 말 안 한 마음 1개 · 그걸 막는 것 1개 | 막차 정류장, 둘만 남았다 |
| 😰 스릴러 | ⏱ 시간 제한 · 들키면 안 되는 것 | 시험지 유출 소문 돈 밤, 교무실 앞 |
| 🌱 청춘물 | 오늘 안에 정해야 할 것 1개 · 친구 사이의 금 | 수학여행 버스 뒷자리 |
| 🏠 가족극 | 매일 반복되는 자리 · 아무도 안 꺼내는 얘기 | 일요일 아침 식탁 |
| 😂 코미디 | 오해 1개 · 혼자 진지한 인물 1명 | 발표 5분 전, USB가 없다 |
| 🏆 스포츠·오디션 | 하나뿐인 자리 · 남이 모르는 약점 | 계주 대기석 |
| 🌍 SF·판타지 | 🌐 세계 규칙 1개 (절대 안 바뀜) | 매일 같은 화요일이 반복되는 교실 |

- 씬마다 장르 하나. 섞고 싶으면 PD 콘솔 **톤**으로 살짝.
- 첫 공개 추천: 🔍 추리 · 💘 로맨스 · 😂 코미디.

## 2. 상황 카드 — 작가가 쓴 건 이게 전부

```
S#.  3학년 2반 교실 / 방과 후 5시 10분 / 해 질 무렵
장르: 🔍 추리

[상황]
  학급비 봉투(12만 원)가 교탁 서랍에서 사라졌다.
  반장 서연이 방금 그걸 발견했다. 교실엔 민재가 남아 있다.
  10분 뒤 담임이 걷으러 온다.

[인물]
  🎭 민재 (주인공 — 네가 연기)
     마지막까지 교실에 있던 애. 원하는 것: 빨리 가는 것. 숨기는 것: 오늘 학원을 빠졌다.
  서연 — 반장. 원하는 것: 내 책임이 아니라는 것. 숨기는 것: 봉투를 교탁 위에 두고 매점에 갔다.

[고정 사실] — 누구도 못 바꿈. PD도.
  · 봉투는 5시 전까지 교탁 서랍에 있었다 (서연이 봤다)
  · 교실 창문 하나가 열려 있다
  · 10분 뒤 담임이 온다

[진실 카드] 🗝 — 봉인 / 열람
  · ●●●●●●●●

[열려 있는 것] — 여기서부터 애드립 구역
  · 누가 무엇을 의심하는가
  · 둘이 서로에게 무엇을 털어놓는가
  · 담임이 오기 전에 무슨 일이 일어나는가
```

- 대사 0줄. 말버릇 한두 개까지만.
- 고정 사실 3개 안팎. 많으면 애드립이 숨을 못 쉰다.
- 🎭 주인공 자리 표시. 다른 인물로 바꿔 들어가면 다른 극이 된다.
- 🗝 진실 카드(추리): **봉인** = 나도 모르고 들어간다(추리 연습) / **열람** = 알고 연출한다(연출 연습).

## 3. 주연 겸 PD — 두 화면

```
 ┌──── 🎭 액션 (연기 중) ────┐        ┌──── 🎛 PD (씬 멈춤) ────┐
 │ 상황 카드 (접힘)           │  컷 →  │ 다이얼·귓속말·돌발·속마음 │
 │ 서연: 학급비. 너 있었지.   │        │ 템포·무르기·비트 N부터    │
 │ [🎙 말하기] [지문] [✋ 컷] │  ← 액션 │ 🟡 새 사실 보드  [🎬 액션] │
 └──────────────────────────┘        └──────────────────────────┘
```

| | 🎭 액션 | 🎛 PD |
| --- | --- | --- |
| 씬 | 흐른다 | 멈춘다 |
| 화면 | 대사 입력 + 지문 + 컷 | 콘솔 + 새 사실 보드 |
| 나는 | 주인공. 주인공이 아는 것만 안다 | 판 전체를 본다 |

- 대사 중간엔 콘솔이 안 열린다. 감독 겸 주연이 「컷」 하고 모니터 보러 나가는 동작. 컷이 곧 **밖에서 보는 시선이 돌아오는 순간**이라 1인칭 몰입을 잡아 준다.
- **PD만 하기**(주인공도 AI)는 선택지. 기본은 주연 겸 PD.

**주인공 카드 = 오늘 연기할 역** — 다이얼 대신 **연기 목표** 하나(「끝까지 학원 얘기 안 하기」). 내 배우 카드에서 가져오거나, 반대로 서 보거나. 작가실이 목표와 실제 연기를 비교한다(평가 아니라 기록).

**차례 규칙** — AI 인물은 최대 2비트 뒤 주인공 차례. 주인공이 30초 넘게 비면 상대가 먼저 한마디, 또는 칩 `패스` `지문만` `컷`. 대사 없이 지문만도 연기다.

**🎙 말로 연기** — 기존 STT. 상대 대사는 TTS(선택).

## 4. PD 콘솔

| 버튼 | 하는 일 |
| --- | --- |
| 🎛 성격 다이얼 | 다른 인물 성격을 돌린다. 액션 이후 대사부터 반영 |
| 🤫 귓속말 | 한 인물에게만 방향 지시. 「~라고 말해」는 거절 |
| ⚡ 돌발 상황 | 장르별 카드 + 직접 쓰기 |
| 🔎 속마음 | 한 인물의 속마음 한 줄 (PD만 앎) |
| ⏩ 템포 | 시간 건너뛰기 |
| ✋ 무르기 | 애드립으로 생긴 사실 하나를 없던 걸로 |
| ⏪ 다시 찍기 | 원하는 비트부터. 전 테이크는 남는다 |
| 🎚 톤 | 장르 톤 섞기 |

**성격 다이얼 4개** (AI 인물마다): 🔥 온도(차분↔터짐) · 🎭 솔직함(숨김↔다 말함) · 💬 말 수 · 👀 상대를 보는 눈(내 사정↔상대 사정). 모바일 기본 노출은 🔥·🎭 둘.

> 같은 대사를 다시 쳐도 상대 다이얼에 따라 반응이 달라진다. **「내 말은 그대로인데 세상이 다르게 받는다」**를 직접 겪는 게 이 모드의 제일 큰 재미.

**PD도 못 하는 것** — 🔒 고정 사실(씬 밖 「카드 고치기」 = 새 판) · 🗝 진실 카드(봉인하면 끝까지) · 다른 인물 입에 대사 넣기(그 말을 하고 싶으면 주인공 입으로, 또는 주인공을 그 인물로 바꿔 들어간다).

## 5. 애드립 규칙 — AI 인물이 사는 법

1. **받고, 더한다.** 「아니」도 받은 다음에.
2. 고정 사실과 부딪히지 않는다.
3. 모르는 건 모른다. 진실은 아는 인물에게만.
4. 새 사실은 지어내도 된다 → **🟡 새 사실**로 쌓인다. 무르기 전까지 진짜.
5. 씬을 대신 끝내지 않는다. 결정적 한 걸음은 **주인공**이 딛거나 PD가 돌발로 연다.
6. 한 비트 한 명, 1~2문장 + 지문 반 줄.
7. 장르 규칙을 지킨다 (추리 단서는 공정하게, 로맨스 마음은 바로 말 안 함).
8. **주인공에게 반응한다.** 상황보다 주인공의 방금 말·행동이 먼저.

## 6. PD가 아는 것 vs 주인공이 아는 것

컷에서 본 것(속마음·귓속말·열람한 진실)을 주인공은 모른다. **막지 않는다.** 대신 「아는데 모르는 척하기」를 연습 거리로. 주인공이 알 수 없는 걸 말하면 작가실이 짚는다 — 사용자가 설명할 수 있으면(「창밖으로 봤다는 설정」) 🟡 새 사실, 못 하면 누설. 추리 봉인 모드엔 **🔎 속마음 끄기** 선택지.

# 2부 — 갈등 원천과 내 작품 조립

## 7. 세 층 — 뼈대는 고전, 공기는 최신 작품, 세부는 다시 고전

> 갈등의 **재료는 저작권 없는 고전**(셰익스피어·그리스 비극·성경·안데르센·우리 고전)이다. 만화·웹툰·영화·연극·뮤지컬 — **최근 3년 · 15세 관람가** — 는 「요즘의 공기」를 주고, 그 갈등이 지금도 살아 있다는 **확인**이다. 단위는 **씬 하나.** 명대사 없음.

```
🏛 뼈대 (고전)        갈등 코어 · 관계의 종류 · (단막극용) 3막
       │
🎬 공기 (최신 작품)    상황의 종류 · 장소의 현대성 · 매체 · 속도 · 요즘 말의 결
       │
🏛 세부 (고전)        원하는 것 · 숨기는 것 · 상징 물건·행동 · 결말의 방향
       │
🧒 재구성 (우리)       중학생 자리 · 가명 · 고정 사실 3개 · 열려 있는 것 · 대사 0줄
       ▼
    상황 카드
```

### 7-1. 층별 규칙

| 층 | 출처 | 가져온다 ✅ | 안 가져온다 ❌ | 왜 안전한가 |
| --- | --- | --- | --- | --- |
| 🏛 뼈대 | 고전 | 갈등 코어 한 줄, 관계의 종류, 단막극용 3막 한 줄씩 | 번역본 문장 | 공유 자산 |
| 🎬 공기 | 최신 작품 (3년·15세) | **상황의 종류**, 장소의 현대성(학원 셔틀·고시원), 매체(단톡·캡처·배터리), 속도, 요즘 말의 결 | **그 씬 자체**, 고유 장치·물건·규칙·공간, 이름, 대사, 사건 순서, 비주얼·가사 | 「현대 생활의 사실」과 「종류」는 아이디어. 보호 안 됨 |
| 🏛 세부 | 고전 | 원하는 것·숨기는 것, 상징 물건·행동(손수건·편지·촛불·박), 결말의 방향 | 번역본 문장 | 세부가 고전이면 최신 작품과 **구체적 조합이 겹칠 수 없다** |
| 🧒 재구성 | 우리 | 중학생 자리(§7-3), 가명, 고정 사실, 열려 있는 것 | — | 우리 창작 |

**왜 안전한가, 한 줄** — 실질적 유사성은 「구체적 조합」에서 생긴다. 공기 층만 최신 작품에서 오고 뼈대·세부·대사·이름이 전부 다른 데서 오면, 완성 씬에 그 작품과 겹치는 조합이 남지 않는다.

**씬 하나 단위** — 3막 구조보다 씬 하나의 상황이 조합이 짧아 「누구나 쓸 수 있는 상황」에 가깝고, 이 앱(방 = 씬)에 맞는다. 단막극용 3막이 필요하면 **고전 뿌리**에서.

**서명 씬 예외** — 씬 하나여도 그 작품의 상징 같은 장면(고유 장치가 핵심)은 표현이다. 판별: **다른 작품 3개 이상에 이 상황이 있는가.** 없으면 안 가져온다.

**최신 작품이 고전에 새로 더한 비틀기**는 그 작품 것. 기록만 하고 쓰지 않는다.

### 7-2. 걸러내기 순서

```
⓪ 뿌리 먼저   갈등을 고르면 고전 뿌리 2개 이상 (§8). 못 찾으면 그 갈등은 쓰지 않는다
① 공기 확인   같은 종류의 상황이 최신 작품 3개 이상에 있나 → 있으면 장르 관습(누구 것도 아님)
② 재구성      중학생 자리로 (§7-3). 장소·나이·사건·관계 전부 바꿈
③ 테스트      완성 카드만 읽고 — 고전은 알아봐도 되고, 특정 최신 작품은 알아볼 수 없어야 한다
```

**③ 테스트, 층별로**

| 질문 | 「예」면 |
| --- | --- |
| 완성 카드로 특정 최신 작품을 맞힐 수 있는가 (두 사람이 읽음) | 공기 층이 너무 두껍다 → 공기만 다시 |
| 공기 층에 그 작품에만 있는 물건·규칙·공간이 남았는가 | 고유 장치 → 뺀다 |
| 세부의 고전 출처 씬을 만든 사람이 댈 수 있는가 | 못 대면 최신 세부일 수 있다 → 고전에서 다시 |
| 뼈대의 고전 뿌리가 2개 이상인가 | 1개면 그 고전의 특이 구조일 수 있다 → 더 추상화 |

## 9. 내 작품 조립 — 여섯 번 고르면 무대가 선다

```
① 장르 → ② 갈등 → ③ 각도 → ④ 인트로 → ⑤ 본론 → ⑥ 결론 방향
                                                      │
                                         상황 카드 자동 생성 (§2 형식)
                                                      │
                                    🎭 주인공 = 나 → 액션 / 컷 / PD (1부)
```

| 단계 | 고르는 것 | 선택지 |
| --- | --- | --- |
| ① 장르 | 어떤 규칙으로 | §1의 8개 |
| ② 갈등 | 무슨 일 | §8의 20개 |
| ③ **각도** | 누구 자리에서 | 😮 당한 사람 · 😬 한 사람 · 👀 본 사람 · 🫥 끼인 사람 |
| ④ 인트로 | 어디서 시작 | 🌤 일상부터 · ⚡ 사건 한가운데 · ⏪ 끝에서 거꾸로 |
| | 어떻게 알게 | 👁 직접 · 🗣 소문 · 📱 화면 |
| ⑤ 본론 | 뭐가 판을 흔드나 | 🚪 사람이 들어온다(조연 슬롯: 목격자·내 편·방해꾼·당사자·어른·엉뚱한 존재) · ⏱ 시간이 쫓는다 · 💣 정보가 터진다 |
| ⑥ 결론 **방향** | 어디서 끝나나 — 열린 결말 안에서 | 🗣 말하고 끝 · 🤐 말 안 하고 끝 · 🔄 뒤집고 끝 · ⏳ 미루고 끝 |

- 마지막 컷(대사 한 줄 + 지문 한 줄)은 어느 방향이든 **내가 쓴다.** 방향은 상대역·조연을 어느 쪽으로 세울지에만 쓴다.
- ③ 각도 = **「다양한 각도에서 영화 보기」.** 같은 갈등을 세 각도로 들어가면 세 작품.
- 같은 갈등을 장르만 바꿔(장르 렌즈) — 「단톡 빼기」가 추리면 「누가 처음 빼자고 했나」, 코미디면 「빠진 줄 모르고 계속 말하는 애」.
- 고르기가 부담이면 🎲 추천 조합(내 배우 카드 + 안 가 본 갈등).

**생성 예 — 🔍 추리 × 2 단톡 빼기 × 👀 본 사람 × ⏪ 끝에서 거꾸로 × 💣 정보가 터진다 × 🤐 말 안 하고 끝**

```
S#.  2학년 3반 교실 / 월요일 아침 8시 20분 / 담임 안 옴
[상황 — 끝에서 거꾸로]
  지난 금요일 밤, 반 단톡에서 유나가 빠졌다. 지금 유나는 교실에 들어와 자기 자리에 앉았다.
  아무도 말을 안 건다. 「나」(하은)는 그 단톡을 처음부터 끝까지 봤다. 담임까지 10분.
[인물]
  🎭 하은 (본 사람) — 원하는 것: 아무 일 없이 1교시. 숨기는 것: 처음 「빼자」 나왔을 때 「ㅇㅋ」를 눌렀다.
  유나 — 원하는 것: 누가 처음 말했는지. 숨기는 것: 캡처를 이미 갖고 있다.
  지호 — 처음 「빼자」고 한 애. 원하는 것: 자기가 처음이 아닌 걸로. 숨기는 것: 유나한테 빌린 돈.
[고정 사실]  · 금요일 밤 10시 14분에 유나가 빠졌다  · 「ㅇㅋ」가 17개였다  · 10분 뒤 담임
[진실 카드] 🗝 봉인 / 열람
[열려 있는 것]  · 유나가 하은에게 먼저 말을 거는가  · 「ㅇㅋ」 누른 사람으로서 하은이 무엇을 하는가  · 담임 전에 지호 이름이 나오는가
[결론 방향] 🤐 — 상대역·조연은 이 방향으로. 마지막 컷은 네가 쓴다.
```

# 3부 — 고전 각색 대본과 🌟 명대사

> 저작권 만료 고전의 대표 씬을 **현대 각색 대본**으로 가져온다. 이미 구조가 있어 무대가 안 무너진다. 나는 **구멍 난 자리만** 채운다. 몇백 년 살아남은 씬은 뼈대가 검증된 씬 — 한 줄만 바꿔도 「내 판」이 된다.

## 10. 대본의 층

| 층 | 표시 | 뭐냐 | 기본 | 바꾸면 |
| --- | :---: | --- | --- | --- |
| 뼈대 비트 | 🧱 | 씬이 그 씬이게 하는 사건 | 🔒 잠김 | 확인 후 「원작에서 벗어나기」 |
| **명대사** | 🌟 | 모두가 아는 그 한 줄의 자리 | ⬜ **항상 숨김** | **방화벽 없음** — 씬 끝까지 흘러감 (§13) |
| 핵심 대사 | 🔑 | 씬을 돌리는 한 줄 | ⬜ 비움 | 다음 🧱까지 영향 |
| 갈림 대사 | 🔀 | 방향을 바꿀 수 있는 줄 | 보임 (난이도 따라 비움) | 다음 🧱까지 |
| 흐름 대사 | 💬 | 이어 주는 줄, 리액션 | 보임 | 그 줄만 |
| 지문·상황 | 📝 | 장소, 행동 | 보임 | 그 줄만 |

한 씬에 🌟·🔑 1~2줄, 🔀 3~5줄, 🧱 3~4개.

## 11. 보기 · 바꾸기

**보기 6가지** (언제든 전환): 📜 전체 대본 · 📝 상황만(대사 전부 숨김 = 1부 오리지널 씬처럼) · 🔑 주요 대사만(🧱+🔑+🔀) · 🎭 내 대사만 · ⬜ 빈칸만 · ⚖️ 원작 대조(비트 요약만, 🌟는 컷 뒤에만).

**바꾸기 4단계**

| 단계 | 비는 것 | 추천 |
| --- | --- | --- |
| 🟢 한 줄 | 🌟/🔑 1개 | **기본** |
| 🟡 갈림길 | 🔑 + 내 쪽 🔀 | 두 번째부터 |
| 🟠 내 판 | 주인공 대사 전부 | 연기 목표가 분명할 때 |
| ✏️ 자유 | 안 비움. 대신 **모든 줄**(상대 줄 포함) 고치기 가능 | 해 본 씬 |

- 어느 단계든 아무 줄이나 탭하면 고칠 수 있다. 단계는 「처음에 몇 개 비울까」일 뿐. (🧱만 확인 한 번)
- **변경 예산** — 🟢 1줄 · 🟡 5줄 · 🟠 주인공 줄 수. 넘으면 막지 않고 한 번만: 「한꺼번에 바꾸면 뭐 때문에 달라졌는지 흐려져.」
- 채우는 법: 🖊 쓰기 · 🎙 연기하기 · 🔁 각색 대사 보고 비틀기(🌟 제외) · 🤐 침묵(지문만).

## 12. 파급 — 한 줄을 바꾸면 어디까지

- 🔑·🔀를 바꾸면 그 뒤 줄들이 ⚠️ 영향받음. **다음 🧱까지만**(뼈대 방화벽). 그 뒤는 원래 대본이 기다린다.
- 영향받은 줄마다: 📌 그대로 / 🟡 애드립으로(기본) / 🖊 내가 고침.
- **🧲 원작 끌림** — AI 인물이 다음 뼈대로 돌아오려는 힘. 강(🟢) · 중(🟡) · 약(✏️, 🧱도 영향 → 「원작에서 벗어났어. 계속?」).
- **원본은 안 사라진다** — 줄마다 ↩️, 씬 전체 ↩️. 판본으로 쌓임. ⚖️ 바뀐 것만 보기.

## 13. 🌟 명대사 자리 — 보여주지 않고 「나였다면?」

1. **안 보여준다.** 어떤 보기·난이도에서도. 힌트도 없다. 먼저 보면 따라 하거나 피하기만 하게 된다.
2. **질문은 하나.** 상황과 바로 앞 한 줄만 주고 — 「여기가 이 작품에서 제일 유명한 한 줄이 나오는 자리야. 너였다면?」
3. **반응으로 이어진다.** 상대는 원래 대본이 아니라 **내 한 줄에** 반응한다.
4. **바뀌면 바뀐 그대로 흘러간다.** 명대사 뒤로는 방화벽이 내려간다.

   | | 🔑·🔀 | 🌟 |
   | --- | --- | --- |
   | 영향 | 다음 🧱까지 | **씬 끝까지** |
   | 🧲 끌림 | 고른 대로 | **자동 약** |
   | 뒤쪽 🧱 | 벽 | **참고 표지판** — 흘러가다 닿으면 닿는 것 |
   | 벗어날 때 | 확인 | **묻지 않음** |
   | 끝 | 각색본의 끝 | **열린 결말** |

   수위 안전장치(§19-3)는 그대로.
5. **공개는 컷 뒤.** ① 내 한 줄 → ② 그 흐름 → ③ 원작 명대사(원어 짧게 + 우리가 새로 쓴 풀이) → ④ 원작에선 그 뒤 무슨 일. 비교는 「같은 자리, 다른 길」.

**다양하게 — 가지** — 같은 자리에서 다시 들어갈 때마다 가지가 쌓인다. 두 번째부터 **결 칩**(대사 아닌 방향만): `농담으로` `질문으로` `한 단어로` `침묵으로` `반대로` `행동으로`. 가지 3개면 「가지 나란히」. 원작은 첫 가지 컷 뒤 한 번 공개, 이후 가지는 「봤음」.

## 15. 예시 — 발코니 씬, 🌟 자리에서 세 가지

```
🧱 비트1  주은은 로운이 맞은편 동에 산다는 걸 오늘 처음 알았다
🧱 비트2  둘 다 집안끼리 원수라는 걸 안다
📝        주은 폰: 「나 오늘 너한테 말 걸려고 학원 앞에서 30분 서 있었다」
🌟 주은    ⬜ ________________   ← 너였다면?
   ┄┄ 여기부터는 네 한 줄 따라 흘러가. 아래는 참고 표지판 ┄┄
🧱 (참고) 주은이 마음을 처음 입 밖에 낸다
🧱 (참고) 거실 불이 켜지고, 둘은 내일을 약속한다
```

| | 가지 1 · 농담으로 | 가지 2 · 반대로 (봤음) | 가지 3 · 침묵으로 (봤음) |
| --- | --- | --- | --- |
| 🌟 내 한 줄 | 「30분이면 우리 엄마랑 너네 엄마 둘 다 지나갔겠네」 | 「그럼 너 학원 옮겨」 | (답 안 함, 블라인드 내림) |
| 로운 첫 반응 🟡 | 「봤어. 너네 엄마가 나 쳐다봤어」 | 「…진짜로 옮기면?」 | 「알았어. 미안」 |
| 씬이 된 것 | 같은 편이 되는 씬 | 누가 떠나나의 씬 | 거절처럼 보이는 망설임 |

> 🎥 **원작과의 거리** — 제일 멀리 간 가지 2가 제일 원작 같은 말(「이름을 버려」)을 했어. 다만 원작은 진심이었고 넌 「농담인데」로 시작했어. 그 차이가 이 판이야.

# 4부 — 내 기억으로 씬 완성하기

> 시나리오는 지어내는 게 아니라 **기억에서 꺼내 씬의 모양으로 옮기는 것**부터. 기억은 **사람 말·몸·소리**를 준다(그래서 진짜 같다). 애드립은 **빈칸**을 채운다(그래서 이야기가 된다). 주연 겸 PD로 — **그때의 나를 다시 연기하고, 컷 하고, 판을 바꿔 다시.**

## 16. 다섯 걸음 (10분)

| 걸음 | 하는 것 | 디렉터 |
| --- | --- | --- |
| ① 기억 하나 | **5분짜리 한 순간** | 「제일 또렷한 장면 하나만. 길게 말 안 해도 돼.」 |
| ② 씬 헤딩 | 어디 / 언제 / 낮·밤 | 「거기 어디였어? 몇 시쯤? 밝았어?」 |
| ③ 남은 것 줍기 | 기억나는 **말**(한 글자라도) · **몸·소리** | 「누가 무슨 말 했는지 기억나? 정확히 아니어도 돼.」 |
| ④ 빈칸 표시 | 기억 안 나는 것 = 열려 있는 것 | 「그다음은 기억 안 나지? 괜찮아. 거기가 무대야.」 |
| ⑤ 무대에 | 그때의 나는 내가, 다른 사람은 애드립 | 「카드 만들었어. 틀린 데 고쳐. 네 기억이니까.」 |

- **기억 씨앗 칩** — 「기억 하나 말해 봐」가 부담이면: `체육대회` `급식실 자리` `수행평가 발표` `단톡방` `버스 정류장` `명절` `전학 온 날` `졸업식`
- 줄마다 표시: ⚪ 기억 · 🟡 애드립 · 🖊 지금.
- **마지막 컷은 두 판** — 「그때 한 것」 / 「그때 안 한 것」. 어느 쪽이 맞다는 건 없다. **두 줄 사이가 그 씬의 진짜 내용.**
- **장르 렌즈** — 같은 기억, 고정 사실(⚪)은 그대로, 장르만 바꿔 다시. 어느 장르에서 내 기억이 제일 살아나는지.
- **하루 한 씬** — 「⚪ 기억 씬」 서랍 = 내 소재 노트. 단막극 S#1(일상)로 꺼내 쓸 수 있다.

## 17. 예시 — 계주, 바톤

> 나: 중2 체육대회. 계주 결승에서 바톤 떨어뜨림. 운동장, 오후, 더웠음. 다음 주자 지수가 「괜찮아」 했음. 바톤 떨어지는 소리. 지수가 내 쪽 안 보고 뛰어감. 그 뒤는 기억 안 남. 꼴찌.
> 🎬 거기가 무대야. 너는 「지후」, 지수는 「하윤」.

```
[고정 사실] ⚪  · 바톤이 떨어졌다 (소리)  · 하윤은 「괜찮아」 했고, 지후를 안 봤다  · 반은 꼴찌
[열려 있는 것] 🟡  · 반 자리에 돌아가서 무슨 일  · 「괜찮아」는 무슨 뜻  · 지후는 무슨 말을 했나 / 안 했나
```

> 🖊 나(지후): 「…미안.」 / **하윤:** *물 마시면서* 괜찮다니까. 🟡
> ✋ 컷 → 🔎 하윤 속마음: *사실 나도 출발 늦었는데.* 🟡 → ⏪ 비트 4부터, 🎛 하윤 솔직함 1→3 → 액션
> 🖊 나(지후): 「…미안.」 / **하윤:** *물병 내려놓고* …나도 출발 늦었어. 너만 그런 거 아냐.
> 🎬 (같은 「미안」, 다른 대답.)
> 마지막 컷 — 그때 한 것: 반 자리 맨 끝에 앉아 신발 끈만 다시 묶는다. / 그때 안 한 것: 「너 아까 나 안 봤잖아. 그거 좀 서운했어.」 **하윤:** *잠깐* …보면 너 울 것 같아서. 🟡
> ✍️ **⚪ 기억에서 온 줄** — 「바톤 소리」「안 봤다」. 이 둘이 씬을 진짜로 만들었어. 지어낸 장면엔 잘 안 나오는 것 — **소리랑 시선.**
> ✍️ **🟡 애드립에서 온 줄** — 「보면 너 울 것 같아서」. 기억엔 없지만 「안 봤다」의 뜻을 바꿔 놨어.

## 19. 안전장치

### 19-1. 이야기 (무대가 안 무너지게)
🧱 뼈대 방화벽 · 🟢 한 줄부터 · 📊 변경 예산 · 🧲 원작 끌림 · ↩️ 원본 복원 · ⚖️ 바뀐 것만 보기 · ⚠️ 개연성 경고는 막지 않음 · 🌟 명대사 숨김(컷 뒤 공개).

### 19-2. 저작권

> ⚠️ 기획 기준. 공개 전 **법률 검토** 필수. 나라마다 보호 기간·2차적 저작물 기준이 다르다.

| 원칙 | 내용 |
| --- | --- |
| 아이디어 / 표현 | 갈등의 종류·관계의 종류·장르 관습·「현대 생활의 사실」은 아이디어 → 가져옴. 제목·이름·대사·고유 설정·**사건의 구체적 순서와 조합**은 표현 → 안 가져옴 |

### 19-3. 수위 (13~18세)

| 원작에 있는 것 | 각색 원칙 |
| --- | --- |
| 죽음·자살 | **안 가져온다.** 끝·이별·단절·전학으로. 자해·자살은 암시도 안 함 |
| 결투·폭력 | 화면 밖. 「싸웠다는 걸 다음 날 안다」 수준 |
| 독·약물 | 안 가져온다 |
| 처벌·감금 | 「연락 끊김」「외출 금지」 수준 |
| 성적 묘사 | 안 가져온다. 로맨스는 마음·말까지 |
| 혐오·차별 대사 | 옮기지 않는다. 필요하면 지문으로만 |

- 15세 작품이어도 중학생 무대에서 빼는 건 뺀다. 씬·갈등마다 **수위 메모** 없으면 공개 안 함.
- 사용자가 고친 대사·주인공 입력 **매 줄** `checkSafety`. 위기 신호면 씬 멈추고 안전 흐름.
- 🧲 약 / ✏️ 자유로 원작 비극 결말 쪽으로 반복 유도 → AI는 따라가지 않고, 2회째 디렉터가 묻는다: 「이 방향, 혹시 네 얘기랑 닿아 있어? 그럼 놀이 말고 천천히 얘기해도 돼.」

### 19-4. 사람 · 개인정보
- 기억 씬은 더 조심. 디렉터는 그 기억이 어땠는지 **캐묻지 않는다.** 기억은 재료, 상담 아님. 아픈 기억이면 무대 접고 깊은 무대 문.
- **실명 저장 안 함.** 이름이 나오면 가명(자동 감지는 불확실 → 사용자가 이름을 탭해 표시 병행). 치환은 화면에 뜨기 전, 원래 이름은 세션 끝나면 버림.
- 기억 씬은 **로컬만.** 서버에 올리면 About 「기록」 약속과 함께 다시 정함.
- 실존 인물 실명·비방 안 됨. 디렉터 톤: 진실하게 말해 달라는 부탁, 친구 같은 말. 「극단적 / 던져 봐」 안 씀.

### 21-4. 핵심 함수

```ts
// 조립 → 상황 카드. 디렉터 1회 호출. 프롬프트 고정: 「실제 작품의 제목·인물·대사·고유 설정 금지. 장소·관계는 §7-3 표에서만」

// 고전 각색: 난이도별 빈칸. 🌟는 항상
function blanksFor(level: EditLevel, a: Adaptation, leadId: string): string[] {
  const mine = (l) => l.by === leadId;
  const famous = a.lines.filter((l) => l.tier === "famous").map((l) => l.id);
  const byLevel = () => {
    switch (level) {
      case "oneLine":    return a.lines.filter((l) => l.tier === "key" && mine(l)).slice(0, 1).map((l) => l.id);
      case "crossroads": return a.lines.filter((l) => (l.tier === "key" || l.tier === "pivot") && mine(l)).map((l) => l.id);
      case "myCut":      return a.lines.filter((l) => mine(l) && l.tier !== "direction").map((l) => l.id);
      case "free":       return [];
    }
  };
  return [...new Set([...famous, ...byLevel()])];
}

// 파급: 다음 🧱까지. 🌟면 씬 끝까지
function affectedBy(changed: string, a: Adaptation): string[] {
  const from = a.lines.findIndex((l) => l.id === changed);
  if (a.lines[from].tier === "famous") return a.lines.slice(from + 1).filter((l) => l.tier !== "beat").map((l) => l.id);
  const nextBeat = a.beats.findIndex((b) => b.id === a.lines[from].beat) + 1;
  const wall = a.beats[nextBeat]?.id;
  const out: string[] = [];
  for (const l of a.lines.slice(from + 1)) {
    if (wall && l.beat === wall) break;
    if ((l.dependsOn ?? [changed]).includes(changed) && l.tier !== "direction") out.push(l.id);
  }
  return out;
}
```

| 최신 작품과 닮음 | 세 층 + 테스트 + 출처 미표시 + 법률 검토 |

## 24. MVP

1. 장르 3개 화면(추리만 열림)
2. 추리 씬 1개 — 사라진 학급비(§2)
3. 조립 흐름 1개 — 갈등 3개(1 배신 · 2 단톡 빼기 · 4 들킨 마음) × 각도 × 결론 방향만 (인트로·본론은 기본값)
4. 기억 씬 흐름 1개 — 다섯 걸음 + 씨앗 칩 + 청춘물 렌즈 하나
5. 🎭/🎛 전환 · 연기 목표 · 콘솔: 🔥🎭 다이얼, 귓속말, 돌발, 다시 찍기 · 🟡 보드(무르기)
6. 고전 각색 2개(발코니 · 시라노) — **🌟 자리 · 결 칩 · 가지 나란히** + 보기 3(전체·상황만·주요 대사만) + 난이도 2(한 줄·자유) + 방화벽 + 바뀐 것만 보기
7. 작가실 5장 — 살아 있는 데 · 드라마 냄새 · 아는 것과 연기한 것 · 🪞 씬 대조 · 한 컷 더

**MVP로 확인할 것** — ① 컷을 누르나 ② 다시 찍기에서 같은 대사를 다시 치나(「같은 말, 다른 반응」이 먹히나) ③ 기억 씬을 끝까지 가나 ④ 🌟 자리에서 가지를 2개 이상 내나.

## 25. 정해진 것 / 남은 것

**정해진 것**
- 방 = 씬 하나. 작가는 상황 카드만(대사 0줄, 고정 사실 3개 안팎, 열려 있는 것).
- 기본은 **주연 겸 PD.** 🎭 액션 / 🎛 PD 화면 분리. 주인공은 연기 목표. PD는 고정 사실·진실·다른 인물 대사를 못 건드림. 누설은 막지 않고 작가실이 짚음.
- **원천은 세 층** — 뼈대 고전, 공기 최신(종류만), 세부 고전. 씬 하나 단위. 출처는 내부 로그에만. 테스트: 고전은 알아봐도, 최신은 못 알아봐야.
- 갈등 20개, 전부 고전 뿌리 2개 이상, 중학생 자리. 괴롭힘은 목격자만. 조립 6단계, 결론은 방향만, 마지막 컷은 내가.
- 고전 각색: 층 5개, 보기 6, 난이도 4, 방화벽, 원본 복원. **🌟 명대사는 안 보여주고 「나였다면?」, 그 뒤는 방화벽 없이 흘러감, 가지 쌓임, 컷 뒤 공개.**
- 기억 씬: 다섯 걸음, ⚪🟡🖊, 두 판 마지막 컷, 장르 렌즈. 실명 저장 안 함, 로컬만.
- 작가실에 🪞 씬 대조 추가. 수위: 죽음·폭력·자해 안 가져옴. 매 줄 `checkSafety`.

**남은 것**
1. 갈등 20의 원천 로그 채우기 — 고전 뿌리 요약 새로 쓰기 + 최신 확인 3개 + 세 층 테스트 기록
2. 「15세」 표시 없는 웹툰·연극 기준 (플랫폼 연령 / 자체 판단)
3. 첫 고전 각색 세트(발코니·시라노·인형의 집·흥부·라 보엠) 제작 — AI 초안 + 내부 검수 vs 작가 섭외
4. 🪞 씬 대조가 교훈처럼 안 들리게 — 디렉터 톤 안에서 문장 샘플 20개
5. 🟡 새 사실이 다음 씬(단막극·연속극)으로 넘어갈 때 전부 / PD가 고른 것만
6. AI 인물 상한 3명, 그 이상 엑스트라(지문만) — 확정 여부
7. 상대 대사 TTS 기본 on/off · 모바일 다이얼 노출 수
8. 상대 🔀 줄을 비웠을 때 기본: AI 애드립 vs 내가 쓰기
9. 「원작에서 벗어난 판」을 오리지널 씬으로 저장(졸업) 여부
10. 중학생 재료표(§7-3) 실제 중학생 확인 — 「요즘 그런 말 안 써」 걸러내기
11. **법률 검토** — §19-2 전체, 특히 「세 층 + 씬 하나 + 고전 뿌리」 논리의 실무 범위. UGC 열 때 검수 흐름
