# 마음무대(MindStage) — 부딪힘과 나의 답안

> **2026-10-12 초안** — About 페이지에 새 스테이지를 하나 더하기 위한 기획 메모.
> 새 엔진을 만드는 게 아니라, 이미 있는 **3막 · 마주침 → 4막 · 거울 → 5막 · 리플레이**를
> "사람과 감정으로 부딪히고, 다름을 알아보고, 내 방식으로 풀어보는" 흐름으로 다시 읽어주는 것.
> 관련 구현: [frontend/lib/stage.ts](../frontend/lib/stage.ts) (`meet` · `mirror` · `replay` 막),
> [frontend/app/about/page.tsx](../frontend/app/about/page.tsx) (About 스테이지 구성).

## 1. 왜 이 스테이지가 필요한가

About 01 「질문」은 *말을 꺼내는 게 어렵다*는 데서 멈춰 있다.
그런데 청소년이 진짜 막히는 자리는 그다음이다.

- 친구, 부모, 선생님과 **감정이 부딪히는 순간** — 그 자리에서 뭘 해야 하는지 아직 해본 적이 없다.
- 그래서 대부분 **삼키거나(참기) / 터뜨리거나(폭발) / 피한다(읽씹·자리 뜨기)**.
- 어른들이 주는 답은 늘 모범답안이다. 「대화로 풀어」「상대 입장도 생각해」「먼저 사과해」.
  맞는 말이지만 *내 몸으로는 안 되는* 답이다.

> 핵심 문장: **"말을 못 하는 게 아니라, 아직 해본 적이 없는 거야."**

무대는 그 "해본 적"을 만들어주는 곳이다. 현실에서 처음 해보면 너무 비싸니까,
네가 만든 캐릭터가 먼저 부딪혀 보고, 그걸 보면서 배운다.

## 2. 기존 틀 위에 얹는 방식 (새 막을 만들지 않는다)

| 기존 막 | 지금 하는 일 | 이 문서에서 강조하는 것 |
| --- | --- | --- |
| **3막 · 마주침** (`meet`) | 사람이 있는 장면을 세운다. 상대는 악역이 아니다 | **부딪히기** — 그 장면에서 올라온 감정을 정리하지 말고 그대로 꺼낸다. 화, 서운함, 억울함 다 무대 위에선 괜찮다 |
| ↳ 렌즈 `guess` | 상대는 그때 무슨 생각이었을 것 같은지 | **다름 알아보기** — 상대 자리에 잠깐 서본다. 이해해주라는 게 아니라 *다르다는 걸 보는 것* |
| ↳ 렌즈 `inner` | 겉으로 한 것과 속으로 한 말의 차이 | 내 안에서도 겉과 속이 부딪힌다는 걸 본다 |
| **4막 · 거울** (`mirror`) | 내 말만 모아 3인칭으로 되읽기 | 부딪힘에서 **내가 늘 하는 방식**(삼키기·터뜨리기·피하기·맞춰주기…)을 내 말로 이름 붙인다 |
| **5막 · 리플레이** (`replay`) | 같은 장면, 다른 선택. 출구 넷 | **나의 답안 써보기** — 모범답안 말고, 내가 실제로 할 수 있는 한 줄. 상대는 현실적으로 반응한다 |
| **커튼콜** | 두 문장 나란히 | 원래 방식 옆에 *나의 답안*을 둔다. 고치는 게 아니라 옆에 두는 것 |

엔진 변경은 거의 필요 없다. 필요하다면:
- `meet.intent`에 "감정을 정리하거나 순화하지 마라. 유저가 고른 감정 단어 그대로 무대에 올려라" 한 줄 추가
- `replay.intent`에 "유저가 쓴 답이 서툴러도 고쳐주지 마라. 모범답안을 제시하지 마라" 한 줄 추가
- (선택) `meet`에 렌즈 `switch` — "상대 자리에 서서 한마디 해본다면" (역할 바꾸기)

## 3. 세 단계 — 부딪히고, 다름을 보고, 내 답을 쓴다

### ① 부딪히기 — 감정은 무대 위에서 먼저 싸워본다

- 무대 위에서는 화내도 된다. 서운하다고 말해도 되고, 억울하다고 해도 된다.
- 디렉터는 그 감정을 **좋은 말로 바꿔주지 않는다.** 「짜증」을 「속상함」으로 순화하지 않는다.
- 감정은 공격이 아니라 **정보**다. "이게 나한테 중요했구나"를 알려주는 신호.
- 대사는 요약하지 않고 그대로 — 상대가 한 제일 아픈 한마디, 내가 실제로 한 말.

> 디렉터: 「그때 속에서 올라온 말, 정리 안 해도 돼. 날것 그대로 한 번 해봐. 무대니까 괜찮아.」

### ② 다름을 보기 — 상대 자리에 잠깐 서본다

- 사이코드라마의 **역할 바꾸기**. 상대 자리에 서서, 상대 목소리로 한마디.
- 목표는 「상대도 사정이 있었네, 내가 참아야지」가 **아니다.**
  목표는 **"저 사람은 나랑 다르게 보고 있었구나"** 를 아는 것.
- 다름을 안다고 내 감정이 틀린 게 되는 건 아니다. 둘 다 진짜다.
- 상대 자리에 서기 싫으면 안 서도 된다. 「모르겠어」도 답이다.

> 디렉터: 「잠깐만 그 애 자리에 서볼래? 그 애 눈엔 이 장면이 어떻게 보였을 것 같아. 싫으면 패스해도 돼.」

### ③ 나의 답안 쓰기 — 모범답안 말고, 내가 할 수 있는 한 줄

- 리플레이에서 같은 장면을 다시 세운다. 상대는 **똑같은 말**을 한다.
- 이번엔 내가 고른 방식으로 받는다. 기존 출구 넷이 그대로 선택지다:
  - 🗣 **말로 받기** — 짧아도 된다. 「그 말 좀 아팠어」 한 줄이면 충분
  - 🚪 **자리 뜨기** — 피하는 게 아니라 *지금은 아니라고 내가 정하는 것*
  - 🌀 **비틀기** — 농담, 질문, 전혀 다른 반응
  - 🔁 **원래 하던 거, 근데 이번엔 알고** — 참는 것도 내가 골랐다면 선택이다
- 상대는 **현실적으로** 반응한다. 갑자기 사과하거나 착해지지 않는다.
- 그러고 묻는다: **"상황은 그대로인데, 네 안에서는 뭐가 달라졌어?"**

> 너: 「똑같이 참았는데, 이번엔 내가 참기로 한 거라서 덜 억울해.」

## 4. 모범답안 vs 나의 답안

About 페이지에서 비교 표(`ab-vs`)로 쓰기 좋은 형태.

| 모범답안 | 나의 답안 |
| --- | --- |
| 「대화로 풀어야지」 | 지금 내가 할 수 있는 말 한 줄. 한 단어여도 됨 |
| 「상대 입장도 생각해봐」 | 상대가 다르게 봤다는 걸 알되, 내 감정도 그대로 둔다 |
| 「먼저 사과하는 게 어른스러운 거야」 | 사과할지 말지는 내가 정한다 |
| 「화내면 지는 거야」 | 화는 "이게 중요했다"는 신호. 무대에선 꺼내봐도 된다 |
| 정답이 하나 있다 | 답은 사람마다, 그날마다 다르다. 오늘의 내 답이 있을 뿐 |
| 잘 해결돼야 끝난다 | 상황이 안 바뀌어도, 내 안에서 뭔가 바뀌었으면 그걸로 한 판 |

디렉터가 **절대 하지 않는 것**
- 「이렇게 말하는 게 더 좋겠다」 하고 유저의 답을 다듬어주기
- 리플레이 결과를 해피엔딩으로 만들기 (사과 서비스 없음)
- 상대 편을 들어 유저 감정을 작게 만들기 (「걔도 힘들었을 거야」로 덮기)
- 어느 방식이 "더 성숙하다"고 순위 매기기

## 5. About 페이지 카피 제안

**위치 제안:** 03 「흐름」 바로 뒤에 새 스테이지 **04 · 부딪힘**. 이후 번호는 하나씩 밀림
(`INDEX = ["질문", "무대", "흐름", "부딪힘", "조종간", "약속", "안전", "기록"]`).
흐름에서 1부·2부를 본 뒤, "그래서 사람이랑 부딪히는 장면에선 이렇게 써" 로 이어지는 자리.

### 제목

> **아직 해본 적이 없는 거야,**
> **못 하는 게 아니라**

### 본문

> 친구랑, 부모님이랑, 선생님이랑 부딪히는 순간 — 그 자리에서 뭘 해야 할지 모르는 게 당연해.
> 아직 해본 적이 없으니까. 그래서 다들 삼키거나, 터지거나, 피하잖아.
> 여기선 <em>네가 만든 애가 먼저 부딪혀 봐.</em> 화내도 되고, 서운하다고 해도 돼.
> 그다음에 상대 자리에도 잠깐 서보고, 같은 장면에서 <em>네 방식</em>으로 다시 해봐.

### 세 단계 (row-item 목록)

```ts
const CLASH = [
  { em: "💥", t: "부딪히기",   d: "감정 정리 안 해도 돼. 올라온 그대로 무대에 올려" },
  { em: "🔄", t: "자리 바꾸기", d: "상대 자리에 잠깐 서봐. 이해하라는 게 아니라, 다르게 보고 있었다는 걸 보는 거야" },
  { em: "✏️", t: "나의 답 쓰기", d: "같은 말을 또 들어. 이번엔 네가 고른 방식으로 받아봐" },
];
```

### 비교 (`ab-vs` 재사용)

```ts
const ANSWER = {
  model: [   // h4: 「모범답안」
    "대화로 풀어",
    "상대 입장도 생각해",
    "먼저 사과하는 게 어른스러운 거야",
  ],
  mine: [    // h4: 「나의 답안」
    "지금 내가 할 수 있는 말 한 줄. 한 단어여도 돼",
    "상대가 다르게 봤다는 걸 알아도, 내 마음은 그대로 둬",
    "사과할지 말지는 네가 정해",
  ],
};
```

### 대사 예시 (bubble)

> 디렉터: 「그 애가 또 똑같은 말 해. 이번엔 어떻게 받을래? 잘 말할 필요 없어. 네 말이면 돼.」
> 너: 「…그 말 좀 아팠어.」
> scene-cap: *걔는 그냥 "아 그래?" 하고 넘어감. 근데 이번엔 손이 안 떨렸어.*

### 노트

> 💬 여기엔 정답이 없어. 오늘 네가 쓴 답이 서툴러도, 그게 오늘의 네 답이야.
> 다음 판엔 또 다를 수 있고, 그것도 괜찮아.

## 6. 톤 체크리스트

- [ ] 진실하게 말해달라고 *부탁하는* 톤인가 (「솔직하게 말해줘도 괜찮아」)
- [ ] 「극단적으로」「던진다」 같은 도발적 프레임이 없는가 → 「세운다」「상황에 있다」
- [ ] 「싸운다」는 **감정을 꺼내 부딪혀본다**는 뜻으로만 쓰였는가 (상대를 공격하라는 뜻 아님)
- [ ] 친구 같은 반말, 13~18세가 바로 이해하는 단어인가
- [ ] 어디에도 "이게 정답"이라는 문장이 없는가
- [ ] 상대를 악역으로 만들지 않으면서, 유저 감정도 작게 만들지 않는가
- [ ] 위험 신호가 보이면 무대를 멈춘다는 06 안전 원칙과 충돌하지 않는가
