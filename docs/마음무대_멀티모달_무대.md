## 0. 한 줄 결론

**감각은 늘리되, 기계가 마음을 "읽는" 쪽이 아니라 사용자가 마음을 "더 보여줄 수 있게" 하는 쪽으로 간다.**

우선순위: **목소리 → 몸(카메라 없이) → 그림·타로 → 영상 → 컴퓨터 비전(조건부)**

실제 무대의 디렉터가 하는 일은 두 가지다.
1. **보고 판단한다** — 몸짓, 눈짓, 목소리 떨림
2. **몸을 움직이게 해서 감정을 깨운다** — 일어나 봐, 그 자리에 서 봐, 직접 말해 봐

채팅이 약한 건 1보다 **2**다. 그리고 2는 카메라 없이도 대부분 할 수 있다.
1은 기계가 대신하면 틀리기 쉽고, 청소년에게 「감시당한다」는 느낌을 줄 수 있다.

## 0-1. 왜 앱인가 — 실제 무대를 대신하려고

가장 좋은 건 실제 사이코드라마 무대다. 하지만 현실의 벽이 있다.

| 실제 무대 | 앱 무대 |
| --- | --- |
| 한 번에 **2시간** 정도 | 한 판 **25분쯤**, 하루 횟수 제한 |
| 인원 **20명** 안팎으로 제한 | 혼자, 언제든, 몇 명이든 |
| 디렉터·참여자 모두 **엄청난 에너지** | 에너지가 필요한 역할(상대역, 연출)을 앱이 나눠 든다 |
| 정해진 날, 정해진 장소 | 밤 11시 내 방, 그 일이 막 일어난 직후 |

그래서 이 앱의 목표는 「실제 무대 전 리허설」이 아니라 **실제 무대에 갈 수 없는 사람에게 무대를 가져다주는 것**이다.
그러려면 사이코드라마 무대를 이루는 역할을 하나씩 앱 안에 세워야 한다.

| 실제 무대의 역할 | 하는 일 | 앱에서 맡는 것 |
| --- | --- | --- |
| **주인공** | 자기 이야기를 무대에 올린다 | 사용자 — 단, 자기가 만든 캐릭터를 대신 세운다 |
| **디렉터** | 장면을 세우고, 보고, 이끌고, 확인한다 | AI 디렉터 + 감각 도구(목소리·몸 지시·그림)로 「보는 눈」을 보완 |
| **보조자아** (상대역·대역) | 상대 역을 연기하고, 속마음을 대신 말해준다 | 🔊 상대역 목소리 · 디렉터의 대역 대사(「혹시 속으로 이런 말 했어?」) |
| **무대** | 몸이 들어가는 공간 | 🖼 장면 그림 + 🪑 실제 방 안의 의자·자리 |
| **워밍업** | 몸과 마음을 푸는 시간 | 🃏 접수 · 카드 뽑기 |
| **나누기** (쉐어링) | 관객이 「나도 그랬어」를 나눈다 | 커튼콜 — 혼자라 약하다. 나중에 익명 「나도 그랬어」 카드 같은 방식을 검토 |

앱이 **실제 무대를 100% 대신할 수는 없다.** 특히 사람 눈으로 보는 판단과 관객의 나눔은 약하다.
그래서 이 문서는 「채팅 → 감각」으로 넓혀서 그 빈자리를 최대한 메우는 방법을 다룬다.
그리고 앱이 감당 못 할 신호가 보이면 사람에게 연결하는 길(06 안전)은 늘 열어 둔다.

## 1. 원칙 — 감각을 늘릴 때 지킬 것

| 원칙 | 뜻 |
| --- | --- |
| **판정하지 않는다** | 신호(목소리가 작아짐, 고개 숙임)를 봐도 「너 지금 슬프구나」라고 말하지 않는다. 신호는 **확인 질문**의 계기로만 쓴다 |
| **내가 켜고 끈다** | 마이크·카메라·소리는 전부 기본 꺼짐. 언제든 끌 수 있고, 꺼도 무대는 똑같이 흘러간다 |
| **영상은 기기 밖으로 안 나간다** | 카메라를 쓴다면 브라우저 안에서만 처리하고, 프레임은 저장도 전송도 하지 않는다 |
| **감각은 감정으로 가는 다리** | 기능을 위한 기능이 아니라, 생각에서 감정으로 넘어가게 돕는 도구일 때만 쓴다 |
| **멈출 계단이 같이 있다** | 감각이 세질수록 감정도 세진다. 「잠깐 멈출래」와 그라운딩을 늘 가까이에 둔다 |

## 2. 모달별 검토

### 2-1. 🎙 목소리 — 제일 먼저, 제일 크게

**이미 있음:** 말로 입력(Whisper STT → 브라우저 내장으로 대체), 디렉터 목소리(TTS).
지금은 「타이핑 대신 말로」 정도다. 이걸 **무대 연출 도구**로 키운다.

| 기능 | 무대에서 하는 일 | 왜 감정으로 가나 |
| --- | --- | --- |
| **소리 내서 대사하기** | 3막·리플레이에서 「이번엔 그 말 소리 내서 해봐」. 입력창이 말풍선 모양 대사 모드로 바뀌고 마이크가 먼저 켜진다 | 글로 쓰면 고치고 다듬는다. 소리로 내면 다듬을 틈이 없다. 목소리가 먼저 떨린다 |
| **상대역 목소리** | 3막에서 상대의 「제일 아픈 한마디」를 **디렉터와 다른 목소리**로 들려준다 | 읽는 것과 듣는 것은 다르다. 상대가 진짜 그 자리에 서 있게 된다 |
| **리플레이 = 같은 말, 같은 목소리** | 5막에서 상대가 **똑같은 목소리로 똑같은 말**을 한 번 더 한다. 그리고 내가 소리 내서 받는다 | 「같은 자리, 다른 선택」이 몸으로 느껴진다 |
| **내 목소리 다시 듣기** | 커튼콜에서 원래 대사와 리플레이 대사를 내 목소리로 나란히 들려준다 (기기 안에만 저장, 본인이 선택할 때만) | 거울 기법의 소리 버전. 「똑같은 말인데 목소리가 달라」를 스스로 듣는다 |
| **목소리 신호 (기기 안)** | Web Audio로 **크기·말 빠르기·침묵 길이**만 잰다. 감정 이름은 붙이지 않는다 | 목소리가 갑자기 작아지거나 오래 멈추면 디렉터가 속도를 늦추고 묻는다: 「여기 좀 무거워? 쉬어가도 돼」 |

**상대역 목소리의 주의점**
- 상대를 악역처럼 연기하지 않는다. TTS 지시문은 「담담하게, 과장 없이, 실제 그 말 그대로」.
- 위기 신호 문장은 소리로 재생하지 않는다 (지금 TTS 라우트의 `checkSafety` 그대로 유지).
- 상대 목소리가 너무 세게 느껴지면 바로 끌 수 있는 버튼: 「글로만 볼래」.

**2단계 — 실시간 음성 대화**
전부 말로만 진행하는 「목소리 무대」 모드(실시간 음성 API). 끼어들기, 말 끊김, 숨소리까지 무대가 된다.
비용과 지연이 크고 안전 필터를 실시간으로 걸어야 해서, 1단계 효과를 본 뒤에 결정한다.

> ⚠️ **About 07 「기록」과 맞추기** — 지금도 STT·TTS는 오디오/텍스트를 외부 API로 보내서 바로 버린다.
> 「이 폰 밖으로 안 나가」 문구를 「저장하지 않아. 말로 할 땐 글자로 바꾸려고 잠깐 보냈다가 바로 버려」처럼
> 정확하게 고칠 필요가 있다. 목소리 기능을 키우기 전에 먼저 정리할 것.

### 2-2. 🪑 몸 — 카메라 없이 몸을 무대에 올리기

사이코드라마의 힘은 「말하기」가 아니라 **「움직이기」**에서 나온다. 화면을 보는 것 말고, 실제 방 안에서 몸을 쓰게 한다.

| 기법 | 지시 예시 | 기존 막 |
| --- | --- | --- |
| **빈 의자** | 「폰을 앞에 있는 의자나 책상에 세워 둬. 거기 그 애가 앉아 있다고 치고, 폰한테 말해봐.」 | 3막 · 마주침 |
| **자리 바꾸기** | 「이제 일어나서 맞은편으로 가 앉아. 거기서 폰을 다시 들어. 지금부터 넌 그 애야.」 (화면은 `swapped` 장면으로 바뀜) | 3막 `guess` 렌즈 |
| **거리 놓기** | 장면 그림에서 상대 캐릭터를 드래그로 가깝게·멀리 놓기. 리플레이 뒤에 한 번 더 | 3막 → 5막 |
| **몸 먼저 묻기** | 「그 말 들으면 몸 어디가 먼저 반응해? 거기 손 한번 올려봐.」 | 2막 · 안쪽 |
| **내려오기** | 리플레이가 끝나면 「다시 원래 자리로 와. 어깨 한 번 털고.」 — 역할에서 빠져나오는 의식 | 4막 · 거울 직전 |

- 전부 **권유**다. 「지금 그럴 상황 아니야(교실, 버스)」 버튼을 늘 같이 둔다 → 그러면 화면 안 버전(드래그, 탭)으로 진행.
- 「역할에서 내려오기」는 꼭 넣는다. 상대 역을 해본 뒤 그 감정을 들고 나가지 않게.

### 2-3. 🃏 그림·타로 — 생각을 건너뛰는 지름길

그림은 분석보다 먼저 감정에 닿는다. **내 얘기가 아니라 「저 그림 속 애」 얘기**라서 방어도 내려간다.

| 기능 | 하는 일 |
| --- | --- |
| **카드 다시 보기** | 생각으로 엉키면 오늘 뽑은 카드를 크게 다시 띄운다. 「카드 속 저 애 표정 봐. 지금 무슨 마음일 것 같아?」 |
| **카드 속으로 들어가기** | 「저 그림 안에 네가 만든 애가 들어간다면, 어디쯤 서 있을까?」 — 카드를 무대 배경으로 쓴다 |
| **감정 그림 고르기** | 단어 대신 그림 여러 장(날씨, 풍경, 표정 없는 실루엣) 중에 「지금 마음이랑 비슷한 거」를 고르기. 고른 뒤에야 「왜 이거야?」 |
| **장면 그림 키우기** | 지금 `StageScene`(배경·조명·표정)을 더 세밀하게 — 사용자가 말한 장소·시간·조명을 그대로 그려서 「이 장면 맞아?」 하고 확인 |
| **생성 이미지 (2~3단계)** | 사용자가 말한 장면을 일러스트로 그려준다. **실사 금지, 인물 얼굴 특정 금지**, 일러스트 톤 고정. 실제 사람(친구·부모)을 닮게 그리지 않는다 |

- 타로는 계속 **말문 여는 소품**이다. 카드 뜻을 풀어주는 순간 점이 된다. 그림만 보여주고 의미는 사용자가 붙인다.
- 감정 그림 고르기는 현재 감정 팔레트([components/EmotionPalette.tsx](../frontend/components/EmotionPalette.tsx))의 그림 버전으로 붙이면 자연스럽다.

### 2-4. 🎞 영상 — 분위기까지만

| 쓰는 곳 | 안 쓰는 곳 |
| --- | --- |
| 막 바뀔 때 짧은 무드 루프 (비 오는 창, 복도 조명, 막이 오르는 커튼) | 실사 인물이 나오는 영상 |
| 커튼콜에서 오늘 장면 그림들을 이어 붙인 짧은 「예고편」 | 상대 역을 영상으로 연기하는 것 (너무 세고, 실제 사람처럼 느껴짐) |
| 그라운딩 때 천천히 움직이는 배경(숨 맞추기 원) | 생성 영상 실시간 제작 (비용·지연 대비 효과 낮음) |

영상은 **조명 역할**이다. 이야기를 끌고 가는 건 목소리와 몸이다.

### 2-5. 📷 컴퓨터 비전 — 가능하지만, 조건이 많다

**기술적으로 되는 것** (브라우저 안에서, 서버로 안 보내고)
- 얼굴·몸 랜드마크 추적 (예: MediaPipe 계열) → 시선이 화면 밖으로 감, 고개 숙임, 얼굴을 손으로 가림, 움직임이 멈춤, 자세가 확 바뀜
- 「일어나서 맞은편으로 가 앉아」 같은 몸 지시를 **실제로 했는지** 확인

**하지 않을 것**
- **감정 판정** (「슬픔 72%」). 표정으로 감정을 맞히는 건 정확도가 낮고 사람마다·문화마다 다르다.
  틀린 판정은 「나도 모르는 내 마음을 기계가 정한다」가 되고, 모범답안보다 더 나쁜 답이 된다.
- 판정을 사용자에게 말하기, 기록하기, 커튼콜에 넣기.

**쓴다면 이렇게 — 「셀프 거울」 모드**
기계가 나를 보는 게 아니라 **내가 나를 보는** 진짜 거울로 쓴다.
- 리플레이에서 대사를 소리 내서 할 때, 화면 구석에 내 얼굴이 작게 보인다 (녹화 없음).
- 끝나고 디렉터가 묻는다: 「방금 그 말 할 때 네 얼굴 봤어? 어땠어?」 — 판단은 사용자가 한다.
- 랜드마크 신호(고개 숙임, 시선 이탈 지속)는 「속도 늦추기 + 확인 질문」에만 쓴다.

**지켜야 할 조건**
- 기본 꺼짐. 켜져 있는 동안 화면에 늘 표시. 한 번 탭으로 끄기.
- 프레임 저장·전송 없음. 수치 신호도 세션이 끝나면 버림.
- 법정대리인 동의: 만 14세 미만은 개인정보 처리에 법정대리인 동의가 필요하다(개인정보보호법). 얼굴 영상은 특히 민감하게 다뤄야 한다.
- 학교·기관에서 단체로 쓰는 경우엔 카메라 기능을 끈다. (예: EU AI Act는 교육 기관에서의 감정 인식 시스템을 금지하고 있다 — 해외 확장 시 참고)
- 출시 전에 법률 검토를 받는다.

> 정리: 컴퓨터 비전은 **「기계의 눈」이 아니라 「사용자의 거울」**일 때만 쓴다. 3단계, 검증 후.

## 3. 생각 → 감정으로 돌아오는 도구 모음

「한번 생각으로 가면 감정으로 이끌기 힘들다」에 대한 모달별 처방.

| 이럴 때 | 디렉터가 꺼내는 것 | 예시 |
| --- | --- | --- |
| 설명이 길어지고 「~것 같아」가 늘어남 | 🎙 소리 내서 대사 | 「설명 말고, 그 애한테 직접 한마디. 소리 내서.」 |
| 「왜냐하면」으로 분석을 시작함 | 🃏 카드 다시 보기 | 「잠깐, 카드 다시 봐. 저 애 표정 어때?」 |
| 단어가 안 나옴, 「몰라」 반복 | 🖼 감정 그림 고르기 | 「말 말고 그림으로. 지금이랑 비슷한 거 하나만.」 |
| 상대 얘기만 하고 내 얘긴 안 함 | 🪑 빈 의자 | 「폰 세워두고, 그 애한테 말해봐. 걔 얘기 말고 걔한테.」 |
| 상대를 이해 못 하겠다고 함 | 🪑 자리 바꾸기 + 🔊 상대 목소리 | 「맞은편 가서 앉아봐. 이제 네가 그 애야. 방금 그 말 다시 들어봐.」 |
| 너무 깊이 들어가서 흔들림 | 🫧 그라운딩 + 🎞 숨 맞추기 영상 | 「무대는 그대로 있어. 먼저 지금 방으로 돌아오자.」 |
| 생각하는 게 오히려 편해 보임 | (아무것도 안 꺼냄) | 「머리가 먼저 나섰네. 괜찮아. 조금만 장면으로 가볼까, 여기서 쉬어갈까?」 |

마지막 줄이 중요하다. **생각으로 가는 것도 마음을 지키는 방법**이다. 억지로 끌고 가지 않는다.

## 4. 한 장면 예시 — 3막에서 리플레이까지

> 상황: 단톡방에서 친구 「지우」가 「너는 원래 그렇잖아ㅋㅋ」라고 보냈다. 사용자가 만든 캐릭터는 「수민」.

1. **🖼 장면 세우기** — 디렉터가 말한 그대로 그린다: 밤 11시, 방, 불 꺼짐, 폰 화면만 밝음. 「이 장면 맞아?」 → 사용자: 「스탠드 켜져 있었어」 → 고쳐 그림.
2. **🔊 상대 목소리** — 지우 목소리로 담담하게: 「너는 원래 그렇잖아ㅋㅋ」
3. **🎙 소리 내서** — 「수민이 그때 실제로 뭐라고 쳤는지, 소리 내서 읽어봐.」 → 「ㅋㅋ 그치」
4. **🪑 몸 먼저** — 「그 말 들으면 몸 어디가 먼저 반응해?」 → 「목」 → 「거기 손 한 번 올려봐.」
5. **🪑 자리 바꾸기** — 「맞은편 가서 앉아봐. 이제 네가 지우야. 지우는 그 말 왜 보냈을까? 지우 목소리로.」 → 「그냥… 장난이었는데」 → 「다시 원래 자리로. 어깨 한 번 털고.」
6. **🪞 거울** — 사용자 말만으로 되읽기. 「수민은 아픈 말이 오면 ㅋㅋ로 받는다.」
7. **⏪ 리플레이** — 지우 목소리로 **똑같은 말**. 이번엔 수민이 소리 내서: 「…그 말은 좀 별로야.」
8. **🔊 상대는 현실적으로** — 「아 뭐야 진지하네ㅋㅋ」 (사과 서비스 없음)
9. **질문** — 「상황은 그대로인데, 수민 안에서는 뭐가 달라졌어?」 → 「목이 안 조여.」
10. **👏 커튼콜** — 두 대사를 내 목소리로 나란히 듣기 (원하면). 「ㅋㅋ 그치」 / 「그 말은 좀 별로야」

카메라는 한 번도 안 썼다. 그래도 몸, 목소리, 그림이 다 무대 위에 있었다.

## 6. About 페이지에 쓸 수 있는 카피

> **글로만 하는 무대 아니야**
> 말로 해도 되고, 소리 내서 대사해도 돼. 폰을 의자에 세워두고 그 애한테 말해봐도 되고,
> 일어나서 맞은편에 앉아 그 애가 돼봐도 돼. 카드 그림 보고 떠오르는 걸로 가도 되고.
> 마이크도, 소리도 전부 네가 켜고 꺼. 꺼도 무대는 똑같이 흘러가.

> **나만의 무대, 나만의 방식으로**
> 쓰는 게 편하면 쓰고, 말하는 게 편하면 말하고, 몸이 먼저 움직이면 몸으로.
> 어떤 방식이 정답인 건 없어. 오늘 네가 마음껏 부딪혀 볼 수 있는 방식이면 그게 맞아.

## 7. 정해야 할 것

1. 상대역 목소리를 **고를 수 있게** 할까? (성별·나이대 느낌) — 실제 인물을 너무 닮으면 세질 수 있음
2. 「소리 내서」를 기본으로 권할까, 버튼으로만 둘까? — 공공장소 사용 비율에 따라
3. 내 목소리 녹음을 기기에 남길까? 남긴다면 몇 판까지?
4. 카메라(셀프 거울)를 로드맵에 계속 둘까, 아예 빼고 「몸 지시」로만 갈까?
5. 실시간 음성 무대를 할 거라면, 위기 신호 감지를 실시간으로 어떻게 걸까?
