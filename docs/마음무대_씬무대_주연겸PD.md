# 마음무대 — 씬 무대 (주연 겸 PD) · 최종본

> ⚠️ **통합 최종본은 [마음무대_씬무대_최종.md](마음무대_씬무대_최종.md).** 이 파일은 1~3부가 순서대로 쌓인 작업본(원천 규칙 §31→§39→§40→§41 진화 과정 포함). 읽을 때는 통합본을 보고, 이 파일은 근거·예시 원문 참고용으로 둔다.

> - **2026-10-12 최종본.** [마음무대_열린결말_방탈출.md](마음무대_열린결말_방탈출.md) 4부(§30~§40)를 바탕으로, **「주연 겸 PD」**를 기본 모드로 다시 정리한 문서.
> - 방 하나 = **드라마의 씬(S#) 하나.** 작가가 써 둔 건 **상황뿐**, 대사는 0줄. 인물들은 **애드립**으로 산다.
> - 나는 **주인공을 연기하는 배우**이면서, 컷을 외치면 판을 바꾸는 **PD**다.
> - **원작 씬 각색 (2부, §20~):** 저작권 만료 고전의 대표 씬을 **현대로 각색한 대본**으로 가져온다. 뼈대는 그대로, **핵심 대사·갈림 대사만 비워서** 내 스타일로 끌고 간다. 🌟 명대사는 안 보여주고 「나였다면?」.
> - **갈등 원천 (3부, §31~):** 씬 하나를 **세 층**으로 만든다(§41) — 🏛 뼈대는 저작권 없는 고전, 🎬 공기(상황의 종류·장소의 현대성·매체·속도)는 **최근 3년 · 15세** 작품, 🏛 세부(원하는 것·숨기는 것·상징·결말 방향)는 다시 고전. 명대사 없이, **우리나라 중학생 처지**로 재구성한다. 장르 × 갈등 20 × 각도 × 인트로 × 본론 × 결론을 골라 내 작품을 조립하고, 주인공이 되어 반응한다.
> - 이 무대로 하는 연습 하나 — **「내 기억으로 씬 완성하기」**

## 0. 한 줄

**「무대는 세워 놨어. 대사는 없어. 네가 주인공으로 들어가고, 판이 마음에 안 들면 컷 외쳐.」**

원작 씬일 때: **「이 씬, 몇백 년 된 거 요즘으로 옮겨 놨어. 뼈대는 그대로야. 제일 중요한 한 줄만 비워 뒀어 — 네 말로 채워 봐.」**

## 1. 핵심 아홉 가지

| | 내용 |
| --- | --- |
| 🎬 **방 = 씬** | 방 하나는 S# 한 줄짜리 씬 하나. 어디, 언제, 누가, 방금 무슨 일이 있었나 |
| 📄 **상황만 있다** | 오리지널 씬: 작가는 상황 카드만 쓴다. 대사 0줄. 고정 사실 3개 안팎 + 「열려 있는 것」 |
| 🎭 **원작 씬 각색** | 영화·연극·뮤지컬 씬을 현대 대본으로. **🔑 핵심 · 🔀 갈림 대사만 비우고** 나머진 그대로 — 내가 바꾸는 만큼만 바뀐다 (§20~) |
| 🧩 **내 작품 조립** | 최근 작품에서 **구조만** 걸러낸 갈등 20개. 장르 × 갈등 × 각도 × 인트로 × 본론 × 결론을 고르면 중학생 처지의 상황 카드가 선다 (§31~) |
| 🛡 **안전장치** | 🧱 뼈대 방화벽 · 변경 예산 · 원본 복원 · 저작권 · 수위 · `checkSafety` (§25, §35) |
| 🎞 **장르 먼저** | 들어가기 전에 장르를 고른다. 장르는 분위기가 아니라 **그 장르가 돌아가는 규칙** |
| 🎭 **나는 주연** | 주인공 한 명은 내가 연기한다. 다른 인물들이 **나한테 반응**한다 |
| 🎛 **나는 PD** | 「컷」 하면 씬이 멈추고 PD 콘솔이 열린다. 성격 다이얼·귓속말·돌발 상황·다시 찍기 |
| 🟡 **애드립** | 인물들은 상황만 지키면 뭐든 한다. 새로 생긴 사실은 쌓이고, 그게 이 씬의 결과물 |

## 2. 기존 무대와의 관계

```
씬 방 1개            = 방탈출 한 판 (10분)       ← 잠긴 문(뻔한 결말)이 붙은 씬
씬 방 7개 이어 붙임   = 단막극 한 편 (40분)
단막극 여러 편        = 연속극
기억으로 만든 씬 방   = 기억 씬 연습 (10분)
```

| | 방탈출 (1~3부) | **씬 무대 (이 문서)** |
| --- | --- | --- |
| 입구 | 갈등 고르기 (배신, 고백…) | **장르 먼저** → 그 장르의 씬 |
| 작가가 쓴 것 | 장면 + 상대역 + 잠긴 문 | **상황 카드만** |
| 나 | 주인공을 쓰는 작가 | **주연 배우 + PD** |
| 진행 | 상대역이 반응, 내가 씀 | 내가 연기하고, 모두가 애드립으로 받는다 |
| 끝 | 마지막 컷 + 작가실 | 마지막 컷 + 작가실 + **🟡 이 씬에서 생긴 사실** |

깊은 무대와 다른 점: 깊은 무대는 **내 이야기**를 디렉터와 함께 들여다본다. 씬 무대는 **내가 세운 판에서 논다.** 놀다가 「이거 내 얘기랑 닿는데」 싶으면 깊은 무대로 건너가는 문은 늘 열려 있다.

## 3. 장르 — 그 장르가 돌아가는 규칙

장르를 고르면 상황 카드에 꼭 있어야 하는 칸이 정해진다.

| 장르 | 꼭 있어야 하는 것 | 씬 예시 |
| --- | --- | --- |
| 🔍 **추리** | 🗝 진실 카드 1장 · 단서 2~3개 · 뭔가 숨기는 인물 1명 이상 | 방과 후 교실, 학급비 봉투가 사라졌다 |
| 💘 **로맨스** | 아직 말 안 한 마음 1개 · 그걸 막는 것 1개 | 막차 정류장, 둘만 남았다 |
| 😰 **스릴러** | ⏱ 시간 제한 · 들키면 안 되는 것 | 시험지 유출 소문 돈 날 밤, 교무실 앞 |
| 🌱 **청춘물** | 오늘 안에 정해야 할 것 1개 · 친구 사이의 금 | 수학여행 버스 뒷자리 |
| 🏠 **가족극** | 매일 반복되는 자리 · 아무도 안 꺼내는 얘기 | 일요일 아침 식탁 |
| 😂 **코미디** | 오해 1개 · 혼자 진지한 인물 1명 | 조별과제 발표 5분 전, USB가 없다 |
| 🏆 **스포츠·오디션** | 하나뿐인 자리 · 남이 모르는 약점 | 계주 대기석 |
| 🌍 **SF·판타지** | 🌐 세계 규칙 1개 (절대 안 바뀜) | 매일 같은 화요일이 반복되는 교실 |

- 장르는 씬마다 하나. 섞고 싶으면 PD 콘솔의 **톤**으로 살짝 (추리인데 코미디 톤).
- 첫 공개는 **추리 · 로맨스 · 코미디** 3개 추천. 추리는 애드립이 제일 재밌고, 로맨스는 제일 많이 고르고, 코미디는 망쳐도 웃기다.

## 4. 상황 카드 — 작가가 쓴 건 이게 전부

방에 들어가면 화면 맨 위에 이 카드가 붙는다. 대본처럼 생겼지만 **대사 칸이 비어 있다.**

```
S#.  3학년 2반 교실 / 방과 후 5시 10분 / 해 질 무렵
장르: 🔍 추리

[상황]
  학급비 봉투(12만 원)가 교탁 서랍에서 사라졌다.
  반장 서연이 방금 그걸 발견했다. 교실엔 민재가 남아 있다.
  10분 뒤 담임이 걷으러 온다.

[인물]
  🎭 민재 (주인공 — 네가 연기)
     마지막까지 교실에 있던 애. 원하는 것: 빨리 가는 것. 숨기는 것: 오늘 학원을 빠졌다.
  서연 — 반장. 원하는 것: 내 책임이 아니라는 것. 숨기는 것: 아까 봉투를 교탁 위에 두고 매점에 갔다.

[고정 사실] — 누구도 못 바꿈. PD도.
  · 봉투는 5시 전까지 교탁 서랍에 있었다 (서연이 봤다)
  · 교실 창문 하나가 열려 있다
  · 10분 뒤 담임이 온다

[진실 카드] 🗝 — 작가만 앎. 봉인 / 열람 중 고른다.
  · ●●●●●●●●

[열려 있는 것] — 여기서부터 애드립 구역
  · 누가 무엇을 의심하는가
  · 둘이 서로에게 무엇을 털어놓는가
  · 담임이 오기 전에 무슨 일이 일어나는가
```

**카드 규칙**
- 작가는 **대사를 쓰지 않는다.** 말버릇 한두 개까지만(「아니 그러니까」).
- **고정 사실은 3개 안팎.** 많으면 애드립이 숨을 못 쉰다.
- **열려 있는 것**을 꼭 적는다. 「여기는 너희가 만들어」라는 표시.
- **주인공 자리**를 하나 표시한다(🎭). 어떤 인물이든 주인공으로 바꿔 들어갈 수 있다 — 같은 씬을 서연으로 다시 들어가면 다른 극이 된다.
- 추리의 🗝 진실 카드:
  - **봉인** — 나도 모르고 들어간다. 연기하다 진실과 부딪히면 그때 열린다. **추리하는 연습.**
  - **열람** — 알고 들어간다. 어떻게 숨기고 어떻게 들키는지 연출한다. **연출하는 연습.**

## 5. 주연 겸 PD — 두 모드

배우는 **안에서** 보고, PD는 **밖에서** 본다. 둘이 섞이면 둘 다 흐려진다. 그래서 화면을 둘로 나눈다.

```
     ┌──────────── 🎭 액션 (연기 중) ────────────┐
     │  상황 카드 (접힘)                          │
     │  서연: 학급비. 너 계속 여기 있었지.         │
     │                                          │
     │  [ 민재로 말하기 🎙 ]  [ 지문 ]  [ ✋ 컷 ]   │
     └──────────────────────────────────────────┘
                     │ 컷
                     ▼
     ┌──────────── 🎛 PD (씬 멈춤) ──────────────┐
     │  인물 다이얼 · 귓속말 · 돌발 상황 · 속마음   │
     │  템포 · 무르기 · 비트 N부터 다시            │
     │  🟡 새 사실 보드                           │
     │                          [ 🎬 액션 ]      │
     └──────────────────────────────────────────┘
```

| | 🎭 액션 | 🎛 PD |
| --- | --- | --- |
| 씬 | 흐른다 | 멈춘다 (프리즈) |
| 화면 | 대사 입력 + 지문 + 컷 버튼뿐 | PD 콘솔 + 새 사실 보드 |
| 나는 | 주인공. 주인공이 아는 것만 안다 | 판 전체를 본다 |
| 바꾸는 것 | 내 대사·행동 | 다른 인물·상황·시간 |

- **대사 중간엔 콘솔이 안 열린다.** 컷은 내 차례이거나 상대가 말을 끝냈을 때만.
- 감독 겸 주연 배우가 「컷」 하고 모니터 보러 걸어 나가는 그 동작이다. 컷이 곧 **밖에서 보는 시선이 돌아오는 순간**이라, 1인칭 몰입에 너무 빠지지 않게 잡아 준다.
- **PD만 하기**도 선택지로 둔다(주인공도 AI가 애드립). 단, 기본값은 주연 겸 PD.

### 주인공 카드 = 오늘 연기할 역

주인공은 AI 인물처럼 다이얼로 움직이지 않는다. 대신 **연기 목표**를 정한다.

```
🎭 민재 · 오늘의 연기
  성격 — 피하는 편 · 말 짧음
  연기 목표 — 「끝까지 학원 얘기 안 하기」
  (선택) 내 카드에서 가져오기 / 반대로 서보기
```

- 내 배우 카드(1부)에서 가져와도 되고, 반대 성향으로 서 봐도 된다.
- 작가실이 연기 목표와 실제 연기를 비교한다 — 「목표는 숨기기였는데 비트 7에서 먼저 꺼냈어. 왜 그랬는지가 이 씬에서 제일 궁금한 데야.」 평가가 아니라 기록.

### 차례 규칙

- AI 인물은 **1~2비트만 말하고 주인공에게 넘긴다.** 주인공 없이 AI끼리 길게 주고받지 않는다.
- 주인공 차례가 **30초 넘게 비면** — 상대가 먼저 한마디 하거나, 칩을 보여준다: `패스` `지문만 쓰기` `컷`.
- 주인공은 **대사 없이 지문만** 넣어도 된다(「대답 안 하고 창밖을 본다」). 침묵도 연기다.

### 말로 연기하기

폰으로 대사를 치는 건 연기가 아니라 타자다. **🎙 마이크로 말하면 대사가 들어간다**(기존 STT). 상대 대사는 TTS로 들려줄 수 있다(선택). 지문은 손으로.

## 6. PD 콘솔 — 컷 했을 때 쥐는 것

| 버튼 | 하는 일 | 예 |
| --- | --- | --- |
| 🎛 **성격 다이얼** | 다른 인물 성격을 돌린다. 액션 이후 대사부터 반영 | 서연 — 🔥 온도 2→4 |
| 🤫 **귓속말** | 한 인물에게만 몰래 방향 지시. 다른 인물은 모른다 | 서연에게: 「민재를 대놓고 의심하진 마」 |
| ⚡ **돌발 상황** | 상황을 하나 넣는다 (장르별 카드 + 직접 쓰기) | 「창문으로 바람, 블라인드가 덜컹」 |
| 🔎 **속마음** | 한 인물의 속마음 한 줄을 본다 | 서연 속: 「매점 간 거 말하면 내 탓 되는데」 |
| ⏩ **템포** | 시간을 건너뛴다 | 「3분 뒤」 → 담임까지 7분 |
| ✋ **무르기** | 애드립으로 생긴 사실 하나를 없던 걸로 | 「복도 CCTV」 → 이 학교엔 없음 |
| ⏪ **다시 찍기** | 원하는 비트부터 다시. 전 테이크는 남는다 | 「비트 4부터 다시」 |
| 🎚 **톤** | 장르 톤을 살짝 섞는다 | 추리 + 코미디 한 스푼 |

### 성격 다이얼 4개 (AI 인물마다)

| 다이얼 | 0 | 4 |
| --- | --- | --- |
| 🔥 온도 | 차분함 | 터짐 |
| 🎭 솔직함 | 다 숨김 | 다 말함 |
| 💬 말 수 | 한 단어 | 길게 설명 |
| 👀 상대를 보는 눈 | 내 사정만 | 상대 사정부터 |

- 배우 카드 4축을 다이얼로 옮긴 것. 모바일에선 🔥 온도 · 🎭 솔직함 2개만 기본으로 보이고 나머지는 펼침.
- **주연 겸 PD의 제일 큰 재미가 여기서 나온다.** 같은 대사를 다시 쳐도 상대 다이얼에 따라 반응이 달라진다. 「내 말은 그대로인데 세상이 다르게 받는다」를 직접 겪는다.

### PD도 못 하는 것

- 🔒 **고정 사실 바꾸기** — 작가 영역. 바꾸고 싶으면 씬 밖에서 「상황 카드 고치기」(= 새 판).
- 🗝 **진실 카드 바꾸기** — 봉인했으면 끝까지 봉인.
- **다른 인물 입에 대사 넣기** — 귓속말은 방향만. 「~라고 말해」는 거절된다. 그 말을 하고 싶으면 **주인공 입으로** 하거나, 주인공을 그 인물로 바꿔 들어간다.

> 인물은 PD 말을 듣지만, **자기 입으로** 말한다. PD가 대사를 넣기 시작하면 애드립이 아니라 대본이 된다.

## 7. 애드립 규칙 — 상황만 존재한다

AI 인물은 이 규칙으로 산다. 사용자에게도 보이는 규칙이다.

1. **받고, 더한다.** 주인공 말을 무시하지 않는다. 「아니」라고 해도 받은 다음에 「아니」.
2. **고정 사실과 부딪히지 않는다.** 창문이 열려 있으면 열려 있다.
3. **모르는 건 모른다.** 인물은 자기가 아는 것만 안다. 진실 카드는 그걸 아는 인물에게만 보인다.
4. **새 사실은 지어내도 된다.** 애드립이 만든 사실은 **🟡 새 사실**로 표시되고, 씬 끝까지 진짜가 된다. PD가 ✋ 무르기 전까지. 주인공(나)이 지어낸 사실도 똑같이 🟡.
5. **씬을 대신 끝내지 않는다.** 인물이 먼저 「범인은 너야」로 풀지 않는다. 결정적인 한 걸음은 **주인공이 딛거나**, PD가 돌발 상황으로 연다.
6. **한 비트 한 명, 1~2문장.** 지문(*행동*)은 반 줄.
7. **장르 규칙을 지킨다.** 추리면 단서는 공정하게(나중에 「아까 그거였네」 할 수 있게), 로맨스면 마음은 바로 말하지 않는다.
8. **주인공에게 반응한다.** 상황보다 주인공의 방금 한 말·행동이 먼저다.

**🟡 새 사실 보드** — PD 화면 옆에 쌓인다.

```
🟡 민재는 4시 50분에 화장실에 갔다           (🎭 민재=나, 비트 3)
🟡 3반 애 하나가 복도를 지나갔다             (🎭 민재=나, 비트 5)
🟡 서연은 창문을 직접 열었다                 (서연 애드립, 비트 9)
✋ 복도 CCTV — 무름                          (PD, 비트 6)
```

## 8. PD가 아는 것 vs 주인공이 아는 것

PD로 컷 했을 때 본 것(속마음, 귓속말, 열람한 진실)을 **주인공은 모른다.**

- **막지 않는다.** 대신 이걸 연습 거리로 삼는다 — **「아는데 모르는 척하기」.** 배우들이 매일 하는 일이다.
- 주인공이 알 수 없는 걸 말하면 작가실이 짚는다: 「서연이 매점 간 건 PD만 아는 건데, 민재 입에서 나왔어. 민재는 그걸 어떻게 알았을까?」
  - 사용자가 「일부러 그랬어. 민재가 아까 창밖으로 봤다는 설정」이라고 하면 → 🟡 새 사실로 올린다. **설명할 수 있으면 애드립, 못 하면 누설.**
- 추리 봉인 모드에선 **🔎 속마음 끄기**를 선택할 수 있다. 진짜 추리를 하고 싶은 날.

## 9. 내 기억으로 씬 완성하기 — 연습

> 시나리오는 지어내는 게 아니라 **기억에서 꺼내 씬의 모양으로 옮기는 것**부터 시작한다.
> 기억은 **사람 말·몸·소리**를 준다(그래서 진짜 같다). 애드립은 **기억에 없는 빈칸**을 채운다(그래서 이야기가 된다).
> 주연 겸 PD로 하면 — **그때의 나를 내가 다시 연기하고, 컷 하고, 판을 바꿔 다시 연기한다.**

### 다섯 걸음 (10분)

| 걸음 | 하는 것 | 디렉터가 하는 말 |
| --- | --- | --- |
| ① 기억 하나 | **5분짜리 한 순간.** 하루 전체 말고 | 「제일 또렷한 장면 하나만. 길게 말 안 해도 돼.」 |
| ② 씬 헤딩 | 어디 / 언제 / 낮·밤 → S# 한 줄 | 「거기 어디였어? 몇 시쯤? 밝았어?」 |
| ③ 남은 것 줍기 | **기억나는 말**(한 글자라도) · **기억나는 몸·소리** | 「누가 무슨 말 했는지 기억나? 정확히 아니어도 돼.」 |
| ④ 빈칸 표시 | 기억 안 나는 것 = **열려 있는 것** = 애드립 구역 | 「그다음은 기억 안 나지? 괜찮아. 거기가 무대야.」 |
| ⑤ 무대에 올리기 | 상황 카드 완성. **그때의 나는 내가 연기**, 다른 사람은 애드립 | 「카드 만들었어. 틀린 데 고쳐. 네 기억이니까.」 |

**기억 씨앗 칩** — 「기억 하나 말해 봐」가 부담일 수 있다. 처음엔 칩부터 보여 준다:
`체육대회` `급식실 자리` `수행평가 발표` `단톡방` `버스 정류장` `명절` `전학 온 날` `졸업식`

### 줄마다 붙는 표시

| 표시 | 뜻 |
| --- | --- |
| ⚪ 기억 | 실제로 있었던 말·행동 |
| 🟡 애드립 | AI 인물이 빈칸에서 만든 것 |
| 🖊 지금 | 내가 주인공으로 지금 한 말 |

다 찍으면 셋이 섞인 씬이 남는다. 작가실은 **어느 표시의 줄이 제일 살아 있는지**를 본다.

### 마지막 컷은 두 판

- **그때 한 것** — 실제로 그랬던 대로.
- **그때 안 한 것** — 그때 못 한 말·행동.
- 둘 다 찍어서 나란히 둔다. 어느 쪽이 맞다는 건 없다. **두 줄 사이가 그 씬의 진짜 내용**이다.

### 장르 렌즈 — 같은 기억, 다른 씬

고정 사실(⚪ 기억)은 그대로, 장르 규칙만 덧씌워 다시 올린다.

| 기억 (고정) | 🌱 청춘물 | 🔍 추리 | 😂 코미디 | 💘 로맨스 |
| --- | --- | --- | --- | --- |
| 계주 결승, 바톤을 떨어뜨렸다. 하윤이 「괜찮아」 했다 | 그날 반 자리 | 바톤은 왜 미끄러웠나 | 반 전체가 「괜찮아」를 다른 뜻으로 말함 | 「괜찮아」를 다르게 들은 애가 한 명 |

**어느 장르에서 내 기억이 제일 살아나는지** — 이 연습이 알려주는 것.

### 하루 한 씬

기억 씬은 서랍에 **「⚪ 기억 씬」**으로 따로 모인다. 하루 하나씩 모으면 그게 **내 소재 노트**다. 나중에 단막극·연속극의 S#1(일상)로 꺼내 쓸 수 있다.

**🎭 비트 1~4 — 그때처럼**
> 🖊 나(지후): 지문 — 반 자리 앞에서 멈춘다.
> **하윤:** *물병 따면서* 더워 죽겠다.
> **반 친구 A:** 아 아깝다 진짜. 2등까지 갈 수 있었는데. 🟡
> 🖊 나(지후): 「…미안.」
> **하윤:** *물 마시면서* 괜찮다니까. 🟡

**✋ 컷 → 🎛 PD**
> 나: 🔎 하윤 속마음.
> 🔎 *하윤 속: 사실 나도 출발 늦었는데. 아무도 그건 모름.* 🟡
> 🎬 (애드립이 기억에 없던 사실을 하나 만들었어. 하윤도 실수했다.)
> 나: ⏪ 비트 4부터 다시. 🎛 하윤 솔직함 1 → 3.
> 🎬 액션.

**🎭 비트 4~6 — 다시**
> 🖊 나(지후): 「…미안.」
> **하윤:** *물병 내려놓고* …나도 출발 늦었어. 너만 그런 거 아냐.
> 🖊 나(지후): 「…진짜?」
> **하윤:** 응. 근데 바톤 떨어진 게 소리가 커서 그거만 다 기억하는 거지.
> 🎬 (같은 「미안」이었는데 다른 대답이 왔어.)

**마지막 컷 — 두 판**
> 🎬 두 개 찍어 볼래? 「그때 한 것」이랑 「그때 안 한 것」.
> 🖊 나(지후) · 그때 한 것 — 대사: (없음). 지문: 반 자리 맨 끝에 앉아서 신발 끈만 다시 묶는다.
> 🖊 나(지후) · 그때 안 한 것 — 대사: 「너 아까 나 안 봤잖아. 그거 좀 서운했어.」
> **하윤:** *잠깐* …보면 너 울 것 같아서. *물병을 건넨다* 🟡
> 🎬 컷.

**작가실 — 기억 씬**
> ✍️ **⚪ 기억에서 온 줄** — 「바톤 떨어지는 소리」「나를 안 봤다」. 이 둘이 씬 전체를 진짜로 만들었어. 지어낸 장면엔 잘 안 나오는 것 — **소리랑 시선.** 기억이 제일 잘 주는 거야.
> ✍️ **🟡 애드립에서 온 줄** — 「보면 너 울 것 같아서」. 기억엔 없지만 「안 봤다」의 뜻을 바꿔 놨어. 빈칸을 이렇게 채우면 기억이 이야기가 돼.
> 🎥 **같은 대사, 다른 반응** — 「미안」을 두 번 했어. 하윤 솔직함 1에선 「괜찮다니까」, 3에선 「나도 늦었어」. 네 말은 그대로였어. 판이 바뀐 거야.
> 🎥 **두 판 나란히** — 신발 끈과 「서운했어」. 어느 쪽이 맞다는 건 없어. 그 두 줄 사이가 이 씬의 진짜 내용이야.
> 🎥 **한 컷 더** — 이 기억, 추리로 올려 볼래? 「바톤은 왜 미끄러웠나」. 같은 운동장, 다른 장르.

> 🎬 기억 씬 하나 완성. 서랍에 「⚪ 기억 씬」으로 들어갔어.

## 12. 작가실 — 씬 무대용 카드

방탈출 4장에서 씬 무대에 맞게 바꾼다. 점수·등급·순위는 없다.

| 장 | 보는 것 | 언제 |
| --- | --- | --- |
| ✅ 살아 있는 데 | 가장 사람 같은 한 줄 (대사든 지문이든) | 항상 |
| ⚠️ 드라마 냄새 | 개연성이 흔들리는 한 곳 | 항상 |
| 🔎 아는 것과 연기한 것 | PD만 아는 걸 주인공이 썼나 / 연기 목표와 실제 연기 | 주연 겸 PD |
| 🎥 PD 기록 | 컷 몇 번, 뭘 바꿨나, 무엇이 판을 열었나 | 항상 |
| ⚪🟡 기억과 애드립 | 어느 표시의 줄이 제일 살아 있나 | 기억 씬 |
| 🎬 한 컷 더 | 다음 씬 미끼 | 항상 |

**비판의 선** (기존 그대로)
- 고쳐주지 않는다. 「여기가 흔들려」까지만.
- 캐릭터 선택을 도덕으로 평가하지 않는다.
- 비판은 작품에, 사람에게 아님 — 「이 줄이 드라마 말이야」.
- 진실하게 말해 달라는 톤. 「극단적으로 / 던져 봐」 같은 말은 쓰지 않는다.

## 14. 안전 · 개인정보

- **위기 신호가 먼저.** 기존 `checkSafety`를 매 주인공 입력마다 돈다. 걸리면 씬을 멈추고 안전 흐름으로.
- **기억 씬은 더 조심.** 그때의 나를 직접 연기하면 감정이 더 진해진다.
  - 디렉터는 그 기억이 어땠는지 **캐묻지 않는다.** 기억은 재료다. 상담이 아니다.
  - 아픈 기억이 나오면 무대를 접고 묻는다 — 「이건 놀이 말고 깊은 무대에서 천천히 해도 돼. 어떻게 할래?」
- **실명은 저장하지 않는다.**
  - 기억 씬 ③단계에서 이름이 나오면 디렉터가 「이 사람 이름 바꿔 둘게」 하고 가명을 붙인다. 자동 감지가 불확실하니 **사용자가 이름을 탭해서 표시**하는 방식을 같이 둔다.
  - 치환은 화면에 뜨기 전에. 원래 이름은 세션 끝나면 버리고 가명만 남긴다.
- **기억 씬은 로컬에만.** 서버에 올리게 되면 About 「기록」 약속과 함께 다시 정한다.

## 16. 프롬프트

### 16-1. 인물 애드립 — `improvTask(scene, castId, take)`

AI 인물마다 따로 부른다. 주인공은 부르지 않는다(PD만 하기 모드 제외).

```
너는 {name}. {role}.
지금 상황: {situation}
누구도 못 바꾸는 사실: {facts}
너만 아는 것: {hides} {truth.knownBy에 네가 있으면 truth}
네가 원하는 것: {wants}
지금 네 성격: 온도 {temp}/4, 솔직함 {honesty}/4, 말 수 {words}/4, 상대 보는 눈 {otherView}/4
PD가 너한테만 한 말: {whispers — 방향만}
주인공: {lead.name} — 방금 주인공이 한 말·행동이 제일 중요하다.
지금까지: {lines 최근 8비트}
지금 생긴 새 사실: {newFacts (undone 제외)}

규칙: 받고 더한다. 사실과 부딪히지 않는다. 모르는 건 모른다.
씬을 대신 끝내지 않는다. 1~2문장 + 지문 반 줄.
새 사실을 지어냈으면 newFact에 한 줄로 적는다.
출력: { "text": "", "action": "", "newFact": null | "" }
```

- **진실 카드는 아는 인물에게만** 넣는다. 아무도 모르는 진실(`knownBy: []`)은 인물 프롬프트에 절대 안 들어가고, 판정 호출만 본다. 비밀 새는 걸 막는 핵심 장치.
- 다음 말할 인물: 직전에 안 말한 사람 우선, PD가 돌발 상황으로 지목하면 그 사람. AI 인물은 최대 2비트 연속 뒤 주인공 차례.

### 16-2. 판정 — `judgeTask(scene, take)` (비트마다, 가볍게)

```
입력: 진실 카드, revealWhen, 고정 사실, 직전 비트, pdOnly 목록
출력: {
```

## 19. 정해진 것 / 남은 것

**정해진 것**
- 방 = 씬 하나. 작가는 상황 카드만 쓴다 (대사 0줄, 고정 사실 3개 안팎, 열려 있는 것 명시).
- 입구는 장르 먼저. 장르는 상황 카드에 필요한 칸을 정한다.
- **기본은 주연 겸 PD.** 🎭 액션(연기)과 🎛 PD(씬 멈춤)는 화면을 나눈다. PD만 하기는 선택.
- 주인공은 다이얼 대신 **연기 목표**를 갖는다.
- PD는 고정 사실·진실 카드·다른 인물 대사를 못 건드린다.
- PD만 아는 걸 주인공이 쓰면 막지 않고 작가실이 짚는다. 설명되면 🟡 새 사실.
- 기억 씬: 기억 → 씬 헤딩 → 남은 말·몸 → 빈칸 = 애드립 구역 → 그때의 나를 연기. 마지막 컷은 「그때 한 것 / 안 한 것」 두 판.
- 실명 저장 안 함. 기억 씬은 로컬만.

**남은 것**
1. 첫 씬 세트 크기 — 추리 3 · 로맨스 3 · 코미디 3으로 시작할지
2. 🟡 새 사실이 다음 씬(단막극·연속극)으로 넘어갈 때 전부 넘길지, PD가 고른 것만 넘길지
3. AI 인물 상한 — 지금 안: 3명까지, 그 이상은 엑스트라(지문만)
4. 상대 대사 TTS를 기본으로 켤지 (몰입은 늘고, 교실·버스에선 불편)
5. 주인공 바꿔 들어가기(서연으로 같은 씬)를 「같은 씬 다른 판」으로 묶을지, 새 씬으로 볼지

# 2부 — 원작 씬 각색: 대본에 구멍 뚫기

> **2026-10-12 추가.** 영화·연극·뮤지컬의 **대표 씬**을 가져와 **현대로 각색한 대본**으로 보여준다.
> 이미 구조가 있는 씬이라 무대가 무너지지 않는다. 나는 **중요한 대사와 상황을 바꿀 수 있는 대사만 비우고** 그 자리를 내 스타일로 채운다.
> **전체를 다 바꾸려 하면 힘들다.** 그래서 기본은 「한 줄만」. 원하면 대사 전부를 고칠 수 있고, 보기도 「주요 대사만」「상황만」 등으로 고른다.
> 1부(오리지널 씬 = 상황만, 대사 0줄)와 같은 무대 위에서 돈다. 다른 점은 **빈 대본이냐, 구멍 난 대본이냐** 하나.

---

## 20. 왜 원작 씬인가

| | 1부 오리지널 씬 | **2부 원작 씬 각색** |
| --- | --- | --- |
| 시작 | 빈 무대 (상황 카드만) | **완성된 각색 대본** |
| 내가 하는 일 | 처음부터 다 만든다 | **구멍 난 자리만 채운다** |
| 부담 | 큼 — 첫 줄부터 내가 | 작음 — 한 줄부터 시작 |
| 무대가 무너질 위험 | 애드립이 흩어질 수 있음 | **뼈대가 붙잡아 줌** |
| 배우는 것 | 상황을 세우는 법 | **한 줄이 씬을 어떻게 바꾸는지** |
| 재미 | 내가 만든 세계 | 「로미오가 요즘 고2면?」 — 아는 이야기를 비트는 맛 |

> 몇백 년 살아남은 씬은 **뼈대가 검증된 씬**이다. 그 위에서는 한 줄만 바꿔도 「내 판」이 된다. 처음 쓰는 사람에게 제일 좋은 연습 무대.

---

## 21. 대본의 층 — 무엇이 비고, 무엇이 남나

각색 대본의 모든 줄에는 **층**이 붙어 있다. 층이 「얼마나 바꾸기 쉬운가」와 「바꾸면 얼마나 퍼지나」를 정한다.

| 층 | 표시 | 뭐냐 | 기본값 | 바꾸면 |
| --- | :---: | --- | --- | --- |
| **뼈대 비트** | 🧱 | 씬이 그 씬이게 하는 사건. 「둘이 서로 원수 집안이라는 걸 안다」 | 🔒 잠김 | 씬 정체성이 바뀜 — 확인 후 「원작에서 벗어나기」 |
| **명대사** | 🌟 | 원작에서 **모두가 아는 그 한 줄**의 자리. 🔑 중에서도 특별 | ⬜ **항상 숨김** (어떤 보기·난이도에서도. 컷 뒤 공개) | **방화벽 없음** — 바뀐 그대로 씬 끝까지 흘러감 (§23-1) |
| **핵심 대사** | 🔑 | 씬을 **돌리는** 한 줄. 이 줄 전과 후가 다른 씬이 됨 | ⬜ **비움** | 뒤쪽 대사가 영향받음 (§23) |
| **갈림 대사** | 🔀 | 상황의 **방향**을 바꿀 수 있는 줄. 다른 답이면 다른 길 | 보임 (난이도 따라 비움) | 다음 🧱 전까지 영향 |
| **흐름 대사** | 💬 | 이어 주는 줄, 리액션, 말버릇 | 보임 | 그 줄만 |
| **지문·상황** | 📝 | 장소, 행동, 분위기 | 보임 | 그 줄만 |

- 한 씬에 🔑는 **1~2줄**, 🔀는 **3~5줄**, 🧱는 **3~4개**. 이 비율이 무너지면 각색 대본을 다시 짠다.
- 🔑는 보통 **주인공 줄**이다. 내가 연기하는 자리에 구멍이 난다.
- 🔀는 주인공 줄일 수도, 상대 줄일 수도 있다. 상대 🔀를 비우면 **AI가 그 자리를 애드립**하거나 **내가 대신 쓴다**(PD 권한).

## 22. 보기 · 바꾸기 — 내가 고르는 것

### 22-1. 보기 6가지 (언제든 전환, 대본 내용은 안 바뀜)

| 보기 | 보이는 것 | 이런 때 |
| --- | --- | --- |
| 📜 **전체 대본** | 모든 줄 (비운 자리는 ⬜) | 처음 읽을 때 |
| 📝 **상황만** | 🧱 뼈대 + 📝 지문만. 대사 전부 숨김 | 대사 없이 상황만 보고 **처음부터 내 말로** 하고 싶을 때 (= 1부 오리지널 씬처럼) |
| 🔑 **주요 대사만** | 🧱 + 🔑 + 🔀 | 씬의 **척추**만 보고 싶을 때. 흐름은 애드립에 맡김 |
| 🎭 **내 대사만** | 주인공 줄만 (앞뒤 한 줄씩 큐) | 연기 연습할 때 — 배우 대본처럼 |
| ⬜ **빈칸만** | 내가 채워야 할 자리 + 바로 앞 큐 한 줄 | 빠르게 채우고 싶을 때 |
| ⚖️ **원작 대조** | 왼쪽 원작 비트 / 오른쪽 현대 각색 | 「이게 원래 뭐였지?」 궁금할 때 (§25 저작권 규칙 따름). 🌟 명대사 자리는 컷 뒤에만 |

### 22-2. 바꾸기 난이도 4단계 (들어가기 전에 고름, 씬 중에도 올리고 내릴 수 있음)

| 단계 | 비는 것 | 내가 쓰는 양 | 추천 |
| --- | --- | --- | --- |
| 🟢 **한 줄** | 🔑 핵심 대사 1개 | 1줄 | **처음. 기본값** |
| 🟡 **갈림길** | 🔑 + 내 쪽 🔀 | 3~5줄 | 두 번째부터 |
| 🟠 **내 판** | 주인공 대사 전부 | 주인공 전부 | 연기 목표가 분명할 때 |
| ✏️ **자유** | 아무것도 안 비움. **대신 모든 줄 고치기 가능** (상대 줄 포함) | 원하는 만큼 | 이미 한 번 해 본 씬 |

- 어느 단계든 **아무 줄이나 탭하면 고칠 수 있다.** 단계는 「처음에 몇 개를 비워 줄까」일 뿐, 막는 게 아니다. (🧱 뼈대만 확인 한 번)
- **변경 예산** — 단계마다 「이 정도 바꾸면 딱 좋아」 선이 있다. 🟢 1줄, 🟡 5줄, 🟠 주인공 줄 수. 넘어가도 막지 않고 한 번만 말한다: 「벌써 8줄 바꿨어. 여기서 한 번 돌려 보고 더 바꿀래? 한꺼번에 바꾸면 뭐 때문에 달라졌는지 흐려져.」

### 22-3. 채우는 방법

| 방법 | 하는 것 |
| --- | --- |
| 🖊 **쓰기** | 빈칸에 직접 쓴다 |
| 🎙 **연기하기** | 액션 중 그 차례가 오면 말로 한다 (STT) |
| 🔁 **원작 보고 비틀기** | 그 자리 각색 대사를 잠깐 보고(원작 대사 아님), 내 말로 바꾼다 |
| 🤐 **침묵** | 대사 없이 지문만. 「대답 안 한다」도 핵심 대사가 될 수 있다 |

## 23. 파급 — 한 줄을 바꾸면 어디까지 바뀌나

핵심은 **내가 바꾼 만큼만 바뀌고, 나머지는 붙잡혀 있는 것.**

### 🧱 방화벽 규칙
- 내가 🔑·🔀 한 줄을 바꾸면, **그 뒤 줄들이 ⚠️ 영향받음**으로 표시된다.
- 영향은 **다음 🧱 뼈대 비트까지만** 간다. 뼈대가 방화벽이다. 그 뒤로는 원래 대본이 그대로 기다린다.
- 영향받은 줄마다 세 가지 중 하나:

| 선택 | 하는 일 |
| --- | --- |
| 📌 **그대로** | 원래 대사 유지. 어색하면 작가실이 짚음 |
| 🟡 **애드립으로** | AI가 바뀐 줄에 맞춰 그 줄을 다시 연기 (다음 🧱로 돌아가는 방향으로) |
| 🖊 **내가 고침** | 직접 |

- 기본값은 **🟡 애드립으로.** 그래야 「한 줄 바꿨더니 상대가 다르게 받는다」가 바로 보인다.

### 돌아오는 힘 — 「원작 끌림」 다이얼
AI 인물이 다음 🧱 뼈대로 얼마나 세게 돌아오려 하는지.

| 끌림 | 하는 일 | 이런 때 |
| --- | --- | --- |
| 🧲 강 | 내가 비틀어도 인물들이 다음 뼈대로 부드럽게 데려감 | 🟢 한 줄 · 처음 |
| 🧲 중 | 뼈대엔 오지만 가는 길은 자유 | 🟡 기본 |
| 🧲 약 | 뼈대 무시하고 내 판으로 흘러감. 🧱도 영향받을 수 있음 → 「원작에서 벗어났어. 계속 갈래?」 | ✏️ 자유 |

### 원본은 절대 안 사라진다
- 모든 줄에 **↩️ 원래대로**가 있다. 씬 전체 **↩️ 처음 각색본으로**도.
- 바꾼 판은 판본으로 쌓인다(1부 단막극의 「1판·2판·감독판」과 같은 규칙).
- **⚖️ 바뀐 것만 보기** — 원래 각색본 대비 내가 바꾼 줄과 그 때문에 바뀐 줄만 하이라이트.

## 23-1. 🌟 명대사 자리 — 보여주지 않고, 「나였다면?」

원작 씬에는 **모두가 아는 그 한 줄**이 나오는 자리가 있다. 이 자리는 🔑 핵심 대사 중에서도 특별하게 다룬다.

### 원칙 다섯

1. **안 보여준다.** 어떤 보기(📜 전체 · ⚖️ 원작 대조 포함)에서도, 어떤 난이도(✏️ 자유 포함)에서도 숨긴다. 「원래는 이런 결이었어」 같은 힌트도 없다.
   먼저 보면 그 말이 머리에 박혀서, 나는 그걸 **따라 하거나 피하기만** 하게 된다.
2. **질문은 하나.** 상황과 바로 앞 한 줄만 보여 주고 묻는다:
   > 🎬 「여기가 이 작품에서 제일 유명한 한 줄이 나오는 자리야. 너였다면?」
3. **반응으로 이어진다.** 상대는 원래 대본이 아니라 **내 한 줄에** 반응한다. 그다음도, 그다음도.
4. **바뀌면 바뀐 그대로 흘러간다.** 명대사 뒤로는 방화벽이 내려간다.

   | | 🔑·🔀 일반 대사 | 🌟 명대사 |
   | --- | --- | --- |
   | 영향 범위 | 다음 🧱 뼈대까지 | **씬 끝까지** |
   | 🧲 원작 끌림 | 고른 대로 | **자동으로 약** |
   | 뒤쪽 🧱 뼈대 | 벽 | **참고 표지판** — 흘러가다 닿으면 닿는 것, 안 닿으면 안 닿는 것 |
   | 원작에서 벗어날 때 | 확인 한 번 | **묻지 않음.** 벗어나는 게 이 자리의 목적 |
   | 끝 | 각색본의 끝 | **열린 결말** — 내 한 줄이 만든 데서 끝 |

   단, **수위 안전장치(§25-3)는 그대로.** 흐름이 자유로워도 죽음·폭력·자해 쪽으로는 AI 인물이 따라가지 않는다.
5. **공개는 컷 뒤에.** 순서가 정해져 있다.
   ① 내 한 줄 → ② 그 한 줄이 만든 흐름 → ③ **원작 명대사** → ④ 원작에선 그 뒤에 무슨 일이 있었나(요약).
   비교는 「누가 더 잘했나」가 아니라 **「같은 자리, 다른 길」**.

### 다양하게 — 같은 자리에서 다시

명대사 자리는 **갈래 나무의 뿌리**가 된다. 같은 자리에서 다시 들어갈 때마다 가지가 하나씩 생기고, 가지마다 흐름이 다르다.

```
🌟 명대사 자리
 ├─ 가지 1 — 내 한 줄 A → 상대 반응 → … → 끝 A
 ├─ 가지 2 — 내 한 줄 B → 상대 반응 → … → 끝 B   (원작에서 벗어남)
 └─ 가지 3 — 침묵       → 상대 반응 → … → 끝 C
```

- 가지는 지우지 않는다. 판본처럼 쌓인다.
- 두 번째부터는 **「결 바꿔 보기」 칩**을 보여 준다. 대사가 아니라 **방향**만:
  `농담으로` `질문으로` `한 단어로` `침묵으로` `반대로` `행동으로`
  정답을 주지 않고, 내가 아직 안 가 본 쪽만 가리킨다.
- 가지가 **3개 모이면** 「가지 나란히」 보기가 열린다 — 가지마다 내 한 줄 · 상대 첫 반응 · 끝 한 줄.
- 원작 명대사는 **첫 가지 컷 뒤에 한 번** 공개된다. 그 뒤 가지들은 원작을 알고 쓰는 판이라 「봤음」 표시가 붙는다.

### 저작권 — 공개할 때
- 저작권 만료 원작: **원어 원문 짧게 + 우리가 새로 쓴 우리말 풀이.** 기존 번역본은 쓰지 않는다.
- 영화·뮤지컬 씬 원형(§24-2): 원문을 싣지 않는다. 「이 자리엔 보통 이런 결의 말이 나와」 수준으로만.

### 24-2. 영화·뮤지컬 「씬 원형」 (저작권 있는 작품 — 대본 안 가져옴, 원형만)

### 25-2. 저작권 안전장치

> ⚠️ 아래는 기획 원칙이다. 실제 공개 전에 **법률 검토**를 받는다(나라마다 보호 기간·2차적 저작물 기준이 다름).

| 원칙 | 내용 |
| --- | --- |
| **원문을 싣지 않는다** | 원작 대사를 그대로 옮기지 않는다. 저작권이 만료된 작품도 **현대어로 새로 쓴 각색 대사**만. 번역본은 번역가 저작권이 따로 있으므로 **기존 번역도 쓰지 않는다** |
| **만료 작품만 「원작 씬」** | §24-1 목록은 원작자 사망 후 70년 넘은 작품으로 시작한다. 작품 추가할 때마다 확인 |
| **최근 영화·뮤지컬·웹툰은 구조만** | 대사·가사·제목·인물명·고유한 설정 안 씀. 3막 한 줄씩까지만 추상화, 원천 3개 이상 반복된 갈등만, 출처 표시 없음 (§31~§32, §35) |
| **가사 금지** | 어떤 작품의 가사도 싣지 않는다. 노래 자리는 독백 |
| **⚖️ 원작 대조는 비트만** | 원작 쪽엔 「무슨 일이 일어났나」 한 줄 요약만. 원문 인용 없음 |
| **AI 생성 규칙** | 각색 대본·애드립 프롬프트에 「원작 대사·유명 대사를 그대로 쓰지 말 것」 고정. 판정 호출이 원작 유명 대사와 너무 비슷한 줄을 걸러냄 |
| **사용자 입력** | 사용자가 유명 대사·가사를 그대로 쳐도 막지는 않음(본인 연습). 단 **공유·서버 저장 기능이 생기면** 그때 다시 정함 |

### 25-3. 수위 안전장치 (13~18세)

원작 비극에는 죽음·폭력·자해가 많다. 각색할 때 **사건의 감정은 가져오고, 장면은 바꾼다.**

| 원작에 있는 것 | 각색 원칙 |
| --- | --- |
| 죽음·자살 | **안 가져온다.** 끝·이별·관계 단절·전학으로 옮긴다. 자해·자살은 암시도 안 함 |
| 결투·폭력 | 화면 밖으로. 「싸웠다는 걸 다음 날 안다」 수준 |
| 독·약물 | 안 가져온다 |
| 신체 처벌·감금 | 「연락 끊김」「외출 금지」 수준으로 |
| 성적 묘사 | 안 가져온다. 로맨스는 마음·말까지 |
| 혐오·차별 대사 (원작 시대상) | 대사로 옮기지 않는다. 필요하면 「그런 분위기」를 지문으로만 |

- **사용자가 고친 대사도** 매 줄 `checkSafety`를 돈다. 위기 신호면 씬을 멈추고 안전 흐름으로(기존 그대로).
- 원작 씬 목록 각 줄에 **수위 메모**를 붙인다(§24-1). 메모 없는 씬은 공개하지 않는다.
- 사용자가 🧲 약 / ✏️ 자유로 원작 결말(죽음 등) 쪽으로 끌고 가면 → AI 인물은 따라가지 않고 다른 방향으로 받는다. 반복되면 디렉터가 묻는다: 「이 방향, 혹시 네 얘기랑 닿아 있어? 그럼 놀이 말고 천천히 얘기해도 돼.」

### 25-4. 사람 안전장치 (기존 그대로)
- 실존 인물 실명·비방 안 됨. 기억 씬 실명 처리(§14) 동일.
- 비판은 작품에, 사람에게 아님. 고쳐주지 않음.
- 진실하게 말해 달라는 톤. 「극단적 / 던져 봐」 안 씀.

## 26. 시나리오 I — 발코니 씬, 명대사 자리에서 「나였다면」

> 🎬 원작 씬 골라 볼래? 로맨스면 이거 어때 — 『로미오와 줄리엣』 발코니. 요즘으로 옮겨 놨어.
> 나: ㅇㅇ.
> 🎬 둘은 서로 원수인 두 학원 원장네 애들이야. 밤 11시, 아파트 마주 보는 베란다. 넌 줄리엣 자리 — 이름은 「주은」. 상대는 「로운」.

### 작가실

> ✍️ **같은 질문, 세 대답** — 세 가지 다 원작 명대사랑 같은 질문에 답했어. 「집안이 우리 사이에 뭐가 중요해?」 가지 1은 **농담으로 「안 중요해」**, 가지 2는 **「그럼 바꿔」**, 가지 3은 **「아직은 중요해」.**
> 🎥 **원작과의 거리** — 가지 2가 원작에서 제일 멀리 갔어. 근데 재밌는 건, 원작에서 줄리엣이 실제로 한 말이 「이름을 버려」거든. **제일 멀리 간 가지가 제일 원작 같은 말을 했어.** 다만 원작은 진심이었고, 넌 「농담인데」로 시작했어. 그 차이가 이 판이야.
> ✍️ **살아 있는 데** — 가지 3, 「아니」 썼다 지우고 「아니 그게 아니라」 썼다 지우는 것. 대사 하나 없이 주은이 다 나왔어.
> ✍️ **드라마 냄새** — 가지 1, 「플래시 두 번 = 된다는 뜻」은 조금 영화 같아. 근데 둘이 플래시로 대화하던 흐름이면 버틸 수 있어. 취향.
> 🎬 어느 가지가 제일 주은 같아? 그걸 감독판으로 하면, 다음 씬(다음 날 편의점이든, 학원 상담실이든, 아무 일 없는 아침이든)이 거기서 열려.

### 27-3. 비울 줄 고르기 · 파급 계산

```ts
function blanksFor(level: EditLevel, a: Adaptation, leadId: string): string[] {
  const mine = (l: Line) => l.by === leadId;
  const famous = a.lines.filter((l) => l.tier === "famous").map((l) => l.id);   // 🌟 어느 난이도든 항상 숨김
  return [...new Set([...famous, ...byLevel()])];
  function byLevel(): string[] {
  switch (level) {
    case "oneLine":    return a.lines.filter((l) => l.tier === "key" && mine(l)).slice(0, 1).map((l) => l.id);
    case "crossroads": return a.lines.filter((l) => (l.tier === "key" || l.tier === "pivot") && mine(l)).map((l) => l.id);
    case "myCut":      return a.lines.filter((l) => mine(l) && l.tier !== "direction").map((l) => l.id);
    case "free":       return [];                  // 비우지 않음. 대신 모든 줄 편집 가능
  }
  }
}

// 바뀐 줄 → 다음 🧱 전까지 의존 줄만 affected
// 🌟 명대사면 방화벽 없음: 뒤쪽 대사 전부 내 한 줄 기준으로 다시 흐름
function affectedBy(changed: string, a: Adaptation): string[] {
  const from = a.lines.findIndex((l) => l.id === changed);
  if (a.lines[from].tier === "famous") return a.lines.slice(from + 1).filter((l) => l.tier !== "beat").map((l) => l.id);
  const nextBeat = a.beats.findIndex((b) => b.id === a.lines[from].beat) + 1;
  const wall = a.beats[nextBeat]?.id;                              // 방화벽
  return a.lines
    .slice(from + 1)
    .filter((l, i, rest) => !wall || rest.slice(0, i + 1).every((x) => x.beat !== wall))
    .filter((l) => (l.dependsOn ?? [changed]).includes(changed) && l.tier !== "direction")
    .map((l) => l.id);
}
```

## 29. 실행 가능성 — 2부

| 부분 | 난이도 | 메모 |
| --- | :---: | --- |
| 각색 대본 데이터 · 층 표시 · 보기 6가지 | 쉬움 | JSON + 필터. 보기는 같은 데이터의 다른 렌더 |

| 영향받은 줄 🟡 애드립 재생성 | 보통 | 줄 단위 호출. 다음 뼈대를 프롬프트에 넣으면 품질이 오히려 1부보다 안정적 |

**1부보다 쉬운 점:** 대본이 이미 있어서 AI가 처음부터 만들 게 적다. 호출은 「바뀐 줄 이후 다음 뼈대까지」만. 비용도 품질도 더 안정적이다.

**MVP에 넣는다면:** 원작 씬 2개(발코니 💘 · 시라노 대필 😂) + **🌟 명대사 자리 · 결 바꿔 보기 칩 · 가지 나란히** + 보기 3개(📜 전체 · 📝 상황만 · 🔑 주요 대사만) + 난이도 2개(🟢 한 줄 · ✏️ 자유) + 방화벽 파급 + ⚖️ 바뀐 것만 보기. 명대사 자리가 이 모드의 첫인상이라 MVP 1순위. 영화 원형 씬은 그다음.

## 30. 2부에서 정해진 것 / 남은 것

**정해진 것**
- 원작 씬 = 현대 각색 대본. 줄마다 층(🧱 뼈대 · 🔑 핵심 · 🔀 갈림 · 💬 흐름 · 📝 지문).
- 기본은 **🟢 한 줄** — 핵심 대사 하나만 비움. 모든 줄은 언제든 고칠 수 있음(뼈대만 확인).
- 보기 6가지: 전체 · 상황만 · 주요 대사만 · 내 대사만 · 빈칸만 · 원작 대조.
- 바뀐 줄의 영향은 **다음 뼈대까지만**(방화벽). 원본·판본은 절대 안 사라짐.
- **🌟 명대사는 예외.** 먼저 안 보여주고 「나였다면?」만 묻는다. 그 한 줄 뒤로는 방화벽 없이 바뀐 그대로 흘러간다. 같은 자리에서 다시 들어가면 가지가 쌓이고, 원작 명대사는 컷 뒤에 공개.
- 저작권 만료 작품만 원작 씬, 최근 영화·뮤지컬은 씬 원형만. 원문·번역·가사 안 씀. 공개 전 법률 검토.
- 원작의 죽음·폭력·자해는 가져오지 않음. 고친 대사도 매 줄 `checkSafety`.

**남은 것**
1. 첫 원작 씬 세트 — 발코니 · 시라노 · 인형의 집 · 흥부 박 · 라 보엠 5개로 시작할지
2. 각색 대본을 누가 만드나 — AI 초안 + 내부 검수, 아니면 작가 섭외
3. 🔀 갈림 대사 중 **상대 줄**을 비웠을 때 기본을 AI 애드립으로 할지, 내가 쓰기로 할지
4. 「원작에서 벗어나기」 한 판을 1부 오리지널 씬으로 저장해 줄지 (원작 → 내 씬으로 졸업)
5. 사용자가 각색본을 직접 만들어 공유하는 기능(UGC)을 열지 — 열면 저작권 검수 흐름이 따로 필요

# 3부 — 갈등 원천: 최근 작품의 구조만 가져와 내 작품으로

> **2026-10-12 추가.** 갈등의 원천은 **만화·웹툰·영화·연극·뮤지컬.** 기준은 **최근 3년(2023~2026) · 15세 관람가.**
> 2부의 원작 씬(저작권 만료 작품, 명대사 놀이)과 달리 여기서는 **명대사 없음. 상황과 구조만.** 가져온 구조를 **지금 우리나라 중학생의 처지**로 다시 쓰고, 내가 주인공이 되어 반응한다.
> 하나의 작품을 만드는 행동이다 — **장르 × 갈등 20 × 각도 × 인트로 × 본론 × 결론**을 고르면 내 무대가 선다.

## 31. 원천 규칙 — 가져오는 것 / 안 가져오는 것

| 가져온다 ✅ | 안 가져온다 ❌ |
| --- | --- |
| **갈등 코어 한 줄** — 「믿던 애가 내 비밀을 퍼뜨렸다」 | 제목, 인물 이름, 작품 고유 명칭 |
| **관계의 종류** — 친구 / 가족 / 라이벌 / 무리 | **대사** — 명대사 포함 전부 |
| **감정의 종류** — 억울함, 들킴, 끼임 | **고유 설정** — 세계관, 특수 능력, 특별한 물건·직업·규칙 |
| **씬 하나의 상황** — 기본 (§39). 단막극 뼈대가 필요하면 **고전 뿌리의 3막** (§40) | **사건의 구체적 순서·조합** — 장면 단위로 따라가지 않음 |
| 장르 관습 — 「범인은 이 안에」「경기 전 라커룸」 | 장면 디테일, 그림·비주얼, 음악·가사 |

- **최근 3년** — 지금 중학생이 아는 감각이기 때문. 단 사용자 화면에 「○○에서 가져옴」 표시는 **절대 안 한다**(§36).
- **15세 관람가** — 입구 필터. 그 위에 우리 수위 규칙(§25-3)이 한 번 더 걸린다. 15세 작품이어도 중학생 무대에서 빼는 것(자해 암시, 성적 장면, 극단적 폭력)은 뺀다.
- **명대사 없음** — 최근 작품의 대사는 한 줄도 안 쓴다. 「나였다면?」 놀이는 2부 저작권 만료 작품에서만.
- 만화·웹툰도 같은 규칙. 그림·캐릭터 디자인·말풍선 문구 전부 ❌.

## 32. 두 번 걸러내기 — 원천 → 갈등 카드

```
원천 작품 (내부 로그에만)
   │  ① 추상화 — 갈등 한 줄 + 관계 + 감정 + 3막 한 줄씩. 이름·장소·물건 다 지움
   ▼
갈등 코어 (추상)
   │  ② 재구성 — 우리나라 중학생 처지로 다시 쓰기. 장소·나이·사건·관계 전부 바꿈
   ▼
갈등 카드 (사용자에게 보이는 것)
   │  ③ 알아맞히기 테스트 — 카드만 읽고 원작을 맞힐 수 있으면 ❌ → ①부터 다시
   ▼
공개
```

**① 추상화의 선** — 기본은 **씬 하나의 상황**(§39). 단막극용 3막이 필요해도 한 줄씩까지만, 그리고 **고전 뿌리**(§40)에서. 「S#1에서 이런 일, S#2에서 저런 일」처럼 장면 단위로 적기 시작하면 너무 가깝다.

**⓪ 뿌리 먼저** — 갈등을 고르면 먼저 **고전 뿌리를 2개 이상** 찾는다(§40-2). 못 찾으면 그 갈등은 쓰지 않는다. 최근 작품은 뿌리가 지금도 살아 있다는 **확인**으로만 기록한다.

**② 재구성의 재료** — 중학생의 자리

| 장소 | 교실 · 급식실 · 학원 · 학원 셔틀 · 단톡방 · PC방 · 편의점 앞 · 아파트 놀이터 · 집 식탁 · 내 방 · 체육관 · 수련회 |
| --- | --- |
| 시간 | 쉬는 시간 10분 · 야자 없음(중학생) · 학원 끝 밤 9시 · 시험 전날 · 방학 첫날 · 수행평가 발표 직전 |
| 관계 | 초등 때부터 친구 · 2학기 전학생 · 같은 학원 다른 학교 · 형·누나·동생 · 엄마·아빠·할머니 · 담임 · 학원 쌤 · 반장 |
| 물건 | 폰 (압수됨/안 됨) · 단톡 캡처 · 성적표 · 용돈 · 게임 계정 · 체육복 · 급식 줄 |

**③ 알아맞히기 테스트** — 만든 사람 말고 **두 사람**이 카드를 읽는다. 한 명이라도 원작을 맞히면 다시 쓴다.

**④ 중복 원천 규칙** — 같은 갈등이 **서로 다른 작품 3개 이상**에 있으면 그건 장르 관습이다 → 안전. **한 작품에만 있는 특이한 갈등**은 더 멀리 추상화하거나 버린다.

**예시 (원천은 가상)**

| 단계 | 내용 |
| --- | --- |
| 원천 (내부) | 웹툰 — 전학 온 주인공이 전 학교 소문 때문에 무리에서 밀려나는데, 사실 소문의 주인공은 다른 사람 |
| ① 추상 | 새로 온 사람 + 따라온 소문 + 소문의 진짜 대상은 따로 있음. 3막: 밀려남 / 진짜 대상을 알게 됨 / 말할지 말지 |
| ② 재구성 | 2학기 전학생 「나」. 학원 단톡에 돌던 캡처. 그 캡처 속 사람이 사실 우리 반 반장이라는 걸 급식 줄에서 알게 됨. 반장은 나한테 제일 먼저 말 걸어 준 애 |
| ③ 테스트 | 두 사람 다 못 맞힘 → 통과. (「전학생 + 소문」은 작품 수십 개에 있음 → ④로도 안전) |

| 15 | 👀 괴롭힘을 봤다 | 다 봤는데 아무도 말 안 한다. 나도 | 체육복 갈아입는 교실 | 목격자 (※ 목격자 자리만) |
| 16 | 🎭 두 무리 사이 | 초등 친구 무리와 새 무리가 서로 싫어한다. 급식 어디 앉나 | 급식실 | 무리 |
| 17 | 🧢 외모·몸 | 놀림 한마디. 거울 앞 | 체육 시간 · 단체 사진 | 나 자신·무리 |
| 18 | 🧓 집안일이 내 몫 | 할머니 돌봄·동생 픽업이 내 차례. 친구들은 PC방 | 집 · 학원 셔틀 | 가족 |
| 19 | 🎮 거짓말 | 학원 빠지고 PC방. 엄마가 학원 쌤한테 전화했다 | 학원 앞 · 집 가는 길 | 가족·학원 |
| 20 | 🌱 하고 싶은 것 | 춤·그림·게임·노래. 「그걸로 뭐 먹고살래」 | 학원 상담실 · 식탁 | 가족·어른 |

- 10·17·18처럼 민감한 갈등은 수위 메모가 붙고, 위기 신호가 뜨면 바로 `checkSafety`.

## 34. 내 작품 조립 — 여섯 번 고르면 무대가 선다

```
① 장르  →  ② 갈등  →  ③ 각도  →  ④ 인트로  →  ⑤ 본론  →  ⑥ 결론 방향
                                                                  │
                                                     상황 카드 자동 생성 (§4 형식)
                                                                  │
                                                  🎭 주인공 = 나 → 액션 / 컷 / PD (1부 그대로)
```

| 단계 | 고르는 것 | 선택지 |
| --- | --- | --- |
| ① **장르** | 어떤 규칙으로 돌아가나 | §3의 8개 — 🔍 추리 · 💘 로맨스 · 😰 스릴러 · 🌱 청춘물 · 🏠 가족극 · 😂 코미디 · 🏆 스포츠 · 🌍 SF |
| ② **갈등** | 무슨 일이냐 | §33의 20개 |
| ③ **각도** | 누구 자리에서 보나 | 😮 당한 사람 · 😬 한 사람 · 👀 본 사람 · 🫥 끼인 사람 |
| ④ **인트로** | 어디서 시작하나 | 🌤 일상부터 (평소의 작은 선택 → 사건) · ⚡ 사건 한가운데 · ⏪ 끝에서 거꾸로 (결과를 먼저 보여주고) |
| | 어떻게 알게 되나 | 👁 직접 · 🗣 소문 · 📱 화면 |
| ⑤ **본론** | 뭐가 판을 흔드나 | 🚪 사람이 들어온다 (조연 슬롯: 목격자·내 편·방해꾼·당사자·어른·엉뚱한 존재) · ⏱ 시간이 쫓는다 · 💣 정보가 터진다 (비밀 하나 더) |
| ⑥ **결론 방향** | 어디서 끝나나 — **열린 결말 안에서 방향만** | 🗣 말하고 끝 · 🤐 말 안 하고 끝 · 🔄 뒤집고 끝 · ⏳ 미루고 끝 |

- 마지막 컷(대사 한 줄 + 지문 한 줄)은 어느 방향이든 **내가 쓴다.** 결론 방향은 디렉터가 상대역과 조연을 어느 쪽으로 세울지 정하는 데만 쓴다.
- ③ **각도가 「다양한 각도에서 영화 보기」다.** 같은 갈등을 당한 사람으로 한 번, 한 사람으로 한 번, 본 사람으로 한 번 들어가면 세 작품이 된다. 2부의 「주인공 바꿔 들어가기」와 같은 장치.
- 같은 갈등을 장르만 바꿔 다시 (장르 렌즈, §9) — 「단톡 빼기」를 추리로 보면 「누가 처음 빼자고 했나」가 되고, 코미디로 보면 「빠진 줄 모르고 계속 말하는 애」가 된다.
- 조합은 8 × 20 × 4 × 3 × 3 × 3 × 4 = 수만 개지만, 무대 구조는 하나다(1부 씬 무대 + 3부 단막극 씬 7개). 조합이 바뀌면 **상황 카드와 인물의 원하는 것·숨기는 것**이 바뀐다.
- 고르기가 부담이면 **🎲 추천 조합** 하나 — 내 배우 카드와 안 가 본 갈등 기준.

### 생성된 상황 카드 예 — 🔍 추리 × 2 단톡 빼기 × 👀 본 사람 × ⏪ 끝에서 거꾸로 × 💣 정보가 터진다 × 🤐 말 안 하고 끝

```
S#.  2학년 3반 교실 / 월요일 아침 8시 20분 / 아직 담임 안 옴
장르: 🔍 추리   갈등: 👥 단톡에서 빼기   각도: 👀 본 사람

[상황 — 끝에서 거꾸로]
  지난 금요일 밤, 반 단톡에서 유나가 빠졌다. 지금 유나는 교실에 들어와 자기 자리에 앉았다.
  아무도 말을 안 건다. 「나」(하은)는 금요일 밤 그 단톡을 처음부터 끝까지 봤다.
  담임이 오기까지 10분.

[인물]
  🎭 하은 (주인공 — 네가 연기 · 본 사람)
     원하는 것: 아무 일 없이 1교시 가는 것. 숨기는 것: 빼자는 말이 처음 나왔을 때 「ㅇㅋ」를 눌렀다.
  유나 — 빠진 애. 원하는 것: 누가 처음 말했는지. 숨기는 것: 단톡 캡처를 이미 갖고 있다.
  지호 — 처음 「빼자」고 한 애. 원하는 것: 자기가 처음이 아닌 걸로. 숨기는 것: 유나한테 빌린 돈.

[고정 사실]
  · 금요일 밤 10시 14분에 유나가 빠졌다
  · 단톡에 「ㅇㅋ」가 17개였다
  · 10분 뒤 담임이 온다

[진실 카드] 🗝 봉인 / 열람
  · ●●●●●●●●

[열려 있는 것]
  · 유나가 하은에게 먼저 말을 거는가
  · 「ㅇㅋ」를 누른 사람으로서 하은이 무엇을 하는가
  · 담임이 오기 전에 지호 이름이 나오는가

[결론 방향] 🤐 말 안 하고 끝 — 상대역·조연은 이 방향으로 세워짐. 마지막 컷은 네가 쓴다.
```

> 🎬 넌 하은이야. 다 봤고, 「ㅇㅋ」도 눌렀어. 유나가 앉았어. 액션.

## 35. 저작권 — 최근 작품 원천에 대한 답

> ⚠️ 기획 기준. 공개 전 **법률 검토** 필수.

**질문:** 오마주라고 하면서 완벽하게 같지 않고 구조와 상황만 비슷하면 괜찮은가?

| | |
| --- | --- |
| **원칙** | 저작권은 **아이디어가 아니라 표현**을 보호한다. 갈등의 종류·관계의 종류·장르 관습은 아이디어 → 가져와도 됨. 제목·이름·대사·고유 설정은 표현 → 안 됨 |
| **구조의 함정** | 대사가 하나도 안 겹쳐도 **줄거리의 구체적 전개·사건 순서·인물 관계 조합**이 그대로면 「실질적 유사성」으로 볼 수 있다. 그래서 **3막 한 줄씩까지만** 추상화하고, 장면 순서는 따라가지 않는다(§32 ①) |
| **「오마주」는 면책이 아니다** | 법적 예외가 아니다. 오히려 「○○에서 가져옴」 표시는 ① 복제 의도의 증거가 되고 ② 제목 사용은 상표·부정경쟁 문제가 따로 생긴다 → **출처는 내부 로그에만.** 사용자 화면·마케팅·About 어디에도 작품명 없음 |
| **안전권의 근거** | 같은 갈등이 서로 다른 작품 3개 이상에 있으면 장르 관습(누구 것도 아님). 20개 갈등은 전부 이 기준으로 골랐다(§33) |
| **최근 3년·15세는** | 저작권과 무관한 **콘텐츠 기준**이다. 전부 보호 중인 작품이므로 명대사·대사·장면은 0줄. 명대사 놀이는 저작권 만료 작품(2부 §24-1)에서만 |
| **테스트** | 알아맞히기 테스트(§32 ③). 카드만 읽고 원작을 맞히면 너무 가깝다 |
| **사용자 UGC가 생기면** | 사용자가 특정 작품을 그대로 옮긴 카드를 공유할 수 있으므로, 공유 기능은 검수 흐름과 함께 연다 |

**정리:** 상황·구조만, 두 번 걸러내기(§32)를 지키면 **위험은 낮다.** 여기에 **씬 하나 단위(§39) + 고전 뿌리(§40)**를 더하면 「최근 작품에서 가져왔다」는 말 자체가 성립하지 않는다 — 가져온 건 고전이고, 최근 작품은 확인이다. 위험이 생기는 지점은 ① 장면 순서까지 따라갈 때 ② 출처를 표시할 때 ③ 고유 설정이 남아 있을 때 셋이다.

## 38. 3부에서 정해진 것 / 남은 것

**정해진 것**
- 갈등 원천 = 만화·웹툰·영화·연극·뮤지컬, 최근 3년, 15세 관람가. **상황·구조만, 명대사 없음.**
- 두 번 걸러내기: 추상화(3막 한 줄씩까지) → 중학생 처지로 재구성 → 알아맞히기 테스트. 원천 3개 이상 반복된 갈등만.
- 출처는 내부 로그에만. 앱·마케팅 어디에도 작품명 없음. 오마주 표시 안 함.
- 갈등 20개, 중학생 자리로. 괴롭힘은 목격자 각도만.
- 조립 여섯 단계: 장르 × 갈등 × 각도 × 인트로 × 본론 × 결론 방향 → 상황 카드 자동 생성 → 주인공 = 나.
- 결론은 방향만. 마지막 컷은 내가 쓴다.

**남은 것**
1. 갈등 20개의 원천 로그 채우기 — 갈등마다 원천 3개 이상 확보 + 테스트 통과 기록
2. 「15세 관람가」 판정이 없는 웹툰·연극은 무엇을 기준으로 할지 (플랫폼 연령 표시 / 자체 판단)
3. `buildScene` 품질 — 조합 수만 개 중 어색한 조합(🌍 SF × 📊 성적표 등)은 막을지, 디렉터가 비틀지
4. 중학생 처지 재료표(§32 ②)를 실제 중학생에게 확인받기 — 「요즘 그런 말 안 써」 걸러내기
5. 법률 검토 — §35 기준 전체 + 특히 「구조만」의 선

## 39. 씬 하나만 가져오기 — 구조 대신 상황

> **2026-10-12 추가.** 3막 구조(§31·§32 ①)보다 **씬 하나의 상황**만 가져오는 쪽이 더 안전하고, 이 앱(방 = 씬 하나)에 더 맞는다. **이걸 기본으로 바꾼다.**

| --- | --- | --- |

| 저작권 거리 | 「구체적 전개의 조합」에 가까워질 수 있음 | 조합이 짧아 **누구나 쓸 수 있는 상황**에 가까움 |
| 앱과의 맞음 | 단막극(씬 7개)에서만 필요 | **방 = 씬 하나** 그대로 |
| 쓰는 곳 | 3부 단막극·연속극의 뼈대 | **1부 씬 무대 · 3부 갈등 카드** |

**씬 하나 가져올 때의 선**
- 가져오는 것: 장소의 **종류**(식탁·교실·정류장), 관계의 종류, 방금 일어난 일의 **종류**, 각자 원하는 것·숨기는 것의 **종류.**
- 안 가져오는 것: 그 장면의 **고유 장치** — 특별한 물건·규칙·공간(그 작품에만 있는 것). 대사. 이름.
- **서명 씬 예외** — 씬 하나여도 그 작품의 상징 같은 장면(고유 장치가 핵심인 장면)은 표현이다. 판별은 같은 질문: **다른 작품 3개 이상에 이 상황이 있는가.** 없으면 안 가져온다.
- 단막극(씬 7개)이 필요하면 3막 구조를 최근 작품에서 가져오지 않고, **§40의 고전 뿌리에서** 가져온다.

## 40. 고전과 융합 — 갈등의 계보

> 영화·소설의 갈등은 대부분 그리스 비극·성경·셰익스피어·우리 고전에 이미 있다. 그러면 논리가 뒤집힌다:
> **「최근 작품에서 가져온 것」이 아니라 「고전에 이미 있던 갈등」을 현대로 옮긴 것이고, 최근 작품은 「요즘 애들도 여기에 반응한다」는 확인용이다.**

### 40-1. 왜 더 안전한가

| | |
| --- | --- |
| 선행 공유 자산 | 고전에 있는 구조는 최근 작품이 **자기 것이라 주장할 수 없다.** 누구 것도 아닌 재산 |
| 증거가 된다 | 갈등마다 고전 뿌리를 붙여 두면, 그 표 자체가 「이건 누구 것도 아니다」의 기록 |
| 조심할 것 하나 | 최근 작품이 고전에 **새로 더한 비틀기**는 그 작품 것. **고전에 있는 것까지만** 가져온다 |
| 번역 | 고전 번역본은 번역가 저작권이 있다. 우리말 풀이는 **우리가 새로 쓴다** |
| 우리 고전 | 춘향전·심청전·흥부전·콩쥐팥쥐·설화는 **저작권이 없고** 중학생에게 가깝다. 적극적으로 쓴다 |

- 최근 작품은 `sources.json`에 **「확인」 항목**으로만 남긴다 — 「이 갈등이 요즘 작품 ○개에도 있다 = 지금 애들에게 살아 있는 갈등」. 가져오는 재료가 아니라 **살아 있음의 증거.**

### 40-3. 융합의 세 가지 방식

| 방식 | 하는 일 | 쓰는 곳 |
| --- | --- | --- |
| 🏛 **뿌리만** | 고전의 갈등 한 줄만 가져와 중학생 자리로 | 3부 갈등 카드 (기본) |
| 🪞 **씬 대조** | 고전의 그 씬과 내 씬을 나란히 — 「리어 왕도 식탁에서 이걸 들었어」 | 작가실 🎥 한 컷 더. 중학생이 고전을 **내 얘기로** 만나는 입구 |
| 📜 **각색 대본** | 고전 씬을 현대 대본으로, 🌟 명대사 놀이 | 2부 (그대로) |

> 🪞 씬 대조가 새로 생긴 재미다. 「단톡에서 빠진 날」을 찍고 나면 작가실이 한 줄 붙인다 — 「이거 400년 전에 온 마을이 한 여자한테 한 짓이랑 같은 모양이야. 그 여자는 끝까지 마을에 남았어.」 교훈이 아니라 **「나만 겪는 게 아니다」**를 고전으로 보여주는 것.

### 40-4. 원천 로그 수정 (§36-1에 더함)

```ts
type SourceLog = {
  // ...기존...
  classicRoots: { work: string; author?: string; scene: string; publicDomain: true }[];  // 고전 뿌리 — 최소 2개
  modernChecks: { medium: string; year: number; rating: "15"; note: string }[];        // 최근 작품 — 「확인」만. 재료 아님
  takeFrom: "classic";                 // 가져오는 재료는 항상 고전. 최근 작품에서 직접 가져오지 않음
  unit: "scene";                       // 기본은 씬 하나 (§39). 단막극 뼈대가 필요하면 고전의 3막
  classicAddedTwist?: string;          // 최근 작품이 고전에 새로 더한 비틀기 — 기록만 하고 쓰지 않는다
};
```

### 40-5. 정해진 것 / 남은 것

**정해진 것**
- 기본 단위는 **씬 하나의 상황.** 3막은 단막극에만, 그것도 고전 뿌리에서.
- 재료는 항상 고전. 최근 3년·15세 작품은 **「살아 있음」 확인용**이며 재료가 아니다.
- 갈등 20개 전부 고전 뿌리 2개 이상. 최근 작품이 고전에 더한 비틀기는 기록만 하고 쓰지 않는다.
- 🪞 씬 대조를 작가실에 추가 — 고전을 「내 얘기」로 만나는 입구.

**남은 것**
1. 계보표(§40-2)의 고전 각 씬을 우리말로 **새로** 요약하기(번역본 인용 없이)
2. 🪞 씬 대조 한 줄이 「교훈」처럼 들리지 않게 — 디렉터 톤 규칙(진실하게, 친구처럼) 안에서 문장 샘플 20개
3. 서명 씬 판별(§39) — 「다른 작품 3개 이상」을 누가 어떻게 확인하나. 체크리스트
4. 법률 검토 때 §35와 §39·§40을 함께 — 「고전 뿌리 + 씬 하나」 논리가 실무에서 어디까지 서는지

## 41. 세 층 — 뼈대는 고전, 공기는 최신 영화, 세부는 다시 고전

> **2026-10-12 추가.** §39(씬 하나)·§40(고전 뿌리)을 합친 최종 조립 규칙. **씬 하나를 세 층으로 만든다.** 층마다 출처가 다르고, 최신 영화 층은 「그 씬」이 아니라 「그 씬의 종류」만 준다.

```
        🏛 뼈대 (고전)        갈등 코어 · 3막 · 관계의 종류
              │
        🎬 공기 (최신 영화)    상황의 종류 · 장소의 현대성 · 매체 · 속도 · 요즘 감각
              │
        🏛 세부 (고전)        원하는 것 · 숨기는 것 · 상징 물건·행동 · 결말의 방향
              │
        🧒 재구성 (우리)       중학생 자리 (§32 ②) · 이름 · 대사 0줄
              ▼
           상황 카드
```

### 41-1. 층별 규칙

| 층 | 출처 | 가져온다 ✅ | 안 가져온다 ❌ | 왜 안전한가 |
| --- | --- | --- | --- | --- |
| 🏛 뼈대 | 고전 (저작권 없음) | 갈등 코어 한 줄, 단막극용 3막, 관계의 종류 | 번역본 문장 | 공유 자산 |
| 🎬 공기 | 최신 영화·웹툰·연극·뮤지컬 (3년·15세) | **상황의 종류**(「어둠 속에서 불빛 빌리러 온 옆방」), 장소의 현대성(고시원·학원 셔틀), 매체(단톡·캡처·배터리), 속도(10분·3%), 요즘 말의 결 | **그 씬 자체**, 고유 장치·물건·규칙, 이름, 대사, 사건 순서, 비주얼 | 「현대 생활의 사실」과 「종류」는 아이디어. 보호 안 됨 |
| 🏛 세부 | 고전 | 인물이 원하는 것·숨기는 것, 상징이 되는 물건·행동(손수건·편지·촛불·박), 결말의 방향 | 번역본 문장 | 공유 자산. **세부가 고전이면 최신 영화와 구체적 조합이 겹칠 수 없다** |
| 🧒 재구성 | 우리 | 중학생 자리, 가명, 고정 사실 3개, 열려 있는 것 | — | 우리 창작 |

**왜 세 층이 더 안전한가** — 실질적 유사성은 「구체적 조합」에서 생긴다. 공기 층만 최신 영화에서 오고 **뼈대·세부·대사·이름이 전부 다른 데서** 오면, 완성된 씬에 그 영화와 겹치는 조합이 남지 않는다.

### 41-2. 예시 — 💘 로맨스 · 「불빛 하나 빌리러」

| 층 | 내용 |
| --- | --- |
| 🏛 뼈대 | 『라 보엠』 — 촛불 꺼진 다락방, 불 빌리러 온 이웃, 열쇠를 찾는 척 손이 닿음. 갈등: 「처음 만난 둘, 핑계 하나로 머무는 시간」 |
| 🎬 공기 | 최신 로맨스 영화들에서 반복되는 **종류**: 정전·배터리·와이파이 같은 「요즘의 불빛」, 좁은 공용 공간, 몇 분짜리 시간 제한. (어느 한 영화의 장치가 아니라 여러 편에 있는 것만) |
| 🏛 세부 | 『라 보엠』에서: 원하는 것 = 더 있고 싶다 / 숨기는 것 = 사실 열쇠(배터리)는 벌써 찾았다 / 상징 행동 = 찾는 척하는 손 / 결말 방향 = 미루고 끝 |
| 🧒 재구성 | 수련회 숙소 복도, 밤 11시 소등. 옆방 애가 「보조배터리 있어?」 하고 문 앞에 선다. 내 폰은 7%. 사감 순찰까지 5분. 숨기는 것: 보조배터리는 가방에 있다. |

> 완성 카드만 읽으면 『라 보엠』은 알아볼 수 있어도(그래도 됨 — 저작권 없음) **특정 최신 영화는 알아볼 수 없다.** 그게 통과 기준.

### 41-3. 테스트 (§32 ③을 층별로)

| 질문 | 답이 「예」면 |
| --- | --- |
| 완성 카드만 읽고 **특정 최신 영화**를 맞힐 수 있는가 | 🎬 공기 층이 너무 두껍다 — 종류가 아니라 씬을 가져왔다. 공기 층만 다시 |
| 🎬 층에 그 영화에만 있는 물건·규칙·공간이 남아 있는가 | 고유 장치 → 뺀다 |
| 🏛 세부가 실제로 고전에 있는가 (만든 사람이 출처 씬을 댈 수 있는가) | 못 대면 그건 최신 영화 세부일 수 있다 → 고전에서 다시 찾는다 |
| 🏛 뼈대의 고전 뿌리가 2개 이상인가 | 1개면 그 고전의 특이한 구조일 수 있다 → 쓰지 않거나 더 추상화 |

### 41-4. 원천 로그 (§40-4에 더함)

```ts
type SourceLog = {
  // ...기존...
  layers: {
    skeleton: { classic: string; scene: string };                          // 🏛 뼈대
    air:      { kind: string; modernChecks: { medium: string; year: number; rating: "15" }[]; count: number };  // 🎬 종류 + 확인 작품 수 (3 이상)
    detail:   { classic: string; wants: string; hides: string; symbol: string; endDir: EndDir };               // 🏛 세부
  };
  layerTest: { modernGuessable: false; uniqueDeviceLeft: false; detailTraceable: true; rootsCount: number };
};
```

### 41-5. 정해진 것

- 씬 하나 = 🏛 뼈대(고전) + 🎬 공기(최신, **종류만**) + 🏛 세부(고전) + 🧒 재구성(우리).
- 최신 작품이 주는 건 「요즘의 공기」다 — 장소의 현대성, 매체, 속도, 상황의 종류. 그 씬·장치·이름·대사·순서는 절대 아니다.
- 세부는 반드시 고전에서. 만든 사람이 출처 씬을 댈 수 있어야 한다.
- 통과 기준: 완성 카드로 **고전은 알아봐도 되고, 최신 영화는 알아볼 수 없어야** 한다.
