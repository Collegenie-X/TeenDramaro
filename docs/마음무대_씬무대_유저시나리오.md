# 1부 — 앱 이름

## 1. 후보 다섯, 추천 하나

| 후보 | 읽는 법 | 왜 | 걸리는 것 |
| --- | --- | --- | --- |
| **컷! (CUT!)** ⭐ | 컷 | 이 앱의 단 하나의 동작. 「컷」 하는 순간 주인공에서 PD가 된다. 중학생 입에 이미 있는 말. 한 글자라 아이콘·버튼·외침이 다 된다 | 「컷」 단독 검색은 흔함 → 앱 스토어 표기는 「컷! — 내가 주연 겸 PD」 |
| 테이크 (TAKE) | 테이크 | 다시 찍어도 전 테이크가 남는다 = 실패가 기록이 아니라 판본. 「테이크 2」가 자연스러운 재도전 언어 | 영어 외래어라 13세에겐 한 번 설명 필요 |
| 나였다면 | 나였다면 | 🌟 명대사 자리의 질문 그대로. 앱 전체가 이 한 질문 | 길다. 버튼·로고로 약함 |
| 씬 하나 (S#1) | 씬 하나 | 방 = 씬 하나. 「오늘 씬 하나 찍자」 | 「씬」이 중1에겐 낯설 수 있음 |
| 애드립 | 애드립 | 인물이 애드립, 나도 애드립. 놀이 느낌 | 개그 느낌이 강해 추리·가족극 톤과 어긋남 |

**추천 — 「컷!」**
- 전체 서비스는 **마음무대(MindStage)** 그대로. 깊은 무대는 「마음무대」, 씬 무대는 「컷!」. 앱 안에선 탭 이름, 밖에선 「마음무대 · 컷!」.
- 태그라인: **「무대는 세워 놨어. 대사는 없어. 네가 주인공으로 들어가고, 마음에 안 들면 컷.」**
- 짧은 판: 「내가 주연 겸 PD」.
- 영어 표기 `CUT!` — 느낌표 포함. 느낌표가 「외친다」는 동작을 품는다.

> 이름이 「컷」인 이유를 사용자에게 한 줄로: **「컷은 끝내는 말이 아니라, 밖에서 보러 나가는 말이야.」**

# 2부 — 페르소나

## 2. 세 명의 중학생, 한 명의 어른

점수·등급이 없는 앱이라 「잘하는 애」 페르소나는 없다. 대신 **어디로 들어오는가**가 다르다. 이름은 전부 가명.

### 2-1. 🔍 민재 — 중3 · 「감정 얘기는 좀」

| | |
| --- | --- |
| 하루 | 학원 끝나면 PC방 아니면 폰. 친구들이랑 단톡 많이 함. 추리·스릴러 웹툰 봄 |
| 앱에 대한 태도 | 「고민 상담」이라고 하면 안 켬. **게임이면 켬** |
| 들어오는 문 | 🔍 추리 씬 「사라진 학급비」 — 봉인 모드. 범인 찾는 줄 알고 들어온다 |
| 처음 겪는 것 | 서연이 「너 있었지」 하고 나한테 말을 건다. 대답을 **내가** 해야 한다 |
| 걸리는 것 | 컷을 안 누름(neverCut). 8비트 지나면 디렉터가 한 번만 「컷 하고 상대 다이얼 하나 돌려볼래?」 |
| 끝에 남는 것 | 「같은 말 했는데 서연 반응이 달라졌다」. 작가실 🔎 「아는 것과 연기한 것」 |
| 깊은 무대로 가는가 | 당장은 아님. 갈등 19 「거짓말」(학원 빠지고 PC방)을 조립하다 「이거 내 얘긴데」 할 수 있다 |

### 2-2. 💘 하은 — 중2 · 「드라마 보면서 대사 따라 함」

| | |
| --- | --- |
| 하루 | 로맨스·청춘물 드라마와 웹툰. 친구 넷 단톡. 글 쓰는 걸 좋아하지만 보여준 적 없음 |
| 앱에 대한 태도 | 「내가 쓴 거」가 생기면 좋아함. 평가받는 건 싫음 |
| 들어오는 문 | 🧩 내 작품 조립 — 💘 로맨스 × 4 「들킨 마음」 × 👀 본 사람 |
| 처음 겪는 것 | 여섯 번 고르니 상황 카드가 선다. 대사가 없는데 **상황이 다 있다** |
| 걸리는 것 | 같은 갈등 같은 각도 3회(sameAngle) → 「😮 당한 사람으로 들어가 볼래? 같은 일이 다른 영화가 돼」 |
| 끝에 남는 것 | 서랍에 쌓이는 「내 작품」. 같은 갈등 세 각도 = 세 작품 |
| 깊은 무대로 가는가 | 🌟 발코니 씬 「나였다면?」에서 가지 3개 내고 나서, 자기 얘기 하나를 기억 씬으로 가져온다 |

### 2-3. 🌱 지후 — 중1 · 「그때 그 일」

| | |
| --- | --- |
| 하루 | 체육 좋아함. 말수 적음. 한 가지 일이 머리에서 안 떠남(계주 바톤) |
| 앱에 대한 태도 | 「얘기해 봐」가 제일 싫음. 근데 그 장면은 계속 생각남 |
| 들어오는 문 | 🧠 기억 씬 — 씨앗 칩 `체육대회` 탭 |
| 처음 겪는 것 | 다섯 걸음. 「제일 또렷한 장면 하나만. 길게 말 안 해도 돼」. 기억 안 나는 데가 **무대**가 된다 |
| 걸리는 것 | 애드립 10% 미만(memoryCopy) → 「빈칸 하나만 애들한테 맡겨볼래?」 |
| 끝에 남는 것 | 마지막 컷 두 판 — 그때 한 것 / 그때 안 한 것. **두 줄 사이**가 그 씬 |
| 깊은 무대로 가는가 | 위기 신호가 아니면 가지 않아도 된다. 「⚪ 기억 씬」 서랍이 소재 노트가 된다 |

### 2-4. 🧑‍🏫 곁의 어른 — 담임·상담 교사·보호자

| | |
| --- | --- |
| 원하는 것 | 아이가 「말하게」 되는 것. 하지만 아이의 기록을 들여다보고 싶진 않다(그러면 아이가 안 쓴다) |
| 앱에서 하는 것 | **아무것도 못 본다.** 기억 씬은 로컬만, 실명 저장 없음. About의 「기록」 약속이 이 사람을 위한 문장 |
| 쓸 수 있는 것 | 수업·동아리에서 **같은 방을 다 같이** — 같은 상황 카드, 서로 다른 마지막 컷. 공유는 사용자가 고른 것만 |
| 걸리는 것 | 「상담 앱이냐」 → 아니다. 진단·병명·처방 없음. 위기 신호면 `checkSafety`가 씬을 멈추고 안전 흐름으로 |

## 5. 갈림길 네 가지

### 5-1. 하은 — 조립 → 각도 바꾸기

```
① 💘 로맨스 → ② 4 들킨 마음 → ③ 👀 본 사람 → ④ 🗣 소문 · 🌤 일상부터
→ ⑤ 🚪 사람이 들어온다 (당사자) → ⑥ ⏳ 미루고 끝
```

> 🎬 「카드 섰어. 넌 유나 — 소문을 **들은** 쪽이야. 좋아하는 당사자는 지호, 지금 급식실 문으로 들어와.」
> (3판째 같은 각도) 🎬 「😮 당한 사람으로 한번 들어가 볼래? 같은 급식실인데 완전 다른 영화가 돼.」

- 하은이 고르기를 20초 비우면(choiceFatigue) 🎲 추천 조합. 내 배우 카드 + 안 가 본 갈등.
- 「○○ 드라마처럼」이라고 쓰면(sourceName) → 「그 작품은 못 가져와. 근데 그 안의 **일**은 가져올 수 있어 — 무슨 일이었는지 한 줄로?」

### 5-2. 하은 — 🌟 발코니, 「나였다면?」

```
🧱 비트1  주은은 로운이 맞은편 동에 산다는 걸 오늘 처음 알았다
🧱 비트2  둘 다 집안끼리 원수라는 걸 안다
📝        주은 폰: 「나 오늘 너한테 말 걸려고 학원 앞에서 30분 서 있었다」
🌟 주은    ⬜ ________________   ← 너였다면?
```

| 하은이 하는 것 | 앱 |
| --- | --- |
| 「원래 뭐였어?」(famousPeek) | 「끝나고 보여줄게. 먼저 보면 네 말이 안 나와.」 그래도 원하면 「봤음」 표시 |
| 30초 비움(famousStuck) | 결 칩: `농담으로` `질문으로` `한 단어로` `침묵으로` `반대로` `행동으로` |
| 가지 1 「30분이면 우리 엄마랑 너네 엄마 둘 다 지나갔겠네」 | 로운이 **이 한 줄에** 반응. 뒤쪽 🧱은 참고 표지판. 씬 끝까지 흘러감 |
| 컷 | 원작 공개 (원어 짧게 + 우리가 새로 쓴 풀이 + 원작에선 그 뒤) |
| 가지 1개로 끝내려 함(oneBranch) | 「같은 자리, 다른 결로 한 번 더?」 |
| 가지 3개 | 「가지 나란히」 — 같은 질문, 세 대답. 원작과의 거리 |

### 5-3. 지후 — 기억 씬, 다섯 걸음

| 걸음 | 디렉터 | 지후 |
| :---: | --- | --- |
| ① | 「제일 또렷한 장면 하나만. 길게 말 안 해도 돼.」 | `체육대회` 칩 → 「계주. 바톤 떨어뜨림」 |
| ② | 「거기 어디였어? 몇 시쯤? 밝았어?」 | 「운동장. 오후. 더웠음」 |
| ③ | 「누가 무슨 말 했는지 기억나? 정확히 아니어도 돼.」 | 「지수가 괜찮아 했음. 바톤 소리. 나 안 보고 뛰어감」 |

| ⑤ | 「카드 만들었어. 틀린 데 고쳐. 네 기억이니까.」 | 지수 → 「하윤」 가명 확인. 틀린 데 없음 |

- 마지막 컷 두 판 → 작가실 ⚪🟡: 「⚪에서 온 줄 — 바톤 소리, 안 봤다. 지어낸 장면엔 잘 안 나오는 것, **소리랑 시선.**」
- 장르 렌즈: 같은 기억, 🌱 청춘물 → 😂 코미디. 어느 장르에서 내 기억이 제일 살아나는지.

# 4부 — 차별점

## 6. 다른 앱과 무엇이 다른가

### 6-1. 한 줄 자리매김

**캐릭터 챗봇은 「대화」를 팔고, 인터랙티브 픽션은 「선택지」를 팔고, 상담 앱은 「진단」을 판다. 컷!은 「내가 세운 판」을 준다 — 대사는 없고, 상황만 있고, 결말은 내가 쓴다.**

### 6-2. 비교표

| | 캐릭터 챗봇 (Character.ai · 제타 류) | 인터랙티브 픽션 (Episode · Choices 류) | 청소년 상담·멘탈 앱 | 시나리오 작법 앱·강의 | **컷! (씬 무대)** |
| --- | --- | --- | --- | --- | --- |
| 나는 누구 | 「나」로 1인칭 몰입 | 독자. 선택지 고름 | 내담자 | 작가 지망생 | **가명 주인공 겸 PD.** 컷마다 밖의 시선 |

### 6-3. 여섯 가지로 압축

1. **주연 겸 PD.** 다른 앱은 「안」에만 있거나(챗봇) 「밖」에만 있다(픽션·작법). 여기선 **컷**으로 안과 밖을 오간다. 컷은 1인칭 몰입이 재연이 되지 않게 잡아 주는 장치이기도 하다.
2. **대사 0줄 상황 카드.** 고정 사실 3개 안팎과 「열려 있는 것」만. 그래서 같은 방을 다른 열쇠로 다시 들어갈 수 있다. 챗봇엔 「방」이 없고, 픽션엔 「열려 있는 것」이 없다.
3. **같은 말, 다른 반응.** 성격 다이얼 4개. 내 대사는 그대로인데 세상이 다르게 받는 걸 직접 겪는다. 챗봇 인물은 맞춰 주고, 픽션 인물은 고정이다.
4. **🌟 숨긴 명대사.** 400년 살아남은 자리에 먼저 내 한 줄을 넣고, 그 뒤 원작을 본다. 작법 강의는 반대로 한다(보여주고 분석).
5. **점수 없는 작가실 + 로컬 기록.** 「여기가 흔들려」까지만. 고쳐주지 않는다. 기록은 이 기기에만. 어른을 위한 리포트가 없는 게 어른을 위한 설계다.
6. **문제가 있어야 오는 앱이 아니다.** 상담 앱은 힘든 사람이 찾아온다. 컷!은 단톡 읽씹·조별과제·명절 질문 같은 **대다수의 이번 주**가 기본 무대다(🥛 순한 맛). 무거운 방(🔥)은 따로 두고, 대다수의 문으로 들어온 소수가 필요할 때 닿게 한다(§11).

### 6-4. 깊은 무대(기존 마음무대)와의 관계

| | 깊은 무대 | 컷! (씬 무대) |
| --- | --- | --- |
| 이야기 | 내 이야기 | 내가 세운 판 (기억 씬은 그 사이) |
| 디렉터 | 사이코드라마 연출 | 작가실 동료 + PD 콘솔 |
| 좋은 결과 | 진실함 | 있을 법함 × 내가 쓴 결말 |
| 들어오는 문 | 「요즘 어때」가 부담 없는 날 | 「게임이면 켬」인 날 |

같은 엔진(디렉터 · `personaBlock` · `checkSafety`), 다른 입장권. 놀다가 「이거 내 얘기랑 닿는데」 싶을 때 건너가는 문 하나.

## 10. 정해진 것 / 남은 것

**정해진 것**
- 이름: 전체는 마음무대, 씬 무대는 **컷!**. 태그라인 「무대는 세워 놨어. 대사는 없어.」
- 페르소나 셋은 **들어오는 문**으로 나뉜다 — 추리 씬 / 조립 / 기억 씬. 어른은 못 본다.
- 첫 판은 추리 씬 봉인 모드. 7일에 단막극 한 편.
- 차별점은 여섯: 주연 겸 PD · 대사 0줄 · 같은 말 다른 반응 · 숨긴 명대사 · 점수 없음+로컬 · 대다수의 하루가 기본 무대.
- 기본 무대는 🐣 기초반 × 🥛 순한 맛. 🔥 극은 따로 만든 방(6부).
- 진행은 데이터 → 한 판 → 내 판 → 명대사 → 단막극. 검증 4가지는 §24 그대로.

**남은 것**
1. 「컷!」 상표·앱 스토어 검색 확인. 안 되면 「테이크」.
2. 홈에서 깊은 무대와 컷!을 어떻게 나란히 둘지 — 탭 둘 vs 입구 하나에 문 둘.
3. 첫 사용자 테스트 모집 경로(학교·동아리·보호자).
4. 페르소나별 온보딩 한 줄 — 민재(게임 톤) · 하은(내 작품 톤) · 지후(씨앗 칩 톤)을 같은 홈에서 어떻게 고르게 할지.
5. 법률 검토(최종.md §19-2) — 이름 확정과 같이.

# 6부 — 장르 다음, 생애주기 — 순한 맛부터 매운 맛까지

> 대다수 중학생의 하루는 극한이 아니다. 단톡 읽씹, 조별과제, 폰 시간, 명절 질문 — **이번 주에 반 친구 절반이 겪은 일**이 대부분이다. 그래서 기본 무대는 「보통의 하루」고, 극한 상황은 **따로 만든 방**으로 둔다. 대다수가 순한 맛에서 컷과 다이얼을 손에 익혀야, 매운 방이 필요한 소수도 그 방에서 「밖으로 나와 보는」 힘을 갖는다.
>
> 두 축으로 정리한다 — **맛**은 상황이 얼마나 무거운가, **반**은 도구를 얼마나 쓰는가. 메뉴판처럼 전부 **보이게** 두고, 추천은 🐣 기초반 × 🥛 순한 맛에서 시작한다.
>
> 형식은 둘을 더한다 — 관찰 카메라 한 대가 한 시간대를 지켜보는 **📹 다큐 한 편**, 한 공간에서 3분 안에 웃기고 찡하게 끝나는 **📦 일상 스케치**(유튜브 생활 코미디 류 — 앱 안에서는 특정 채널 이름을 쓰지 않는다. 최종.md §19-2).

| 🌶 **보통 맛** | 학년마다 반 이상이 **1년에 한 번쯤** 겪는 일 | 많음 | 홈 둘째 줄 「요즘 그 일」 | 바로 | 첫 성적 충격 · 원서 · 첫 고백 · 이사 · 동생 태어남 · 첫 알바 |
| 🌶🌶 **매운 맛** | 몇 명만 겪지만 **다들 봤던** 일 | 일부 | 메뉴판 「진한 방」 | 한 번 묻기: 「놀이로 할래, 천천히 할래?」 | 단톡에서 한 명 빼기 · 믿은 친구의 배신 · 집 안의 냉전 · 「그걸로 뭐 먹고살래」 |
| 🔥 **극** | 소수지만 **겪는 애에겐 전부**인 일 | 소수 | 메뉴판 「따로 만든 방」 (보이지만 추천 안 함) | 🐣 기초반 한 판 이후 · 🐢 천천히 모드 고정 | 부모님 별거 · 집 사정 · 조부모 아픔 · 반려동물 이별 · 친구가 요즘 이상하다 |

- 홈 노출 비율 목표(가설): 🥛 60 · 🌶 25 · 🌶🌶 12 · 🔥 3. 실제 선택 데이터로 다시 정한다.
- 마케팅·홈 배너·학교 수업용은 **🥛·🌶만.** 🌶🌶·🔥는 찾아오는 사람의 방이다.
- 같은 주제도 맛이 넷이다(§13 맛 사다리). 순한 맛이 「가벼운 버전」이 아니라 **대다수의 진짜 하루**다.

### 11-2. 반 — 놀이 실력, 세 단계

| 반 | 하는 것 | 보이는 도구 | 한 판 | 다음 반 추천 시점 (제안) |
| --- | --- | --- | --- | --- |
| 🐣 **기초반** | 차려진 상황 카드에 주인공으로 들어가 말한다. 컷 한 번 | 🎭 액션 · ✋ 컷 · 🔥🎭 다이얼 2개 · ⏪ 다시 찍기 · 30초 칩 | 📦 스케치 3분 | 컷 1번 + 같은 대사 다시 치기 1번 |
| 🐥 **중급반** | 내가 판을 세운다 | 조립 7단계 · 🤫 귓속말 · ⚡ 돌발 · 🔎 속마음 · 🟡 보드·무르기 · 🗝 진실 카드 · 📹 다큐 | 10분 | 같은 갈등을 각도 2개로 |
| 🦅 **심화반** | 내 기억, 고전, 연속극으로 | 🧠 기억 씬 · 🌟 명대사 「나였다면?」 · 연속극 5편 · PD만 하기 · 장르 렌즈 · 고전 각색 난이도 전부 | 10~40분 | — |

- 반은 **잠금이 아니라 추천**이다. 기초반은 도구가 적게 보일 뿐, 「다 보기」로 언제든 펼친다.
- 잠금은 딱 하나 — 🔥 극 맛은 아무 반에서든 **한 판을 끝까지 해 본 뒤** 열린다. 컷으로 밖에 나와 보는 걸 한 번은 해 봐야, 무거운 방에서 빠져나올 수 있어서다.
- **안전 흐름과 깊은 무대 문은 맛·반과 상관없이 언제나 열려 있다.** 잠금은 놀이 방에만.

## 12. 조립 — 장르 다음에 「지금 어디쯤」과 「맛」

```
① 장르 → ② 지금 어디쯤이야? (시기) → ③ 맛 (기본 🥛) → ④ 이번 주 그 일 (시기 × 맛 추천)
      → ⑤ 각도 → ⑥ 형식 (📦 스케치 / 📹 다큐 / 🎬 보통 씬) → ⑦ 결론 방향 → 상황 카드
```

- **빠른 길** — 장르와 시기만 고르면 나머지는 기본값(🥛 · 📦 · 🎲 이번 주 그 일). 기초반의 기본.
- 디렉터: 「지금 어디쯤이야? 정확히 아니어도 돼. 비슷한 데 하나만.」

| 규칙 | 내용 |
| --- | --- |
| 🚣 같은 배 | 생애주기 씬엔 **같은 일을 같이 겪는 인물 1명**이 꼭 있다. 해결사가 아니다. 그 애도 모른다 |
| 🧭 헤쳐 나간다 = 해결 아님 | 끝은 「풀렸나」가 아니라 **「둘이 뭘 하기로 했나 / 안 했나」** 한 줄 |
| 🔇 어른은 답을 안 준다 | 엄마·담임·큰아빠는 자기 사정이 있는 사람. 「이렇게 해」는 안 나온다 |
| 🪪 이거 내 얘긴데 | 칩이 늘 떠 있다. 누르면 가명 그대로 기억 씬으로, 또는 깊은 무대 문. 밀지 않는다 |

## 16. 🐣 기초반 × 🥛 순한 맛 — 대다수의 첫 판

### 16-1. ⭐ 📦 「폰 압수 협상 테이블」 — 🍂 중1 가을 · 😂 코미디

```
S#.  우리 집 거실 소파 / 시험 2주 전 일요일 저녁 / TV 꺼짐
[상황]  엄마가 폰을 식탁에 올려놨다. 「시험 끝날 때까지.」 아빠가 중재자로 불려 왔는데 아빠도 폰 보는 중.
[인물]  🎭 지안 (주인공) — 원하는 것: 하루 30분. 숨기는 것: 단톡에서 내일 뭐 정하는 게 있다.
        🚣 동생 유찬 (같은 배 — 다음 차례) — 원하는 것: 누나 협상이 자기 선례가 되는 것. 말버릇: 「나도 그럼」
        엄마 — 원하는 것: 지안이 잠을 자는 것. 숨기는 것: 본인도 밤에 폰 본다.
        아빠 — 원하는 것: 이 자리가 빨리 끝나는 것. 말버릇: 「엄마 말이 맞지, 근데」
[고정 사실]  · 폰은 식탁 위  · 시험은 2주 뒤  · 아빠는 지금 폰을 보고 있다
[열려 있는 것]  · 아빠 폰이 거론되나  · 「30분」이 몇 분이 되나  · 유찬이 뭘 얻나
[수위 메모]  없음.
```

> **엄마:** 「시험 끝날 때까지. 끝.」 / 🖊 지안: 「아빠는 지금도 보는데.」 / **아빠:** *폰 뒤집으며* 「엄마 말이 맞지, 근데 이건 회사 거.」 🟡
> **유찬:** 「나도 그럼 회사 거 하나 사 줘.」 / **엄마:** *웃음 참으며* 「너는 회사가 없잖아.」 ← 웃긴 데
> ✋ 컷 → 🎛 엄마 🎭 솔직함 1→3 → 🎬 액션
> **엄마:** 「…엄마도 밤에 봐. 근데 엄마는 아침에 안 일어나도 되고 너는 일어나야 돼.」 🟡 ← 찡한 데
> 🖊 지안: 「그럼 밤 10시까지만. 10시에 엄마 폰이랑 같이 식탁에 두자.」 / **아빠:** 「…내 것도?」
> 마지막 컷(내가): 「10시. 셋 다.」 *식탁에 폰 세 개. 유찬이 자기 태블릿을 슬쩍 옆에 놓는다.*
> 📝 (한 박자 뒤) *10시 7분. 엄마가 식탁 쪽을 한 번 본다. 안 가져간다.*

### 16-2. 📦 「조별과제, 나만 했다」 — 🔥 중2 · 😂 코미디

### 17-4. 📦 「단톡 캡처가 돌았다」 — 🔥 중2 · 🌱 청춘물 · 🌶🌶 (기초반도 가능, 천천히 선택)

> 쉬는 시간 화장실 앞 복도. 어제 넷 단톡에서 내가 한 「걔 좀 오버하지 않냐」가 캡처돼 다른 단톡에 돌았다. 당사자 수빈은 아직 모르는 것 같다. 🚣 같은 배 = 캡처를 **처음 받은** 친구 해원 — 지울지 말지 아직 못 정했다. 고정 사실: 캡처는 최소 두 방에 있다 · 수빈은 5분 뒤 이 복도를 지나간다 · 내가 한 말은 사실이다(지울 수 없다).
> 열려 있는 것: 수빈에게 먼저 말하나 · 해원이 캡처를 지우나 · 「오버」의 뜻을 바꾸려 하나.
> 결론 방향 예: 🗣 「수빈아, 나 어제 단톡에서 너 얘기했어. 캡처 보기 전에 나한테 먼저 들어.」 / ⏳ 해원이 폰을 내민다 — 「지울지 네가 정해.」
> 🎬 작가실 — 「사실인 말」과 「돌아다닌 말」은 다른 말이야. 네 마지막 컷은 어느 쪽을 책임졌어?

## 18. 🔥 극 — 따로 만든 방

> 소수를 위한 방이다. 그 소수에겐 이게 전부라서 **따로, 더 조심해서** 만든다.

**들어오는 길**
- 홈 메뉴판 맨 아래 「🔥 따로 만든 방」 — 보이지만 추천에 안 뜬다. 아무 반에서든 **한 판을 끝까지 해 본 뒤** 열린다.
- 어느 판에서든 「🪪 이거 내 얘긴데」 칩 → 「따로 만든 방에 비슷한 무대가 있어. 아니면 깊은 무대에서 천천히 얘기해도 돼.」
- 안전 흐름·깊은 무대는 이 잠금과 상관없이 **언제나** 열려 있다.

**방 안의 규칙** — 🐢 천천히 고정 · 돌발 카드 꺼짐 · 비트 6개 · 컷 자주 권함 · 원인·싸움 장면 없음 · 어른 둘 다 애쓰는 사람 · 매 줄 `checkSafety` · 끝에 작가실 카드와 함께 「같이 말할 수 있는 어른」 카드(담임·학교 상담실·청소년상담 1388).

| 따로 만든 방 | 각도 | 형식 | 🚣 같은 배 |
| --- | --- | --- | --- |
| 💔 부모님이 따로 살게 됨 | 🫥 끼인 사람 | 📦·📹 | 동생 · 같은 처지 친구 |
| 💸 집 사정이 달라짐 | 🫥 · 👀 | 📹 | 형·누나 |
| 🧓 할머니가 입원하심 | 🫥 · 👀 | 📹 | 형제 · 사촌 |
| 🐾 반려동물이 떠난 다음 날 | 전부 | 📹 | 동생 · 같이 산책하던 이웃 애 |
| 👀 친구가 요즘 이상하다 | 👀 본 사람만 | 🎬 | 같이 눈치챈 친구 |
| 👀 한 애를 계속 놀리는 단톡 | 👀 본 사람만 | 🎬 | 같이 단톡에 있는 애 |

### 18-1. 📦 「주말 어느 집」 — 🔥 중2 · 🏠 가족극 · 🫥 끼인 사람

```
S#.  아파트 1층 현관 앞 / 금요일 저녁 6시 / 가로등 켜지기 전
[상황]  부모님이 따로 산 지 두 달. 금요일엔 아빠가 데리러 온다. 오늘 동생이 「안 갈래」라고 했고, 아빠 차는 벌써 밑에 와 있다.
[인물]  🎭 서진 (주인공) — 원하는 것: 아무도 안 울고 이 5분이 지나가는 것. 숨기는 것: 서진도 오늘은 안 가고 싶다.
        🚣 동생 다온 (같은 배) — 원하는 것: 오늘 친구 생일. 숨기는 것: 그게 전부가 아니다.
        아빠 — 원하는 것: 두 달 만에 처음으로 애들이 기다리는 것. 숨기는 것: 오늘 반찬을 네 가지 했다.
[고정 사실]  · 아빠 차는 밑에 있다  · 다온 친구 생일은 진짜다  · 엄마는 야근이라 모른다
[열려 있는 것]  · 서진이 누구 편인가 — 아니면 둘 다 아닌가  · 「다음 주」가 나오나  · 누가 먼저 계단을 내려가나
[수위 메모]  별거 이유·싸움 없음. 양쪽 부모 다 애쓰는 사람. 🐢 천천히 고정.
```

> 🎬 (들어가기 전) 「이 방은 천천히 가. 언제든 컷 하고 나와도 돼.」
> **다온:** 「나 오늘 진짜 생일이야. 거짓말 아니야.」 / 🖊 서진: 「알아. 아빠한테 네가 말해.」 / **다온:** 「…언니가 해 주면 안 돼?」
> ✋ 컷 → 🔎 아빠 속마음: *반찬 네 가지. 두 달 만에 처음 기다렸는데.* → 🎬 액션
> 🖊 서진: *폰으로 아빠에게* 「다온이 오늘 생일 가야 돼. 나만 갈게. 다온은 일요일에 데려다 줄게.」
> **아빠:** (답장) 「ㅇㅋ. 반찬 남겨 둘게.」 🟡 / **다온:** *언니 폰 화면 보고* 「…반찬 뭔데.」
> 마지막 컷(내가): 「일요일에 넷 다 같이 먹자.」 *다온이 「넷」에서 멈칫한다. 서진이 고치지 않는다.*
> 🎬 📦 웃긴 데와 찡한 데가 같은 줄이었어 — 「반찬 뭔데」. 🪞 『리어 왕』 세 딸이 누구 집에서 자나 — 그때도 애들이 정하는 게 아니었어.

### 18-2. 연속극 「따로 사는 첫 달」 — 🚣 동생 다온 · 🦅 심화반 · 5편

| 편 | 장소·형식 | 상황 한 줄 | 열려 있는 것 |
| :---: | --- | --- | --- |
| 1 | 내 방 · 📹 | 짐 두 벌 싸기. 뭘 어느 집에 두나 | 교복을 어느 집에 두나 |
| 2 | 학교 복도 · 📦 | 친구가 「주말에 뭐 해?」. 대답이 두 개 | 말하나 · 둘러대나 |
| 3 | 현관 앞 · 📦 (§18-1) | 다온이 「안 갈래」 | 누구 편인가 |
| 4 | 아빠 집 식탁 · 📹 | 반찬 네 가지. 셋이 앉는다. 자리 하나 빔 | 빈자리 얘기를 하나 |
| 5 | 엄마 차 안 · 📹 | 일요일 밤. 라디오. 엄마가 「아빠 잘 지내?」 | 뭐라고 답하나 · 다온이 먼저 답하나 |

끝은 「정리」가 아니라 **「우리 둘은 이 주말을 이렇게 하기로 했다」** 한 줄.

### 18-3. 📹 「할머니 병원 당번」 — 🔥 · 🐥 중급반 · 🫥 끼인 사람

> 토요일 오후 병원 휴게실 자판기 앞. 할머니 입원 3주째, 주말 당번이 형과 나로 정해졌다. 🚣 형(고2)은 오늘 친구 생일이라 한 시간만 바꿔 달라고 한다. 엄마는 「너희가 알아서」. 고정 사실: 면회는 4시까지 · 할머니는 주무시는 중 · 자판기엔 율무차만 남았다. 수위: 병명·악화 없음, 「입원」까지.
> 📹 인터뷰 컷, 형: 「저도 가기 싫은 게 아니라… 할머니가 저 못 알아보시면 어떡하나 해서요.」 🟡
> 자막 예: **「율무차 두 잔. 한 시간은 내가, 한 시간은 형이.」**

### 18-4. 🎬 「친구가 요즘 이상하다」 — 🔥 · 👀 본 사람만

> 쉬는 시간, 창가. 친구 하린이 2주째 급식을 거르고, 단톡에서 말이 없어졌다. 물으면 「괜찮아」. 🚣 같이 눈치챈 친구 다인. 고정 사실: 2주째 · 하린은 「괜찮아」만 한다 · 담임은 아직 모른다.
> 이 방의 인물(하린)은 **자기 사정을 털어놓지 않는다.** 구체적인 일은 만들어지지 않는다. 판은 「본 사람이 뭘 하나」에만 있다.
> 이 방에만 있는 결론 방향: 🧑‍🏫 **어른 한 명에게 같이 말하러 간다.** 마지막 컷 예: 「다인아, 점심시간에 상담실 같이 가 줄래? 하린이 얘기 말고, 우리가 걱정된다는 얘기만.」
> 끝나면 「같이 말할 수 있는 어른」 카드. 판 중에 주인공 입력에서 위기 신호가 나오면 씬을 멈추고 `checkSafety` 안전 흐름.

### 19-1. 🥛 「중2 2학기」 — 🚣 짝 시우 · 🐥~🦅

| :---: | --- | --- | --- | --- |
| 1 | 교실 · 📦 | 수행평가 조 편성, 시우랑 같은 조. 조장 정하기 | 누가 조장 하나 | 「시우는 발표가 무섭다」 |
| 2 | 각자 방 · 📦 | 단톡 읽씹 세 시간 (§16-3 변형) | 시우가 먼저 개인톡 하나 | 「시우네 주말엔 할머니 댁」 |

| 4 | 스터디카페 · 📹 | 시험 전날 4시간 결제, 공부 40분 | 남은 3시간을 어떻게 | 「둘 다 수학이 무섭다」 |

> 5편 마지막 컷 예: 「체육복은 3학년 때 돌려줘.」 *시우가 체육복을 다시 사물함에 넣는다.*

### 19-2. 🌶 「중3 겨울」 — 🚣 초등 친구 도윤

| 편 | 장소·형식 | 상황 한 줄 | 열려 있는 것 | 넘어가는 🟡 |

| 1 | 담임 상담실 · 🎬 | 담임이 「넌 A 쓸 수 있어」. 도윤은 B | 담임에게 B 얘기를 하나 | 「담임은 A를 밀었다」 |

| 3 | 식탁 · 📹 (§17-1) | 원서 두 장 | 누가 먼저 집나 | 「엄마의 A는 엄마 거」 |
